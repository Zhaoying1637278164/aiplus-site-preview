# D02 双表核对助手 0.1.0

双击 index.html 用现代 Chrome/Edge 打开，可断网使用。先体验虚构示例，再导入 UTF-8 CSV/XLSX，选择页签、表头行、左右匹配键和比较字段、币种列与容差，核对并下载 XLSX 底稿及 JSON 证据。示例预期：一致2组、差异1组、仅左1组、仅右1组、重复1组、无效1组；来源行左7右6。

方案下载不包含财务数据，仅保存映射和规则；恢复后重新导入原文件。证据 JSON 和 XLSX 底稿包含数据，由用户自行保存。关闭或清除页面后内存数据清除。不上传、不遥测、不默认持久化。公式不执行，不采用缓存；不自动换汇。

支持每文件10MB、解压30MB、20000数据行、200列。仅 UTF-8 CSV、XLSX；不支持宏、密码、xls/OCR。Windows未实机验证。官网验收状态查看项目progress/STATUS.md。
