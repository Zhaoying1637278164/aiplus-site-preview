# D06 财务数据质量体检器 0.1.1

用于财务表格质量诊断，不修改原表。支持必填、复合唯一键、类型、允许取值、金额范围、逐行加减勾稽六类规则；错误与警告分开，缺列只阻塞相关规则。

双击版本包 index.html，用现代 Chrome/Edge 打开。先体验完全虚构示例，再导入 UTF-8 CSV/XLSX，选择页签与表头行，展开规则调整字段、严重性、允许值、上下限或勾稽式。勾稽前确认同一行字段币种、单位、期间一致，点击开始体检。支持新增和删除规则，过滤查看问题。

下载质量报告 XLSX 包含规则执行、方案参数、错误问题、警告问题和全量行状态；JSON证据包含原始数据与来源。两种报告保留文件、页签、原行、规则及应用版本。方案下载明确 contains_data:false，只保存规则；恢复后重新导入文件。关闭或清除页面后内存数据清除，不上传、不遥测、不默认持久化。

虚构XLSX和内置示例：8行，7个问题行、1个未命中行、17条问题；错误6行、警告6行可重叠。XLSX最后一行故意含公式，程序不执行且不采用缓存。CSV不支持公式，使用安全文本 FORMULA_NOT_SUPPORTED 替代，因此为16条问题，仍为7个问题行。空白模板仅含表头。

每文件10MB、解压30MB、20000数据行、200列、1至100条规则；检查规模上限50万行字段组合，问题上限5万条，超限不生成部分报告，需减少规则或分批检查。不支持宏、密码、xls、AI/OCR或执行自定义代码。官网与离线验收状态以项目 progress/STATUS.md 为准，Windows实机未验证。

源码重建：npm ci，npm test，npm run typecheck，npm run build -- D06。浏览器验收：node --import tsx tests/d06-browser.ts，可用 AIPLUS_CHROME 指定开发测试浏览器。

0.1.1修复异步页签与表头值读取旧值的问题。财务规则版本不变，允许恢复0.1.0的同规则无数据方案；旧版交付包保留，官网使用新版。
