# D03 科目往来部门映射管理器 0.1.0

原始编码与名称分开，通过企业目标字典和本地映射版本管理科目、往来或部门转换。支持名称别名、范围、生效起止、排序优先级、确认/撤销和版本快照。保留原行，不改源，不汇总金额。

双击 index.html 用现代Chrome/Edge打开，断网使用。先体验完全虚构样例，再导入原始CSV/XLSX与目标字典；选择页签、表头行，指定原始编码、名称、范围、业务日期列。字典必须含目标编码、目标名称、范围。展开映射项编辑，新增默认未确认；优先级只排序，多个目标仍为冲突，用户需编辑/撤销/删除多义项后重新预览。可撤销最近20次编辑。

预览得到已映射、待确认、冲突、未映射、异常五类；名称编辑距离建议仅供复核，不自动应用。目标字典缺失、同范围同码重复或公式均阻断相关目标。已确认且范围/有效期内的唯一映射才应用。日期YYYY-MM-DD，生效边界含当天，空起止为开放端。

XLSX底稿含全量结果、已映射、未映射/待确认、冲突/异常、字典异常、目标字典、映射版本和参数；JSON证据含本次输入数据。结果保留文件/页签/原行、原值、规则ID、字典来源及应用/规则/映射版本。

配置方案明确不含数据；映射版本快照明确contains_data:true，包含映射原值/别名/目标，用户主动保存，不含原始输入表与字典。恢复配置后重新导入数据；恢复映射版本会替换当前映射，可撤销。关闭释放内存；清除本次数据同时清空原始表、字典、映射和历史。不上传、日志、遥测或默认持久化。

虚构XLSX/内置示例：8行=已映射2+待确认1+冲突1+未映射2+异常2；字典异常2条。原始零和负金额保留。第9原行故意为公式，不执行、不采用缓存。CSV用安全文本FORMULA_NOT_SUPPORTED替代该公式，因此8行=2+1+1+3+1。恢复虚构映射版本.json可体验版本恢复。

限制：每文件10MB，解压30MB，20000行、200列，映射1000项、别名50项，编码/名称/范围100字。原始行×(映射数+字典行数)最多100万，模糊建议字符比较最多1000万，超限需分批处理。公式、宏、外链、代码不执行；不支持xls、OCR/AI、远程MDM同步。Windows实机未验证，正式状态见项目progress/STATUS.md。

源码重建：npm ci，npm test，npm run typecheck，npm run build -- D03；输出release/D03/0.1.0。浏览器验收：node --import tsx tests/d03-browser.ts，可设置AIPLUS_CHROME开发测试浏览器路径。
