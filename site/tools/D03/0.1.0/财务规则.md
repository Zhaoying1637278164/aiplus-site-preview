# D03 财务规则

应用0.1.0，规则D03-2026-10-03.1。适用企业科目、往来、部门字典映射管理；依据为用户的本地目标字典、映射版本、范围与生效期。本工具不内置中国或海外会计税务政策，不自动判定科目经济含义或法定政策有效性。

原始编码、名称分开；编码按文本精确比较，前导零不可合并。名称去首尾空格、忽略大小写由用户主动配置，只影响匹配不修改原值。名称别名只在明确name映射项生效，不推断企业同义词。

范围精确一致，逐行业务日期必须有效。起止区间含边界，留空为开放端。优先级仅对候选排序，多个目标即冲突；含未确认不同目标也冲突。相同目标多规则只应用一次，保留所有规则ID。至少一条有效规则已确认且字典唯一时，才写入目标。

字典同范围编码必须唯一；重复或同键另有无效记录不得自动选。未确认、缺字典、公式、缺范围或日期均保留异常/待确认。模糊建议仅供复核，编辑距离不是匹配概率。原始金额仅保留，空不强填零、零负值不删除、不自动换汇或跨币种期间汇总。

输入行=五类结果之和；每原行唯一输出，结果保留原文件/页签/原行/原值、目标字典来源、参数及应用/规则/映射版本。人工预期见规格与独立预期.md。
