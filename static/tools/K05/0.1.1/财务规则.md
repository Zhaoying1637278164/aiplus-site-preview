# K05 财务规则

应用0.1.0，规则K05-CAS1-2026-10-04.1。中国会计依据：[财政部《企业会计准则第1号——存货》](https://www.mof.gov.cn/zhengwuxinxi/zhengcefabu/2006zcfb/200805/t20080519_23107.htm)第14–19、21–22条；[财会2006 3号通知](https://www.mof.gov.cn/gkml/caizhengwengao/caizhengbuwengao2006/caizhengbuwengao20062/200805/t20080519_23694.htm)规定2007-01-01上市公司施行，鼓励其他企业执行。仅供用户确认执行企业会计准则的企业、日期不早于2007-01-01使用，不作小企业准则、生物资产、建造合同等特殊范围的默认政策。

第15条规定成本与可变现净值比较；售价减完工成本、销售费用及相关税费。第16条要求确凿证据并考虑用途和期后事项，材料需按产成品判断；第17条合同数量及超额按不同价格依据。本工具要求用户分段提供数量、用途、价格基础、材料判断和依据，不推断售价或税率。

第18条原则按单项；数量繁多单价低类别或符合地区、系列、用途且难以分开计量的组合可以分组。用户手工填组ID、分组条件和依据批准。程序仅允许同主体、币种、金额单位和数量单位分组，一成员异常阻塞整组；不分摊组结果到单项。

第19条转回须原影响因素消失并限于原已计提准备。本工具要求用户确认因素消失、填写消失依据和可转回既有准备上限，计算min(候选转回,核实限额)；不具备依据仅列待批准差额。第14条已售存货相应准备结转；处置转销列独立变动，不能混入转回。第21条净额为成本减准备；净额输入必须加回测算前準备还原成本，避免再次扣除。

详见规格中的精确公式。期初至测算前数量、准备和三表来源严格勾稽；规则容差只显示重要性，不能解除勾稽错误。空不等于0，不换汇，不自动转换单位，币种/单位/日期必须相同。价格费用为每数量单位金额，成本和准备为总额。

负净值的零下限是本工具经用户批准的工程边界，保留负原值和需要复核标记，额外处置义务/预计负债不测算。不可确定的材料、组别、售价和范围阻塞相应功能。不生成可自动入账结论，不自动记账或提供合规保证。准备其他变动可正可负，但必须说明依据；本工具不为该变动的政策合规背书。
