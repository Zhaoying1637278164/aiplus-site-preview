# K05 存货跌价测算 使用说明

应用0.1.0；规则K05-CAS1-2026-10-04.1。适用于用户确认执行企业会计准则的企业存货期末测算。依据财政部存货准则第14–19、21–22条，2007-01-01起实施。售价、材料和组别判断、转回原因由使用者提供；没有依据的功能阻塞。本工具不自动记账、不测算税务扣除、不以库龄比例决定减值，也不代替企业政策判断。

## 打开与完整下载

官网：在原成本模块列表打开「存货跌价测算」详情，点使用进入本站九页工作；返回详情或导航离开时确认清空。本地：下载完整离线ZIP并解压，用Chrome或Edge双击本目录index.html，无需安装、账户或网络。完整下载包括程序index.html、原生runtime.json、三个空白CSV模板、三份虚构CSV、三表虚构XLSX、含/无数据方案、使用说明、财务规则、参考来源、第三方声明、离线ZIP和源码ZIP。源码包须有锁文件、共享包、工具源码、测试和构建说明，不含node_modules和业务数据。官网发布状态以实际交付为准。Windows实机未验证。

所有资料只在浏览器内存读取、计算、导出；关闭或退出清空。没有上传、遥测、自动保存、换汇、CDN、在线字体。必须主动下载底稿和工作。含数据JSON/XLSX含财务资料，应自行保管。每文件10MB、XLSX解压30MB、20000行、200列、单元格10000字，UTF-8 CSV或静态XLSX，拒绝宏/外链；不运行公式，公式值阻塞。

## 每页操作

1. 工作总览：先体验完全虚构样例或下载三表样例。样例不是企业政策。按资料卡进入各页。
2. 存货成本：导入账面成本，选页签和表头（原行保留），确认字段对应。一存货ID一行。输入成本值并明确「原始成本」或「已扣准备净额」；后者加回测算前准备还原成本。期初+增加-发出+其他数量=期末数量，其他变动须依据。金额单位是总额；价格是每数量单位金额。
3. 准备变动：导入期初、本期已计提、已转回、处置转销和其他准备变动。期初+已计提-已转回-处置+其他=测算前准备；与成本表测算前准备相等。已发生的转回与本次拟转回分开；处置转销不计作转回。
4. 净值依据：一存货可多条合同/一般售价分段，依据ID不可重复。分段数量合计必须等于期末数量；售价、完工成本、销售费用和税费均为单位值。用途为直接出售/加工后出售/生产材料；材料需填写明确判断和依据。依据日期不晚于测算日，用户应先确认期后事项如何影响期末估计，不能直接用未来报价代替。因素消失选择是时提供转回依据；各分段可转回上限合计不得超过存量准备。
5. 组别与批准：先设测算日、期间起日、币种、单位、显示小数和复核容差。默认按单项。若按组别，增加组ID、明确成员、选择第18条条件并填写依据；任一成员异常整组不计算，组别不分摊到单项。确认企业适用、填写批准人与净值政策依据，勾选批准当前资料后计算。换文件、字段或参数会撤回批准、清结果和旧复核。
6. 跌价测算：核对还原成本、原始净值、净值零下限和要求准备。负净值原值仍保留并须另行复核，额外处置义务不在工具内。要求准备为成本减非负净值的正差；容差只标重要性，不调平。
7. 计提与转回：新增为要求准备高于既有准备的差额；允许转回同时受因素消失依据和已核实上限约束。未获准差额留为待依据项，最终准备可能高于要求准备，不能声称都已调到要求值。核对期初至期末准备桥接为0。
8. 来源与例外：选择对象展开三表原值、文件、页签和原行；查看异常的原始字段和全行覆盖。填写复核说明不绕过阻塞；回资料页修正或换入资料后重新批准。
9. 底稿与恢复：下载15页签XLSX、测算CSV、完整JSON证据（含数据）；数值以文本保留完整精度，CSV公式前缀受保护。无数据方案只保存参数和字段；含数据工作包含三表和复核文字。恢复任一方案会清旧资料与结果，恢复后重新批准计算，不相信旧结果。模板CSV用于单表；XLSX虚构样例含三页，分别选页导入。

## 本次测算边界

金额最多24位含6位小数、Decimal80位内部精度、不在计算中舍入；显示0–6位不影响导出。空值不是零；零数量须零成本和准备并提供显式零数量估计行。来源/期间/币种/金额单位/数量单位一致，不自动转换。消耗性生物资产、小企业准则、特殊合同业务、额外义务和企业税率判断不覆盖。材料与组别条件不确定时不能强行套算。下载底稿并复核所有阻塞及待批准转回差额后再作企业处理。
