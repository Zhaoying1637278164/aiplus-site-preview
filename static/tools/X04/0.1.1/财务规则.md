# X04 财务规则 0.1.1

规则版本X04-2026-10-04.1。工具不提供税种政策默认值；规则依据为用户经核验的申报说明/内部账表对应说明。虚构示例只供操作测试，没有政策效力。

每条关系须有ID、名称、依据、规则版本、适用条件、生效起止期（YYYY-MM）与确认。每份资料须确认表单或账表版本和核验依据。规则期间覆盖工作期，所有引用行主体、期间、币种、单位须与工作范围完全一致。未确认或缺失、重复、公式、未知版本及不适用时阻塞该关系，不能用人工复核绕过。

白名单为左右两侧项目求和，单项系数只能+1或-1；项目用资料ID+项目+行项目+列项目精确定位，重复不汇总、不强配。差额=左侧精确和-右侧精确和，绝对差额≤非负容差视为“容差内”，其余“差异”。不调用eval/Function，不支持用户表达式；正负零均保留，空不是零。

金额最多24位数字、6位小数；Decimal独立精度60，内部不舍入，界面显示和底稿保留十进制原值；容差是独立关系参数，不由显示精度推导。币种及单位不换算；元/万元不自动折算。

每项结果带来源文件、页签、行号、原始值、符号、规则/应用版本；未引用行和无效行单列，关系通过不代表全表正确。复核意见只描述事实与处理建议。改变范围、资料、映射、版本、规则清除旧复核；完整工作恢复严格校验后重算，无数据方案不会附带资料和复核。

用户主动导出工作JSON明确contains_data=true；方案为false；均带schema_version、应用/规则版本，不默认保存。资料和JSON上限10MB，总资料行20000；完整工作数据内存处理。导出xlsx含文本金额和来源，不含可执行公式。不作自动申报或税务合规结论。
