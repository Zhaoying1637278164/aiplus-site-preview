# X04 申报数据核对

0.1.1候选。核对用户指定的申报表内、申报表间及申报与账表关系，定位差异并保留复核底稿。没有真实税种预置公式，不自动申报，不提供税务合规结论。官网/正式包/根独立验收尚未完成，不计accepted。

## 使用

候选离线ZIP在progress/evidence/X04/0.1.1/candidate。解压后用Chrome或Edge打开index.html，无需账号和网络。先载入完全虚构样例，了解3项容差内、1项差异、1行未覆盖的独立答案。

1. 在“版本与适用口径”设置主体、期间YYYY-MM、币种和金额单位。
2. 在“申报与账表资料”导入静态CSV/xlsx，选择页签和表头行，预览后加入。每页签为一份资料，稳定ID用在关系里；可移除后重导入。对应主体、期间、币种、单位、项目、行项目、列项目、金额八个字段。
3. 每份资料明确申报/账表类型、版本、核验依据并确认。工具不判定真实版本合法性，未知版本保持未确认。
4. 在“勾稽关系”添加关系，填版本、依据、条件和生效起止期。两侧按资料/项目/行/列选择项目，正负号只允许加减；设置独立容差并确认。未确认、缺失/重复/公式及口径不一致阻塞对应关系。
5. 在“差异复核”查看两侧金额、差额、每项来源文件/页签/原始行号，填写复核事实与建议。记录复核不会改变计算状态。改资料、规则或口径清除旧复核。
6. 在“来源与底稿”查看异常和未覆盖行、下载9张表xlsx底稿、无数据方案或含数据完整工作。恢复后重新校验和计算；无数据方案仍需重新导入资料。

## 隐私和限额

资料只在浏览器内存；不上传、遥测、联网或默认保存。关闭/清空或宿主dispose释放内存；未下载的工作将丢失。含数据工作明确contains_data=true，请自行保管。宏、xlsx外链和任意用户代码拒绝；公式不执行，金额公式缓存不计算。单文件10MB、解压30MB、200列、总20000行，最多12资料、200关系、每侧20项。空不是零，不自动换汇/换单位，金额6位小数内使用Decimal精确计算。

源码ZIP包含锁文件、公共包、本款代码、测试和第三方通知；BUILD.md给出npm ci、npm test、npm run typecheck、npm run build -- X04四命令。候选构建仅输出evidence，不写release。浏览器脚本需本机Chromium，可通过X04_BROWSER指定；安装依赖需要网络或缓存，成品运行离线。

参见产品与页面方案.md、规格与独立预期.md、财务规则.md、参考来源.md、验收证据.md、实现交接.md。Mac Chromium实际运行记录在evidence，Windows实机未验证；候选宿主不等于官网。

## 0.1.1 大批工作

来源表、核对结果和导入预览支持搜索、25条分页及首页/尾页；勾稽关系按5条分页，搜索稳定ID/名称/事项。搜索筛选仅改变页面展示，完整底稿和工作下载始终覆盖全部资料与关系。原始行选择和关系来源展开仍能读取尾部字段。

导入预览可选择“替换D1/D2...”并确认，保留原稳定资料ID和字段对应，替换为新文件/页签/行号；清空资料版本/依据/确认与所有复核，必须重新核验。请先主动下载当前含数据工作保存旧来源，替换不保留旧文件内存。旧0.1.0工作不会静默升级，版本不兼容会提示并保留当前工作。

大批验收使用152关系、1217虚构事项，其中1216参与核对、1条缺金额未覆盖；未知关系确认/依据/条件/生效期各有阻塞。未提高200关系、20000行、10MB/解压30MB限制。320px导航可横向滚动；宽表可在组件内滚动查看全部列。交付样例xlsx固定时间元数据，所有资产可逐字节源码重建；用户底稿保持运行时生成。
