# T01 银行对账台

应用 0.1.0。解压离线包后，用 Chrome 或 Edge 双击 index.html；无需安装，断网可用。先体验完全虚构样例，再导入本机资料。用户数据只在浏览器内存，关闭或退出清空。源码包包含锁文件、共享包、本款代码、测试、说明与声明。Windows 实机未验证；官网验收状态见项目 progress/STATUS.md。 银行流水空白模板与企业日记账空白模板字段相同；统一空白模板入口保留相同字段，两侧仍分别导入。

银行流水、企业日记账各自核验期初/期末，在批准方向后人工关联剩余额度，逐项批准四类未达，生成两侧余额调节表。十二页包括总览、银行流水、企业日记账、字段方向、候选、分配、未达、调节、复核、比较、来源事件及底稿。

1. 先载入完全虚构样例，或批准主体、账户ID、币种、单位、起止期间和截止日。金额精度校验不舍入；披露容差不放宽额度。
2. 银行/企业各自填写独立余额资料，空为未知。期间流水验算期初+收入-支出=期末；截止快照只使用期末，不重复加累计流水。
3. 流水页导入 xlsx/UTF-8 CSV，选页签、物理表头和字段映射，预览确认替换/追加；同名列按物理列区分。必需字段：主体、银行账户ID、币种、单位、流水ID、日期、原始方向、金额；稳定键与摘要可选。
4. 字段方向页批准每个原始方向；借/贷和负号不自动猜。批准稳定键后才生成严格候选；候选不确认。
5. 人工分配逐边指定两端金额和日期/依据，支持一对一、一对多、多对一与部分关联。确认不能超任一端，重复ID含坏行或超额整关联组隔离。撤销记录生效日，历史截止不变。
6. 未达分类逐项批准四类及金额/日期/依据，只用未关联剩余。手续费仅用户批准本地补记建议；调节表不是记账凭证，不发起交易或记账。
7. 两侧调节：企业期末+银行已收企业未收-银行已付企业未付；银行期末+企业已收银行未收-企业已付银行未付。未分类/无效/缺余额明确不完整，不凭差额调平。
8. 全量底稿下载14页签XLSX和每页CSV；主动下载含数据工作JSON或无数据方案，schema_version=1、contains_data明确。恢复先预览，取消保留；确认替换从原资料重算。无数据方案清空资料、余额、关联、分类、事件、复核及基线。

用户文件只在浏览器内存，不上传、不遥测、不默认保存。不执行公式、宏、外链或任意代码；成品无CDN/在线字体。退出取消保留全部工作，确认清空，重入空工作。单文件10MiB、实际解压30MiB、工作原行20000/物理列200；JSON10MiB、动作/事件2000，候选5000、导出30MiB/200万格；超限报错不截断。金额单位/币种不自动转换。

源代码与财务引擎分离，main.tsx与ToolProgram使用同一App，原生ShadowRoot无内层iframe。沿用根锁定依赖；Windows实机未验证。
