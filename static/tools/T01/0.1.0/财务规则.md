# T01 财务规则

规则版本 T01-2026-10-04.1。只提供用户批准输入与确定性算术，不引用海外默认会计/税务政策，不自动记账。

唯一范围：主体、银行账户ID、币种、单位、开始日、结束日、截止日。两侧分别录入余额来源，日期必须与范围一致。期初/期末空为未知。流水模式独立验算期初+收入-支出=期末；余额快照模式不重复加期间流水，标流水勾稽未适用。截止日必须在期间内且期末余额对应截止日。

方向必须逐侧人工批准原始方向值→收入/支出，不猜银行借贷。负号须批准方向后取绝对值，原符号保存。金额 Decimal，精度只校验不截断，容差仅披露差额，不放宽额度。范围外、无效、未批准、重复ID含坏行分别保留。重复ID按侧+主体+账户ID+币种+单位整组隔离。

候选要求有效且同范围/同方向/稳定键非空完全相等，稳定键已批准；一对多显示各连接，不自动核销。分配边金额>0，确认日与依据必填；确认日后生效，撤销日开始无效。重复分配ID、双端重复边、超额、无效端点使整个连接组隔离，不先来先占。人工分配可在有依据时连接不同稳定键，但范围/方向硬约束不可绕过。容差不放行超额。

四类：企业已收银行未收、企业已付银行未付、银行已收企业未收、银行已付企业未付。侧别与方向硬约束，逐项金额、依据、批准日，不从余额倒推。分类金额合计不得超过未关联余额，重复分类ID/超额整组隔离。

企业调节后=企业期末+银行已收企业未收-银行已付企业未付；银行调节后=银行期末+企业已收银行未收-企业已付银行未付。剩余未分类或无效明确不完整；只计算已批准部分，残差不等于对账完成。原截止余额、交易日期不改写。手续费仅用户批准本地补记建议；调节表不是记账凭证。

变更有依据、事件日期和前后值。历史分配/分类不删除，只撤销；版本比较用户主动留基线。恢复从原行/批准/事件重算，不信任缓存结果。用户文件只内存，关闭/退出清除；无网络、默认存储或任意代码执行。

来源补充：xlsx日期型单元格完整原时间保留，批准映射时UTC日另存标准化值；布尔原值保留。CSV含引号换行保留真实物理起始行。超链接/公式/错误对象拒绝。CSV公式样文本加单引号防误执行，含数据JSON与XLSX保留完整原值。
