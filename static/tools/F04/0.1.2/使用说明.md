# F04 集团往来与合并抵销 · 0.1.2 候选

为中国企业集团财务核对统一口径的简单内部债权债务，按明确人工批准模板形成抵销工作底稿。八页完整流程：主体与范围、内部往来、对方映射、双方方向核对、差异与复核、模板审批、抵销底稿、来源与下载。

解压候选离线包，在Chrome/Edge双击index.html；无需账户、安装或联网。点击“载入虚构样例”或“载入604行虚构资料”体验；样例未经自动批准。用户资料只在浏览器内存读取计算导出，无上传、日志、遥测或默认存储。退出/关闭清空；需要保留时主动下载含数据方案。

## 实际操作
1. 主体关系表填主体/母主体ID、纳入范围、政策一致、期间、币种、单位、范围依据；准确主体树及专业合并范围已在外部批准后，勾选确认。
2. 导入双方期末往来；UTF-8 CSV或静态XLSX，选择页签和表头；可通过“对应本款字段”选择原列。记录ID同主体唯一，金额非负十进制、方向借/贷分开，减值准备必须填0，依据必填；双方报送完整后勾选完整性。
3. 别名按“报送主体＋对方原编码”映射至准确主体ID；没有别名时可直接填准确主体ID。不模糊匹配，不自动换汇/跨单位/跨期间。
4. 双方方向核对按债权方/债务方/事项比较。互有债权分别比较，缺一方显示缺失。全部原行在来源页与底稿保留。
5. 逐组填写不同的编制人与复核人、日期及依据并保存。非零差异即使说明完整仍不得抵销，须源账更正后重新导入。
6. 填模板事项、资产及负债科目、有效期、依据；在审批页由批准人填写日期/依据并点击批准。资产科目需与借方来源一致，负债科目需与贷方来源一致，重叠模板不自动选择。
7. 只有零差额、有效资料、范围完整性确认、当前复核和批准模板齐备时，抵销底稿列出借负债贷资产。零额不生成分录；任何全局异常阻塞全部分录。
8. 下载十一表复核XLSX、含数据方案或无数据方案，以及同版本四资料CSV/XLSX模板与虚构样例。含数据方案保留四表、规则、复核审批，恢复重新校验计算；无数据仅保留范围和列映射并清空资料确认审批。无数据方案不含主体/对方/往来/模板资料。任何换资料或规则操作撤销所有旧复核与模板批准；主体或往来替换还会撤销对应范围或完整性确认。

## 0.1.2 大资料操作

604条虚构独立期末余额、27主体、26对方映射、302事项模板，互有债权按方向分别核对。所有表可选每页5/10/20/50行，默认10行，支持首页/末页及跳页；在资料页展开“更正原始行”，选择资料序号、字段及静态更正值，保存后保留源文件/页签/原行并撤销旧复核批准。资料序号604对应原始物理行605。替换资料、载入样例、恢复方案、退出前可取消或确认；取消保留当前工作。任何更改后须重新独立复核及人工批准。

## 边界和文件
只支持同一期间币种单位、已批准共同根范围、零减值简单债权债务。不判断控制，不生成完整合并报表，不处理复杂股权、商誉、未实现利润、减值抵销、递延所得税、收入成本或现金流抵销，不自动入账。本机人工记录没有企业审批或数字签名效力。

文件≤10MiB、解压≤30MiB，≤20000行/200列；单元格≤10000字符。拒绝公式/宏/外链/加密/任意代码；金额≤24数字且≤6位小数，全程精确字符串导出。容差与精度分离：容差只分级，非零差额仍阻止抵销。跨期间等资料不丢弃，原行及异常全部导出。失败导入/恢复不替换当前工作。

Mac Chrome实际运行证据见验收证据.md；Windows实机未验证，官网/正式包/accepted由总控独立验收。本款候选不得宣称已发布。

## 0.1.2 财务阅读界面
小屏使用同一张表的中文字段卡片，不另造隐藏数据表：业务主体/事项/科目/方向/金额优先，全部原列与静态值继续展示，来源文件/页签/原行及资料状态在后。原始组成从JSON改为中文字段和值的完整详情。抵销分录明确列出债权方、债务方、事项、科目、借方、贷方、来源主体及结论；完整原行来源、编制复核批准的人员/日期/依据/当前绑定可展开。桌面保留表内横滚。字号未缩小，小屏字段使用15px。八页及十一表导出字段和财务算法不变。
