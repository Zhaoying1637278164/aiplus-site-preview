# F04 财务规则 · F04-CN-2026-10-04.1

依据：财政部财会〔2014〕10号《企业会计准则第33号——合并财务报表》，2014年7月1日起施行；2026-10-04实际读取财政部文告原文：
https://www.mof.gov.cn/gkml/caizhengwengao/wg2014/wg201405/201412/t20141217_1168564.htm
第7、8、21条：合并范围基于控制及全部子公司，工具不通过股权比例判定控制。用户输入已批准主体关系、共同根主体、范围依据；联营/合营、投资性主体例外及复杂股权须在外部专业判断，本工具不计算。
第26–29条：以报表及内部交易资料为基础，统一政策与期间。关系表明确政策一致，母子主体、期间、币种、单位与工作范围一致。跨期、跨币种、跨单位不得自动换算或抵销。所用币种及单位由用户确定，非政策默认值。首版仅统一口径的期末简单债权债务余额。
第30条（二）：内部债权债务及相应减值准备应抵销。本款仅处理用户声明减值准备为0的简单余额；缺失减值或非0、减值抵销、未实现利润及递延所得税不予推断，明确阻塞并另行专业处理。不将简单债权底稿宣称完成整套合并报表。

本项目执行规则（工程约束，不冒充准则规定）：
- 记录ID在同主体内唯一，重复整批阻塞；双方方向借/贷＋非负金额分开表达。负值不得靠净额抵销，需源账更正静态重导；零值允许但不输出零额分录。空金额不等于零。
- 对方优先采用同主体显式映射，其次准确主体ID；重复映射、未知主体、同主体往来、不同关系根阻塞。
- 借方余额的主体是债权方，贷方余额的对方是债权方。核对键为债权方＋债务方＋事项＋期间＋币种＋单位；双方必须有记录，差额=债权余额合计−债务余额合计。互有债权分组，不自动净额。
- 金额Decimal 40位精度，输入最多6位小数24位数字；全程不舍入，导出金额为精确字符串。容差仅用于差异分级，不清除差额，差额非0即不得抵销。
- 任一无效资料、漏映射、口径/完整性问题均全局禁止产生分录，保留可复核汇总、覆盖与原行。异常不被人工“已复核”绕过。
- 逐组独立编制/复核人、真实日期格式、依据及绑定当前输入；模板唯一、科目与两侧每条来源科目一致、适用事项和期间一致；批准人、日期、依据必填，批准日期不得早于规则生效日。
- 符合以上条件，按显式批准模板生成借负债科目、贷资产科目两行，同额守恒，保留模板批准/逐组复核/源行；只为合并工作底稿，不直接记账。
- 换资料或规则一律撤销旧复核/模板审批；主体或往来替换另外撤销对应范围/完整性确认。差异解释不能替代源账更正；本地人工记录不具企业审批系统或数字签名效力。
