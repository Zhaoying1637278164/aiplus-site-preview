# E01 报销单校验

候选0.2.1，尚未登记accepted。九页：检查总览、资料导入、费用政策、检查参数、检查结果、重复候选复核、异常处理、来源追查、底稿与方案。

下载离线包解压后用Chrome/Edge打开index.html，先载入完全虚构样例，再导入本机UTF-8 CSV/XLSX。金额与日期须静态值，支持页签/表头选择及字段映射。企业政策由用户提供，参考企业费用政策模板填写范围、有效期、来源、版本、币种单位。替换同类资料不追加，且清除复核。

超标、资料缺失、重复候选、未执行政策分开。逐项记录复核人与依据，不改变源数据。底稿XLSX包含13类页签（无输入时可能缺资料页），另可下载检查证据JSON与含数据/仅参数方案。含数据文件由用户自行保管；恢复方案后须重新复核。关闭/退出清内存，无上传、外部请求、遥测和默认持久保存。

单文件10MB、解压30MB、20000行/200列；公式不运行，宏及外链拒绝。相似摘要仅候选，不认定违规舞弊。本款不替代审批，税务扣除、AI及OCR未实现。Mac Chrome候选验收见验收证据.md；Windows未实测，官网/正式包待总控。

开发：在工程根npm ci，然后node --import tsx --test tools/E01-报销单校验/tests/engine.test.ts；node_modules/.bin/tsc -p tools/E01-报销单校验/tsconfig.json；node --import tsx tools/E01-报销单校验/tests/build.ts。候选位于progress/evidence/E01/candidate/0.2.1；正式构建由总控npm run build -- E01。
