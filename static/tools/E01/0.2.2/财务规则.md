# E01 财务规则

应用0.2.0；规则 E01-2026-10-04.2。本规则为用户输入的企业制度检查，不内置法定标准或税务扣除政策。企业限额生效条件：来源依据、版本、有效期、费用类、主体/部门/员工、币种与单位完整；主体/部门/员工可用 *，其他必须精确匹配。有多个适用标准或无标准时该行政策未执行，不推定合规。

1. 金额使用本工程 Decimal 10.6.0，40位精度。输入最多24位数字、6位小数，无自动舍入或换汇。空金额/公式不当零；容差非负且仅判定超额是否需标记，保留未经容差修正的超额。
2. 每笔：超额=max(报销金额−限额,0)。员工每日：按政策ID、主体、员工、日期、币种单位汇总非负报销，组超额=max(合计−限额,0)，每行显示同组超额供追溯，不得逐行再相加。退款不能冲减限额。
3. 零金额默认复核，也可设置允许，仍保留原始零。负金额必须明确类型退款，正数或零退款阻塞。退款关联同主体/员工/费用类/币种单位且原单为正报销、日期不晚于退款。累计退款绝对额超过原单单列异常；跨期退款各期独立展示，不自动冲原期。
4. 按主体、期间、币种、单位分组金额：正/零报销合计＋带符号退款合计＝净额。阻塞行金额不进入合计，展示阻塞行数及原行。期间必须等于费用日期月份；不按申请日重归期间。金额可解析但政策未执行时仍入分组金额，不能解释为政策通过。
5. 必填基础字段固定检查，可增加部门、摘要、附件标记、发票号、原报销ID。政策要求附件时附件标记必须为“有”，该项单列资料缺失，不与超标混为一项。
6. 同发票号、同员工日期费用类金额、或同员工金额且日期窗口内摘要相似均只标重复候选。摘要相似用去空白小写双字符集合 Jaccard=交集/并集，无摘要不产生相似候选。默认不跨期，可显式开启；始终不跨主体币种单位。检查最多200000对或10000候选，截断明确提示未执行部分，须分批导入。
7. 复核保留人员、日期、依据、处理状态，不删改原检查。修改输入/映射/参数或恢复方案清除确认状态，需重新复核；含数据下载留原复核记录供查阅，但恢复不将其当当前确认。
8. 不替代审批，不认定违规/舞弊，不计算可税前扣除额。未提供AI、OCR、联网税率、企业系统连接。Windows实机未验证；官网验收留总控。

独立手算：交通120/120限额100，每笔20；餐费60＋50每日100，组超额10；退款−20关联120；零0单列复核；缺金额行不计0。CNY正金额350、退款−20、净330，USD10独立，无总体混加。
