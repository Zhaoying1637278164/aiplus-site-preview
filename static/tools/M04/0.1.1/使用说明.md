# M04 投资回报测算 0.1.1 候选

十页工作：工作概览 → 现金流资料 → 字段对应 → 折现与时点 → 项目回报 → IRR与风险 → 回收过程 → 情景敏感性 → 来源与异常 → 导出与恢复。

导入标准UTF-8 CSV或XLSX；明确项目、唯一现金流ID、类别、金额、币种、单位、期次或日期。初始投入为负，期次0/估值日；未来现金可按期初/期末或实际日期。非现金项目留底排除。币种与单位逐行一致，不自动换汇。导入页可录入和修订，导入原始资料另表保留。

折现率、要求回报和IRR都是年有效率百分比。年/季/月期次换算成年；日期支持实际天数/365或360，默认365。输入期限1至600。空不补零；公式、重复ID、时间越界、精度超限等阻塞所在项目。金额最多6位小数，计算Decimal70位；显示精度与IRR金额残差容差分开。

输出NPV、要求回报口径NPV、全期限累计现金、简单现金ROI、静态/折现首次及持续回收、情景和双因素NPV敏感性；下载10表完整XLSX及逐表全量CSV，包含参数、版本、源行与导入原值。全量下载不受页面筛选与分页影响。ROI=累计净现金/现金流出绝对值，不是ROIC或会计利润率。不自动判断现金税、通胀、融资/项目口径和投资决定。

IRR在指定范围内搜索，区间外未验证；非传统128个以上或传统601个以上非零净时间点仅IRR未执行，NPV/回收等仍计算。支持多个根和切点根候选，根须经Decimal残差复核；不收敛明确显示。非传统现金流不据单个IRR自动决策。回收插值需用户选择均匀流入假设；默认付款时间点。

所有文件只在浏览器内存。含数据工作、无数据方案均由用户主动下载JSON，带schema_version、工具/应用/规则版本和contains_data；恢复后重算。关闭/清空释放内存。不执行用户公式/代码，不上传、遥测、默认持久化或外部请求。文件≤10MB、解压≤30MB、20000行、200列；最多100项目、10情景、10×10敏感性。
