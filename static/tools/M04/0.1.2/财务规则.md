# M04 财务规则

规则版本M04-2026-10-04.1，自2026-10-04应用；数学底稿规则，无自动中国会计/税务政策判断。适用于用户已确认的税后增量现金流与一致币种单位，缺少依据阻塞运行。

1. 输入金额≤6位小数、24位数字，Decimal70位计算；空值错误，零负独立支持。初始/后续投入、营运投入不得为正；残值/营运回收不得为负。非现金项目明确排除，利润不得代替现金。类别为经营现金流时用户确认实际现金属性，程序不能从名称识别真假现金。
2. 年有效r>−100%。NPV=ΣCF_t/(1+r)^t。规则期次0固定0；期末t=p/f，期初t=(p−1)/f，f为每年1/4/12期。实际日期t=UTC日历天差/365或360。估值日前和期限外阻塞。初始投入只能t=0。缺估值时点须显式补零，不自动猜。
3. 要求回报率独立用户参数，与折现率各自依据确认；不默认WACC/要求回报为中国政策。NPV、各时间点现值和总现值残差留底。
4. IRR令NPV=0，r>−100%，默认搜索−99.9%至1000%。同时间现金先净额汇总、去零后计符号变化。归一化指数和导数递归隔离单调区间，包含切点候选；Decimal迭代复核金额残差≤用户容差。有限搜索数值解，不声称区间外无根；浮点候选隔离不能作为严格符号代数全解证明。传统最多601、非传统最多128非零时间点，更多明确未执行IRR；不收敛/多解/不唯一各自说明。全部净额零为任意利率解；单一符号无解。IRR输出百分比年有效率。
5. 静态/折现回收分别基于累计现金/累计现值。起点无负净投入不适用。首次由负转非负；持续要求此后到期限结束不再负。离散时间点为默认；插值为相邻时点差×未回收余额/本区间净流入，仅用户接受均匀流入假设时使用。
6. 简单现金ROI=全期限净现金/流出绝对值×100；流出为0不适用。不得标会计ROIC。不同项目不默认合计。
7. 情景倍数独立：初始投入、非终端正现金、非初始负现金、残值/营运回收；率独立。双因素只改正经营类现金（包含非终端正现金），初始、终端和负现金不变，不宣称因果。情景参数、版本和全量结果留底。
