# P01 采购三单核对

本款0.1.0。正式离线程序已构建，官网与最终验收由总控逐项验证，未齐证据不标accepted。八个业务页面：工作总览、采购订单、收货与退货、发票与红字、关联与分配、核对口径、差异与复核、来源版本与底稿。

## 使用

解压离线包后双击同目录 index.html；项目内正式程序位于 release/P01/0.1.0/index.html。载入31行完全虚构样例先看订单100、收货80、票100的未交20与已票未收20。分别换入四类CSV/XLSX，选页签、表头、映射，确认静态量额和批准范围；显式订单/来源行ID分配（原单位），查看数量/价格/金额差和来源余量。负单引用原正行，重复或超额阻塞整组。每个来源原行可带依据修订；复核仅记录判断不解除阻塞。

规则页可登记物料专属已批准的单位正因子和生效期，以及明确订单的批准价格版本。金额不换币种/金额单位，不默认税率或税额。未来来源单列，历史仍独立核对。没有适用单位因子不计算该组。

工作和底稿主动下载：完整JSON保留四原表、人工分配、修订、规则、复核、事件和基线，恢复从原始资料重算；无数据方案仅截止/精度/容差，不含范围依据、单据价格和物料换算规则，恢复清旧资料/基线/复核/事件且需重新确认。恢复取消保留旧工作。完整XLSX为31页签，包含参数/全部原行/余量/异常/复核/事件详情分块与比较基线。三原表和关联四类空白CSV、四类虚构CSV、多页签样例XLSX、完整样例JSON共11项可下载。

## 数据与边界

所有资料仅浏览器内存；关闭/确认退出/dispose清除，无上传、日志、遥测、外部请求或自动保存。只读静态值，不执行公式/缓存、宏或外链；10MB文件/工作、30MB实际解压、20000行/200列/10000字单元格上限。完整展开底稿60000行/20MB、文件10MB；工作含操作前后和比较基线同受10MB限制，超限保留旧工作并阻塞操作。请选择适当范围再另建工作，不丢弃历史。

不做采购审批、供应商门户、应付记账、付款、库存估价、税务抵扣、退款或AI/OCR。负单须同原单位、显式原正行和批准依据。Windows实机未验证；Mac使用headless Chrome完成实际file://候选测试，不宣称全平台验收。
