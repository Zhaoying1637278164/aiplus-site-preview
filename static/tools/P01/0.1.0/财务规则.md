# 采购三单核对财务规则

P01-2026-10-03.1，应用0.1.0。与React分离的纯计算；Decimal原始精度，输入最多6小数/24数字，乘法累计使用40位，显示精度0–6与数量/金额容差分开。源占用/负单上限不受容差放宽。

静态资料明示主体、供应商ID、物料、币种、数量单位、金额单位、含税口径和业务日；截止未来不计，不合范围不合并。订单需非负数量/价格/金额且数量×价格与静态金额差单列；收货/发票正量正额，零量只能零额，平均价格为未知。负单必须角色退货/红字、负量非正额、原正行ID、批准依据、同范围同单位且不早于原行；累计数量金额不超原单。价格变更采用截至日最新唯一已批准版本；不自动计算税额。

分配量/额填各来源原单位，符号与来源一致，每种来源累计分配数量/金额不得超过原单绝对值；多条正分配按订单分别累计后与订单数量比较，退货按原单显式关系回原订单且不得超原订单已分配量额。所有相连订单/来源/负单为一组，重复ID（先扫所有原行，含金额无效行）、超额、歧义、缺关联或不兼容阻塞整个组；不先来先占。未来分配单列，不占截止量。

单位规则只用于来源量→订单量，物料、from/to、有效起止、正因子、批准状态及依据均需完整；同日多个有效规则阻塞，即使因子一样。不换币种/金额单位/税额。分配原量额仍保留。

未交=订单量−净收量；票减收=净票量−净收量（正值为已票未收，负值为已收未票）；收/票各减订单量分开。预计订单额=订单量×生效价格；收/票金额差各与预计额比较；价格差=净金额−净转换量×生效价格，零量价格未知。原订单额与生效预计额同时保留，不能覆盖历史。

分配+未分配=原量/额，阻塞组分配视为未生效0并明确状态；未来及无效原行不补零。按主体供应商物料币种金额单位含税数量单位独立分组，正/负原单分别披露；不汇总不同数量单位。复核只记录依据不能解除阻塞；资料/规则改变清复核。版本基线保留原始表重算，仅同截止同规则和范围能比差额。

不覆盖：中国应付入账资格、税务抵扣、税额政策、采购审批、退款、付款、库存估价、AI/OCR。静态金额来自用户已确定范围，不提供默认税率。Windows实机未验证。

无数据方案仅保存截止/显示精度/容差，清范围依据、确认状态及业务专属换算/单据价格规则；无明细/基线/复核/事件。完整工作保存全部规则和原始资料。

参考单价=净金额÷净转换量；单价差=参考单价−生效订单价。Decimal40位除法，仅参考，不用于数量金额守恒；零净量均未知。价格差额用净金额−净量×生效订单价，单独保留原精度。
