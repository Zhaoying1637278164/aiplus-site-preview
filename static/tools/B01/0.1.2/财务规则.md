# B01 财务规则

应用0.1.1，规则B01-2026-10-04.1。适用企业内部月度预算，自2026-10-04起作为本工具计算规则有效，无税率或法定会计政策判断。输入的折旧/残值/工资附加率/付款比例只适用于用户确认的本次预算范围；不得当中国默认政策。

金额使用Decimal40位有效精度，输入最多6小数/24数字；逐行中间结果超过24整数位阻塞，显示货币两位HALF_UP。计算精度与勾稽容差分离；勾稽容差固定0.00，预算行最终金额先舍入、合计由明细相加，舍入差单列。空值不等零，未用参数空白允许，使用参数空白阻塞。收入、费用、人力、CAPEX为正向预算，负结果阻塞；人工负差额可用但最终金额不得负，红冲预算请通过合理净额模型自行确认。

同一预算仅一个币种和金额单位（元/千元/万元），每行必须一致；不换汇。期间为有效YYYY-MM，起止不超过36月，模型月必须范围内。未提交某月行不隐式生成预算：结果标该月行数，用户自行确认完整性。全局重复ID整组阻塞、保留双方源行。

方法：量价a×b；固定base；历史增幅base×(1+rate/100)；人力a×b×(1+rate/100)+c（a平均FTE，b单位月薪）；收入比例=当月调整后收入×rate/100；组合白名单四则表达式，变量a/b/c/base/rate，不执行代码和跨行引用。人力a允许小数FTE，CAPEX寿命正整数1–600，残值率0–100，付款比例0–100。费率可下降但不得低于−100。公式除零、未知变量、超深/超长结构阻塞对应行。

情景：先将逐行参数覆盖（理由必填），再乘a/b/c/base因子，rate加百分点。基准也是明确情景；情景ID固定、名称可改，首个base为比较基准。输入来自该预算行、覆盖、情景因子逐项可追溯。

调整：每条追加记录的情景、驱动ID、差额/替换、金额、理由、经办人、时间必填，依顺序应用；撤销仅改变active并增加操作记录。更换资料清旧调整，配置变更保留但重算校验悬空调整；不让人工绕过源行错误。先收入调整，后计算收入比例费用；先CAPEX调整再重算付款/折旧。

CAPEX：预算额×付款比例为本行同月现金支出假设，未支付额单列，无后续付款自动排程。净折旧基数=CAPEX最终额×(1−残值率/100)，从启用月按寿命直线月摊；前N−1期舍入两位，末期回收尾差，范围内和范围外折旧总和回勾基数。若最后期出现负尾差则阻塞该CAPEX，建议延长精度方案不在本版。启用月不得早于购置预算月；不计算历史资产或税额。

经营贡献=收入−费用−人力，折旧后贡献再扣当月折旧。CAPEX与付款另列，不直接扣进贡献。无毛利/EBITDA/净利润政策称谓。每情景/月/部门和明细汇总零差勾稽；正式结果底稿须无阻塞错误，诊断仍可导出。原始行、当前参数、规则版本、情景、调整前后、舍入差、异常均在底稿保留。
