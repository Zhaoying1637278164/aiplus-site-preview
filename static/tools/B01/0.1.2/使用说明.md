# B01 业务驱动预算

候选0.1.1。本款线程自测与候选交接不等于accepted，公开官网、正式版本和Windows实机由总控验收。

## 使用

解压离线候选后双击index.html，用Chrome/Edge打开，断网运行。先载入完全虚构样例，或进入范围与资料页，确认月度范围、币种和元/千元/万元单位，再导入UTF-8 CSV或静态XLSX，选择页签并对应模板字段后确认应用。

左侧13页分别管理范围、收入、费用、人力、CAPEX与折旧、情景、人工调整、结果、比较、异常、来源、底稿。每行一个预算月，缺月不隐式复制；模型可选量价、固定额、历史增幅、人力成本、费用收入比例和组合四则。算式变量a数量/FTE、b单价/月薪、c附加额、base基数、rate百分数；不支持任意代码或跨行循环。

情景按明确驱动假设设置，先覆盖行参数再应用因子。人工调整指定情景/驱动，填写经办人和理由，按顺序差额或替换，可撤销且历史保留。收入调整重算比例费用，CAPEX调整重算付款和折旧。不存在税率默认或会计政策结论；直线折旧、寿命、残值率、启用月、工资附加率和付款比例都是用户确认的测算假设。

检查勾稽与异常，无阻塞才下载正式预算明细/12页签底稿；诊断底稿始终可下载，保留被排除行与问题。原始行、参数、算式、舍入差、调整及版本可追查。经营贡献=收入−费用−人力，CAPEX不直接扣入贡献；折旧后贡献不等于净利润，未算税额、现金余额或全三表。

资料只在浏览器内存，无上传、日志、遥测、请求和默认保存。主动下载“含数据工作”保留原始资料、模型、情景、调整和留痕；“无数据配置”仅保留范围及情景因子，不含行覆盖/调整。恢复会替换当前工作并重算；更换驱动资料清旧调整、覆盖和留痕。清空/退出会清除内存。不要将未下载工作当作已保存。

## 限额

10MB单文件、30MB解压、200列、2000驱动、36个月、8情景、1000人工调整、4000留痕；明细/月度部门/全寿命折旧衍生合计60000行。方案和导出XLSX也限制10MB。公式、宏、外链、加密文件不支持；组合300字符/100项/12层。金额最多6小数/24数字、两位HALF_UP输出，明细后汇总，容差0.00。负预算阻塞，负调整可用但最终预算不得负。

## 源码构建

候选源码包包含锁文件、共享包、本工具源码/测试/说明/公开参考证据，不含node_modules或业务数据。Node22+与Python3.9+（独立预期测试只用标准库），在解压根目录执行npm ci、npm test、npm run typecheck、npm run build。候选构建接口scripts/build-candidate.ts只写B01证据，正式构建由总控使用主工程npm run build -- B01。
