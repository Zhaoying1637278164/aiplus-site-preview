# A02 资产台账与盘点 0.1.0

候选自测，正式打包和官网验收由总控执行。无需账户，下载后用Chrome/Edge打开index.html，断网可用。仅虚构样例，关闭/退出页面清空所有内存。

1. 新建盘点批次，填主体、账面期间、截止和盘点日期、币种金额单位、位置范围；一张卡片对应一件实物。
2. 资产台账、盘点记录、ID对应分别导入CSV/XLSX；多表需逐页签导入。可设置表头行和字段。换资料或规则令当前复核与选择失效，历史保留。
3. 盘点记录必须明确在场/未找到/待核实；无记录不等于未找到。同名不同ID不合并。标签需显式一对一对应。
4. 重复盘点写人员依据选择一条，所有原行可追查并撤销。记录ID重复、台账重复与映射歧义不能绕过。
5. 差异复核逐项记录人员/依据/结论；未盘/待核实/异常必须补齐资料后再复核。盘盈价值未知，盘亏显示账面净值供调查，均不自动记账。
6. 勾稽检查净值、覆盖和全部原行去向；全部完成才能确认批次。确认只是封存个人底稿，禁止修改；新批次复制参数不复制数据。
7. 保存含数据工作可恢复所有原行、决定与历史；无数据方案仅保存参数和字段，恢复后重新导入。恢复会替换当前工作，先下载留存。
8. 完整XLSX底稿12表，逐表CSV；模板三表和虚构样例均可下载。底稿本身不是恢复工作，使用JSON工作恢复。

只在浏览器内存读取计算导出，无上传、遥测、默认持久化、宏公式外链执行、自动更新、CDN或在线字体。单文件10MB、20000行、200列、单元格10000字，解压30MB/2000条目；30批次/60000历史资料行/每批20000事件，工作JSON10MB。金额十进制最多6小数及24数字；显示精度和容差分开，元/万元不换算、不换汇。

退出先主动下载工作；Mac Chromium候选实测见证据，Windows实机未验证。企业资产审批、扫码设备、云协作、自动会计处理不在范围。
