# A02 财务规则

版本 A02-2026-10-04.1；生效2026-10-04起，适用于用户指定单主体单账面期间、币种及金额单位的资产盘点准备底稿。确定性数据核对，无税率、资本化、损失计量、折旧或会计政策判断。依据：本项目共同口径 docs/finance-rules.md、用户授权任务及本款产品方案；ERPNext只参考对象分离，不沿用其会计分录或海外政策。

- 唯一键为主体＋资产ID结构化编码，名称不参与。ID保留前导零；只去首尾空格（显式参数），不改大小写。标签对应必须在本批次同范围内明确指定，禁止按相似名称合并；映射一对一，歧义阻塞。
- 台账截止期间为YYYY-MM，要求截止日同月；盘点起止在截止日之前。记录需同批次、主体、期间、币种、金额单位并在盘点起止区间。位置范围以账面位置筛台账，以实物位置筛无账面实物；已有账面ID搬迁到范围外仍展示位置变化。
- 一卡一件，不汇总数量。实盘在场=1，明确未找到=0；待核实/缺盘=null。差数仅已确定实盘减账面1；缺记录不产生-1。无账面在场为盘盈候选，价值未知；不是资产确认或审批结论。明确未找到为盘亏候选，展示账面净值供调查，不自动转为损失。
- 金额十进制最多6小数及24数字，Decimal40位；原值、累计折旧、减值不得负，净值=原值−累计折旧−减值且不得负。“账面净值”另与计算净值比较，容差为显式参数，空不等于零，必须有静态值。显示精度不改变精确合计。元/万元不换算，币种不换汇。
- 重复台账禁止合并；盘点记录ID重复禁止选择绕过。不同记录重复盘同一资产需人员依据选择一条，其余明确“重盘未采用”；撤销恢复阻塞。无效原行不得通过人工复核绕过。
- 每项复核仅为个人底稿记录。明确未盘、待核实、异常不能确认复核；其余可记录“认可分类”或“需后续处理”，留人员和依据。参数、字段或输入变化令当前决定失效，保留失效事件；历史批次完全保留。已确认批次不可编辑，不生成会计处理。
- 确认批次前要求有效台账、盘点、完整范围、每项已复核、无异常/待核实/未盘；只表示本地个人底稿已封存，企业审批另行进行。
- 合计只汇总有效同范围台账；异常、范围外、重盘未采用分别计数，全部源行有去向。总净值与分类净值之差=0；精确合计与逐卡舍入合计尾差单列。盘盈未知金额不填零。
- 方案 schema_version=1、应用/规则版本精确匹配；无数据仅参数字段，含数据保留所有批次、原行、对应、决定、事件及确认快照。恢复重新计算并验证复核/确认，禁止任意代码及公式。
