# C04 科目余额核查
应用 0.1.0，完整十一页财务流程。下载离线包并解压后，用 Chrome 或 Edge 双击本文件夹内 index.html；断网可用，无需账号或安装。官网及平台实际验收状态见项目 progress/STATUS.md；Windows 实机未验证。
打开本文件夹内 index.html，可完全断网运行。先载入完全虚构样例，预期四行勾稽0、两期三类借贷差额0、两条后期连续性0；首期无前期显示未执行。
CSV/XLSX静态资料，10MB/解压30MB/20000行/200列；选择页签和表头，再对应字段。正常方向来自资料列或配置，缺配置不猜测。六个金额必填非负，空不等于零，精度不自动舍入。主体期间币种单位分别核查。
只有同层级完整科目表可声明完整汇总；有效行小计不代表全账。父子科目不得重复汇总，工具不替用户决定科目层级。方向异常仅为复核线索，不保证账务正确，不自动记账，无AI/OCR。
资料只在浏览器内存，不上传不默认保存不执行宏公式外链。关闭清除；主动下载含数据工作或无数据方案，恢复有schema_version且版本核查。底稿八页均为静态文本。
开发：Node22+；npm ci；node --import tsx --test tools/C04-科目余额核查/tests/engine.test.ts；npx tsc -p tools/C04-科目余额核查/tsconfig.json --noEmit；node --import tsx tools/C04-科目余额核查/tests/build.ts。独立源码包提供四命令脚本。Mac及官网验证以验收证据为准，Windows未实机验证。
