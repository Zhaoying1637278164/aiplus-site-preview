# C04 财务规则
规则C04-2026-10-04.1，应用0.1.0；自2026-10-04本版生效。适用用户已确认的同层级余额表，非会计税务政策引擎，不自动记账、不保证账务正确。
依据：复式记账的借贷相等与余额代数恒等式（工具核对规则）；参考S01同期间口径及文档方法。正常方向和重要性来自用户配置，没有按科目编码猜政策。未确定方向则未执行方向检查。
1. 金额六列必填，空不等于零；非负借贷栏、最多用户指定0–6位小数、最多24位数字。Decimal精度40，禁止自动四舍五入。负数列为资料异常，不能悄然移到另一栏。
2. 主体、期间YYYY-MM(1900–9999)、币种、单位、科目编码、科目名必填。按主体/期间/币种/单位分组，不换汇不换单位；科目编码为文本。须声明同层级完整表才可给汇总结论；无法证明漏科目。
3. 相同主体/期间/币种/单位/科目重复全部阻塞，不合并不去重。分组有缺失、重复或金额无效时汇总状态未执行；未知分组的行使所有汇总未执行。显示有效行小计但禁止当完整账表总额。
4. 期初净额=期初借−期初贷；发生净额=发生借−发生贷；预计期末=期初净额+发生净额；差额=实际期末净额−预计期末。逐行独立，abs差额≤容差为容差内。借贷汇总分别检查期初/发生/期末差额，不代表每行正确。
5. 正常方向借/贷/不限/未设置。净额反向且abs净额>重要性阈值列复核线索；未设置为未执行。期初或期末借贷同时非零为展示范围复核线索，仍显示代数结果；发生借贷同时非零是正常交易汇总，不列异常。
6. 连续性按主体/币种/单位/科目相邻月份；期初净额与前期末净额比较。不启用则未执行；首期无前期资料未执行；中间缺月阻塞连续性，不跨月相抵。只覆盖导入的科目期间范围，不推断未导入的科目。
7. 来源保留文件、页签、原行号及六列原值；每行输出应用/规则版本、配置和异常。导出原值为文本，不执行公式/宏/外链。
