# B04 财务规则

规则B04-2026-10-04.1，应用0.1.1。适用于用户确认的预算期间，无法定计薪/税务政策判断。参数依据与适用期间由用户输入，未确认阻塞预算。虚构样例参数仅示范。

1. 单一预算范围起止月（最多36月）、币种、金额单位；每行须一致，不自动换汇/换单位；岗位有效日期与入离职包含当日。缺失非零；空离职表示持续，空调薪日期/金额必须成对；空岗无到岗日期表示待定，成本零并提示，实岗必填到岗日期。
2. 岗位组编制容量、计划人数非负整数，人数<=编制，最大10000。实岗人数与空岗计划人数分别统计，计划招聘到岗后为计划到岗人数而非已实现员工。编制在岗位有效期覆盖日计数；月末编制、实岗、计划到岗、未填编制分别显示。月内人数日/自然月天数为折算人数，与月末人数不同。年度不累加月末人数，人数日及人数月可累计。
3. 到离职/岗位有效期交集决定实际覆盖日。自然日折算：每段(月薪或月津贴/月奖金)*人数*覆盖日/自然月天数；整月预算：月内有覆盖即给整月、调薪以该月最后覆盖日月薪为准。用户明确选择，不猜测法定工作日。
4. 一次调薪在具体日期生效，允许正/负方向但新旧月薪均不得负。按自然日拆段；津贴/月奖金同计薪系数，非年度一次性奖金。福利附加=未舍入薪资*用户给定百分率/100；只以薪资为基数，不含津贴奖金，率0–1000%。不模拟社保基数/封顶/个税。零薪资、零率合法并提示；负薪资/津贴/奖金/率阻塞。
5. Decimal clone precision50；输入金额最多6位小数及24位数字，所有金额组件分别按用户选择0–6位小数HALF_UP舍入，总额=四个舍入组件之和；保存未舍入组件、组件舍入差合计，月度汇总加明细舍入金额，不对汇总再舍入。人数折算保留12位，不与金额混算。勾稽容差独立设置，不能绕过输入错误。
6. 重复岗位组ID全组阻塞，公式任何列不接受。无效日期、倒置时间、超过数量/期间限制、币种单位不符阻塞对应行，完整性提示不能把部分结果当完整预算。范围外日期不截改源数据。保留全部异常及有效行的零月记录。
7. 每个结果保留源文件/页签/行、组ID、参数与版本、覆盖日与调薪分段。调整保留原始行和修改记录；任何修改/换数据清复核。确认仅记录经办意见，不自动审批。导出全部结果而非筛选页，含无数据配置明确contains_data=false且不含岗位、人员、复核、操作记录；恢复严格校验结构版本并重算。
