# B04 编制与人工预算

候选0.1.1。本款自测与源码重建证据见验收证据，正式包装/官网由总控验收；未标accepted。仅使用完全虚构样例。

八页工作：预算总览 → 岗位计划/资料导入 → 薪酬假设 → 月度人数 → 人工预算 → 来源与复核 → 方案底稿。范围币种、单位和假设依据须明确确认。实岗和计划招聘分别统计；到离职包含当日。自然日折算与整月预算需选择，非工资实算或税法社保引擎。

候选离线包解压，Chrome/Edge打开index.html，不需账号或网络。成品无CDN、在线字体或外部请求。文件只在浏览器内存，不上传、不记录遥测或默认持久化。关闭/清空移除资料；使用“下载含数据工作”保存可恢复底稿，“下载无数据配置”仅保留范围及计薪配置。不同结构/应用/规则版本拒绝恢复。

导入UTF-8 CSV或静态XLSX，选择页签、映射全部19列、核对原始预览，再确认替换。可选离职/调薪列单元格可空；福利率、月薪、津贴、月奖金缺失不会补0。宏/公式/外链不执行且拒绝导入。最多1000岗位组、36月、组×月<=20000，单文件10MB、解压30MB、200列。超过边界拆分期间或部门，明确范围。

岗位组内日期和薪酬必须一致。一组按人数计划，不模拟员工逐人流动；跨组不会识别相同员工，用户须自行避免重复计划。一次调薪日期及新薪成对，多次调薪不在首版。福利=薪资×用户附加率，仅为预算；月奖金是月度假设，不是年度一次性奖金。年度不得累加月末人数。

缺失/重复/负值/无效日期/超编/混币种单位阻塞对应组，展示有效组的部分诊断，不能确认完整预算。源行、参数、版本、调薪分段和舍入差保留；修改/换数据清复核。全量底稿10张表与明细CSV不受筛选分页影响。
