# B02 预算实际差异分析

候选0.1.1，七页完整财务流程；本款tested候选交接，非正式发布或accepted。只处理用户选定预算版本和实际批次，不自动编造原因、连接ERP、审批、换汇、AI/OCR或自动入账。

## 使用

解压候选离线ZIP，用Mac Chrome/Edge打开index.html，断网可用。先体验完全虚构样例；确认可比范围，分别导入预算与实际CSV/XLSX，选择页签/表头/字段列，生成并确认组织科目映射与方向，计算差异，逐项复核重要差异，查看来源勾稽，下载完整底稿。

预算标准字段：记录ID、期间、组织、科目、金额、版本、币种、单位。实际以批次替代版本。月份YYYY-MM；金额静态十进制最多6位小数/24位数字，不含千分位；收入和费用分别配置增加/减少有利。不同ID同键汇总，同侧重复ID整组异常。数据缺失不补零，币种单位不一致不换算，零预算无百分比，负预算用绝对预算分母并标注。

用户文件仅浏览器内存；不上传、遥测、运行宏/公式/外链或默认保存。关闭即清空。每文件10MB，XLSX解压30MB，20000行/200列。保存工作由用户主动下载含数据JSON；无数据方案只含参数和映射（可含组织科目名称），不含金额、原始记录或复核原因。恢复将替换当前工作并重新计算；换资料或口径清除旧结果与复核。

## 输出

完整底稿10表：参数与版本、字段映射、组织映射、科目与方向、差异结果、重要差异复核、原始预算、原始实际、来源行分类、行数与金额勾稽。导出保留全量行和原值；结果、复核与来源每页50行，首页/上一页/页码/下一页/末页可达全部记录；可搜索任意列，结果可按责任组织和重要性/完整性筛选。尾部记录可逐行编辑复核或查看来源。人工原因/负责人/证据引用齐备才能标已复核；重要性仅是调查线索。
