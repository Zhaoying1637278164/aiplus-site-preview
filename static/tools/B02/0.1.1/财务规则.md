# B02 财务规则

应用0.1.1，规则B02-2026-10-04.1。2026-10-04起适用本款管理预算比较，不作为会计、税务或业绩考核政策。用户须确认核算基础/含税口径/主体范围可比；未确认不计算。本款无海外政策默认值。

- 比较键：期间（月）、共同责任组织、共同科目，限定相同币种、单位；预算版本与实际批次分别显式筛选。范围外保留原始行但不纳入分析。
- 差额=实际−预算。正预算差异率=差额÷预算×100；负预算=差额÷|预算|×100，标明该口径；零预算（包括0对0）差异率为空，不作0%。汇总先加金额，再计算比率；不平均逐行百分比。
- 收入默认增加有利，费用默认减少有利；其他项须用户明确方向，可选择中性。负预算也按配置方向判断，不能仅按差异率正负判有利。未出现的一侧为空，不能补零。
- 金额Decimal，最多6位小数/24位数字；内部40位有效精度，未对金额舍入。百分比展示6位小数，重要性按未舍入值判断。金额容差独立；绝对差额≤容差标一致，否则判有利/不利/中性。重要差异=超过容差且（绝对金额≥金额阈值或绝对百分比≥百分比阈值）。阈值和容差非负；零预算只按金额阈值。
- 侧内记录ID重复：同一ID所有行异常，避免重复计入。不同ID同键为明细汇总。组织/科目映射多对一允许；同侧同原编码映射重复为配置错误，不能计算。共同科目的性质/有利方向冲突为配置错误。
- 必填空值、公式、非法期间、非法金额、未映射、币种单位不符为异常；先验证行再筛范围，不允许损坏数据被范围外静默隐藏。某键存在可识别异常，该键有效行标为“相关行异常”不作完整比较；无法识别键的异常明确全局不完整，结果不能作完整分析。
- 每个来源行分类恰好一次：已汇总（对应结果键）/范围外/异常。每侧行数守恒；每组预算+差额=实际。单边缺失、相关异常和全局异常保留；无完整分析声明。
- 原因、证据引用、负责人和行动只接受用户输入。标已复核须前三项齐备。任何资料/口径/映射修改清除计算结果和复核，恢复工作重新计算而不信任JSON里预存结果。

依据：S01具体固定版variance-analysis的总差额、重要性调查与预算实际比较方法仅作参考；零负预算、缺失、方向、行分类、数据边界和复核闭环为本项目明确规则。S01阈值示例不是中国默认政策，本款示例参数仅为虚构练习。
