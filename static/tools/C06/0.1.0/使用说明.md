# C06 总账明细账对账

应用 0.1.0，完整八页财务流程。下载离线包并解压后，用 Chrome 或 Edge 双击本文件夹内 index.html；断网可用，无需账号或安装。官网及平台实际验收状态见项目 progress/STATUS.md；Windows 实机未验证。

## 用法

解压离线包，以Chrome/Edge双击index.html，断网可运行。先载入完全虚构样例；三类资料分别导入xlsx/UTF8 CSV、选择页签表头并确认使用；按原列对应标准字段。指定组织/科目/期间映射及是否允许未映射原值沿用，再设置范围、辅助粒度和容差。按本口径核对；查看逐项差额与两侧勾稽，选组查看全部原行；记录编制/复核说明，下载十表底稿及含/无数据方案。退出或关闭即清空内存。

总账余额表每统一粒度一行；明细流水每行ID一笔借贷发生；辅助余额每完整辅助粒度一行期初期末。期初借方、期初贷方、本期借方、本期贷方、期末借方、期末贷方必须明确提供，不把空/缺记录补零。余额借正贷负，发生额先汇总再比较；差额=总账−明细。即使金额一致也不是原账正确性保证。

用户资料只在浏览器内存，无上传、日志、遥测或默认保存，不执行宏/公式/外链/用户代码。文件/方案≤10MiB，xlsx解压≤30MiB，每表≤20000行/200列，单元格≤10000字。含数据方案明确包含原始材料；无数据方案恢复清旧资料。换资料/规则清旧结果与复核。未实现AI/OCR，不自动记账或换汇。
