# C06 财务规则

规则C06-2026-10-04.1；适用：用户已确认的月度同口径余额表、流水、辅助余额。2026-10-04起应用技术规则，非会计税务政策。依据=用户任务粒度/不可调平要求与具体参考同期间控制总额方法；账户性质、数据完整性由财务复核。

1. 借方余额为正、贷方余额为负；各表用期初借方/期初贷方与期末借方/期末贷方列，余额借贷不得负、不得同一行双边非零。本期借方/贷方允许负数冲销但提示复核，不反转方向。不自动判科目正常方向。
2. 期初净额=期初借−期初贷；期末净额=期末借−期末贷。勾稽残差=期初净额+本期借−本期贷−期末净额。两侧单独核验，残差绝对值超过明确容差即异常；在容差内但非零也保留残差。
3. 统一粒度包含组织/科目/期间/币种/单位，可额外含辅助维度。三类资料先按显式映射转换，流水先合计发生额、余额先合计净额，再与总账比较。币种单位期间永不跨组，不自动换汇/单位折算。
4. 总账同目标粒度重复阻塞，辅助余额同完整辅助粒度重复阻塞，流水行ID在原组织期间内重复阻塞。多个原科目映射为同一科目导致总账重复时不静默聚合。存在原始键不可确定的坏行，全局阻塞；有键坏行阻塞本组，保留每一原行。
5. 缺流水则借贷发生未核对；缺辅助余额则期初期末未核对；缺总账侧则总账未核对。缺数不补零，显示null，不计算不存在的差额。无业务发生也须提供显式零行；工具不证明文件完整性。
6. 差额均=总账−明细，分别期初净额、本期借、本期贷、期末净额，保留两侧全部组成和勾稽。总额相抵不能替代逐组结论；差额有数仅用于复核，不自动生成调整/确认正确。
7. 金额6位小数、最多24数字，Decimal precision40；显示保留原计算值，不四舍五入。容差独立参数≥0且最多6位小数。精度不是容差；0与空区别明确。
8. 映射原组织/科目/期间按资料侧设定，完全相等匹配。可明确允许未映射原值沿用；关掉即必须逐项映射。多目标/空目标阻塞不猜。范围外逐行列示不丢弃；排除的组织科目用精确值列表。
9. 复核记录只能解释差异，不能覆盖数值或异常。换资料/规则清空复核；恢复含数据方案重算，版本/字段/类型/上限严格校验。底稿保留源文件/页签/原始行、映射后键、参数版本与问题。

数值单元格最多15数字，超过须提供原始十进制文本，不把已丢失的Excel数字精度当准确原额。
