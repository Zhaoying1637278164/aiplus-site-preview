# E04 财务规则

依据：用户明确要求的内部测算口径；本工具不是中国劳动报酬、税务或会计政策判定器。企业规则须填依据、适用计划、币种、单位及生效起止日。虚构政策有效期2026-01-01至2026-12-31；不可作为企业默认政策。

1. 粒度为员工ID×期间YYYY-MM×计划ID×币种×单位。业绩与回款分别汇总，不混用，不自动换汇。业绩/回款列两者均必填（无值填显式0）；重复记录ID整组阻塞对应个人，不去重猜测。计划ID关联规则，整个月必须被唯一规则覆盖；中途变更或重叠阻塞，需另行确定分期规则。
2. 档位从0开始连续且最后上限空表示无穷，最多30档；比例为百分数0–100，固定奖金非负。边界为(下限,上限]，0命中首档但奖金为0。负业绩行只有规则选择“净额冲减”时允许；净基数仍须非负，负净额不按绝对值猜测。历史支付冲回通过调整表单独负额处理。
3. 累进：每段max(0,min(净基数,上限)−下限)×比例/100。全额：净基数×最高命中档比例/100。在同一基数上比较两种算法，不默认为等价。
4. 固定奖金为最高命中档一次性奖金，非各档累计，零基数无奖金。规则额=未舍入提成合计+奖金，最后一次ROUND_HALF_UP到用户精度0–6位。每段展示12位，段展示舍入不是最终计算依据；独立列出总舍入差额。
5. 封顶空为无限制，0为零上限；限制规则额（含档位奖金），随后加已复核调整，调整可突破封顶。封顶、业绩、调整和奖金必须适配选定金额精度，否则阻塞；币种单位不一致不能关联。容差只标识勾稽异常，不改变计算、规则覆盖或档位。
6. 调整类型“奖金”只允许非负；“调整”允许有符号；“冲回”须非正且有原支付ID。同一原支付ID同一人员不能重复冲回；不得自行推算可冲回余额。金额、理由、依据、制单人、复核人、复核日必填，复核人须不同，状态“已复核”才生效。非已复核阻塞对应个人；不声称这是企业在线审批。最终负测算额须规则显式允许，否则阻塞。
7. 不可量化金额不补零。个人阻塞时不给可支付金额，明确未计算；范围合计只涵盖成功测算个人，并列阻塞数量。规则额−封顶扣减+已复核调整=最终测算额，残差严格为0。
8. 没有业绩组的孤立调整为异常，不造员工；无资料不生成零工资单。每个结果保留参与原始行、规则及档位来源、调整来源、应用版本与规则版本。
