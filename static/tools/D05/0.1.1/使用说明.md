# D05 财务表格公式检查

应用 0.1.1。下载离线包并解压后，用 Chrome 或 Edge 双击本文件夹内 index.html；无需安装，断网可用。源码包包含锁文件、共享包、本款源码、测试、参考许可和构建说明；官网实际验收状态见项目 progress/STATUS.md。Windows 实机未验证。

导入本机XLSX，选择页签和A1范围，静态定位原公式、引用关系、缓存错误、相对模式差异、硬编码候选与循环路径，下载完整检查底稿。七页工作：工作簿、检查范围、问题定位、模式复核、来源追查、检查底稿、方案管理。

使用：打开本文件夹内 index.html（Chrome/Edge；断网file://可运行），先体验完全虚构样例或导入自己的XLSX，再在检查范围页开始。每页50项，所有问题、公式和原格可翻页。追查可见文件/页签/原格、原公式、缓存状态和引用；空格不补零。逐项忽略需要依据，支持撤销，完整底稿保留忽略项。

下载完整底稿XLSX含七张表，所有公式写为文本，不执行。完整报告JSON与含数据工作含财务资料，需主动下载并妥善保管。无数据方案不含原格、缓存及忽略依据；恢复后在检查范围页“导入并套用方案”，页签名须匹配。换入新工作簿清除旧范围、结果和忽略。关闭/清除/宿主退出释放浏览器内存；无默认持久化、上传、遥测、CDN、在线字体、外部请求。

单文件10MB，解压30MB；30页签，每页20000行200列，总100000格，数组公式主格最多1000个；公式/文本10000字符；恢复JSON20MB。宏、密码、XLS/XLSM、嵌入对象拒绝。外链部件只读作静态资料，不访问外部地址。

不重算公式、不自动修复、不承诺Excel全部语法或计算引擎。不做报表平衡、币种/单位/期间自动核验。名称、结构化、3D、整行整列、动态/溢出引用列覆盖不足；循环检查仅覆盖可解析A1依赖，超过20万边或100万范围扫描次时明确未执行。少于三公式或无严格多数不标模式差异；正常小计/特殊行和硬编码可能合理。

平台和官网验证证据见项目 progress/STATUS.md；Windows 实机未验证。

同版本源码包含锁文件、共享包、工具源码/测试/参考许可和构建说明，不含node_modules或真实业务资料。解压源码后依次运行 `npm ci`、`npm test`、`npm run typecheck`、`npm run build -- D05` 重建；见 docs/source-build.md。[参考来源](参考来源.md) · [财务规则](财务规则.md) · 规格与独立预期见源码包本款目录 · 实际验收证据见项目 progress/STATUS.md
