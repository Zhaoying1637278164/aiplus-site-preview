# D05 财务规则 · D05-2026-10-04.1

适用：2026-10-04起本工具0.1.0的浏览器静态XLSX复核。方法依据ExcelJS4.4.0公式/共享/数组章节与S25 audit-xls Step2/4，见参考来源；自主实现。没有采用海外会计、税务或行业阈值。

1. 只读公式和保存的缓存。缺少缓存≠零；零、负值、false、空字符串、错误类型单独保留。金额原XML字符串保留，不汇总、不运算、不换汇；精度/容差无需设置。财务期间、币种、单位由原表保留，不自动判断一致。
2. 原错误单元格、公式正文#REF!、错误类型缓存与不存在的引用页签：记录原文件证据，不声称重算结果。字符串常量中的#REF!不是公式断裂。
3. 引用解析：A1、绝对/混合引用、普通页签/带空格及转义页签、A1范围、外部文件引用。大小写不同的内部页签按原名定位。共享公式用ExcelJS平移后检查，并保留主格。数组主格范围与输出原格保留，不把输出值当硬编码。
4. 模式：所选范围内同列逐行或同行逐列，比较相对R/C偏移、绝对坐标、页签、函数、数字、字符串。至少3个可解析公式，严格多数模式至少2个才标少数差异。范围外公式不参与多数判断。未识别语法不参与模式判定。
5. 硬编码：所选范围与配置硬编码范围交集内，数值原格夹在两个相同相对模式公式之间才列候选；空、文本、合并格和数组输出排除。数值0和负值与其他数值一致适用。公式数字常数只列复核线索，不自动判断合理性。
6. 静态循环：在整个工作簿已识别A1公式依赖图上分析强连通分量；仅报告范围内位于循环中的格，指向循环但自身不成环不误报。有意迭代可能合理，本工具不迭代。最多20万边/100万范围扫描次，超限明确“循环检查未执行”。名称、动态、结构化、整行整列、3D和溢出引用不完整，不能据此证明无循环。
7. 外链仅标记源公式与目标文本，外部XML不得拉取文件。缺失原格/导入范围外不是错误，也不补零；已识别不存在的页签单列。隐藏公式提示原状态。
8. 忽略需逐项依据，保留问题键、来源与理由；不删除证据。规则变化、换数据清旧结果和忽略。含数据恢复按相同schema/应用/规则版本重新检查；无数据方案排除工作簿和忽略，需重新套用文件。
9. 导出包含全量结果和全部原格（含检查范围外），不受UI筛选影响，公式为纯文本。发现问题不是财务错误保证，未发现问题也不是报表正确性保证。不自动修复原文件。
