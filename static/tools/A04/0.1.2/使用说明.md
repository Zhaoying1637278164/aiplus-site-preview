# A04 租赁测算底稿

返修候选0.1.1。仅供总控独立验收，尚未官网发布或accepted。解压成品后用Chrome/Edge双击index.html，断网可用，无需账号。Windows实机未验证。

## 使用流程

1. 先体验完全虚构样例。九页导航对应导入、合同、付款、折现、现值、负债、变更和底稿。
2. 下载合同空白模板与付款模板，填写静态值。导入CSV或XLSX，选择页签和表头，确认每个字段映射。合同和付款分别导入；同一XLSX的两页可分别选择。
3. 核实合同期限、币种单位、期初/期末/逐日模式，确认中国新租赁准则适用、税费已分拆且无复杂条件。期初付款日等于归属期开始日，期末等于结束日；任意明确实际日期用逐日。
4. 输入已确定年利率（百分数）、内含/增量借款类别和具体依据，明确有效/名义年率、实际/365或实际/360、名义率复利频率1/2/4/12并确认口径。示例利率仅虚构演示，不是建议。
5. 核对开始日已付与初始未付负债，逐笔现值和逐期利息/付款/余额；币种单位不混加。内部80位十进制，显示精度与容差分别设置，尾差不隐藏。
6. 若比较固定未来付款，先冻结原计划，复核截至指定日期（含当天付款）的真实历史，填写复核人及依据。再修改未来付款或新已确定利率；历史修改、期限/范围等复杂变更显示阻塞。结果只为测算，不自动形成会计调整。
7. 在异常与底稿下载完整18表XLSX或选页CSV。保存“含数据完整工作”可恢复原始与工作数据、原计划、历史确认、映射和规则并重算；“无数据方案”只保存映射/精度/容差，不含合同利率及数据。
8. 退出需确认并清空内存，关闭页面同样清除；未主动下载的工作丢失。换入资料会清原计划和历史，避免沿用旧确认。

## 输入字段与限制

合同：租约ID、合同名称、开始日、结束日、币种、单位、付款模式、年利率百分数、利率类别、利率依据、利率口径、日数基础、计息频率、适用确认、税费分拆确认、折现口径确认、复杂条件。付款：付款ID、租约ID、付款日、金额、币种、单位、归属期开始/结束、支付状态。金额最多6位小数，日期YYYY-MM-DD；单位元/千元/万元；币种三位大写代码；开始日已付仅开始日发生，其余为未付。

输入每文件10MB、恢复工作JSON10MB（导出前校验，超限须缩小批次）、解压30MB、20000行、200列、单格10000字符。仅UTF-8 CSV和静态XLSX，不支持XLS/XLSM/加密文件。宏/外链拒绝，公式不执行。空值不补零、负付款不作为退款直接算、重复ID整组阻塞；零金额保留并提示；无法分配的异常保守阻塞所有结果。

## 边界

仅已确定的承租人固定净付款。分类、税费、增量借款利率由用户判断。豁免、指数/利率重估、可变租金、选择权、担保余值、范围/期限变更、首次执行、减值等复杂条件不支持。没有使用权资产或折旧功能；第16条初始成本不能由负债现值直接代替。无上传、遥测、外部请求、自动更新或默认存储。政策及算法详见财务规则与参考来源。
