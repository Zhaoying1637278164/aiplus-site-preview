# A04财务规则 · A04-2026-10-04.1

依据：财政部2018修订《企业会计准则第21号——租赁》第14、16—18、23、25—29条及财会〔2018〕35号；原链接与具体章节见参考来源。其他执行企业会计准则企业2021-01-01起适用；特定境内外上市企业2019-01-01起。用户须确认本合同适用新准则且不适用豁免，并提供固定付款净额、税费分拆、已确定利率和依据。缺少确认即阻塞该合同。

## 计量算法

每合同单币种及单位，不换汇不跨币种混加。金额最多6位小数，内部Decimal80有效位；输出金额精度0—6位HALF_UP。容差独立0—1本单位，只用于勾稽/历史对照，不改变计算、不把空当零。年利率输入百分数0—100且必须有来源类型（内含或增量借款）和依据，不猜利率。

日数基础实际/365或实际/360，区间取(end-start)实际日数、不含起日包含终日。有效年利率：累积因子G(a,b)=(1+r)^[(b-a)/basis]；名义年利率：G=(1+r/m)^[m*(b-a)/basis]，m=1/2/4/12。分数幂表示固定复利曲线，非单利；该算法须经用户确认，是底稿的计量口径而非准则指定默认。频率仅对名义年率换算起作用。

PV_i=付款_i/G(租赁开始日,付款日)。开始日已付款必须恰好在开始日，PV单列且排除未付初始负债；开始日未付仍纳入负债，付款时计零利息。期初付款日=归属期开始日；期末付款日=归属期结束日；逐日按明确付款日。付款归属期必须在合同期内、结束不早于开始；付款日也须在合同期内。付款ID全表唯一，重复整组阻塞所属合同；同日不同ID可多笔，按ID稳定排序。

L0=所有未付PV之和。按付款日排序逐笔：I=Lprev*(G(prevDate,date)-1)，L=Lprev+I-payment。展示期初/利息/付款/期末分别按精度舍入；展示勾稽尾差=展示期末-(展示期初+展示利息-展示付款)。内部残余及累计利息保留，绝不为了归零隐藏尾差或改现金流。精确末余额保留原始分数幂计算残余，不强制调零。只按付款事件列期，非月度总账结息分录。

## 变更比较

原计划需所有合同与付款无阻塞才可冻结；保存原数据、映射、规则与结果重新计算。历史截止日不得早于合同开始或晚于结束，历史含截止日付款（付款后时点）。确认须复核人/依据；原历史与当前历史逐笔相同，否则阻塞比较，不能静默修改已确认记录。合同币种单位/期限/付款模式/政策/基础和频率须与基线一致；允许新未来付款与明确的新利率及依据。

原截止余额用未舍入原计划最后一次付款后余额滚动到截止日；无未付历史时从L0开始。原未来现值以原利率折现到截止日；新未来现值以当前利率折现。展示旧余额、原未来PV、新未来PV、差额及剩余新排程；差额只是测算，非自动分录或会计变更认定。原新已付款历史不能编辑绕过。重新导入资料/字段映射清空原计划和确认；直接编辑历史留基线但比较显示阻塞。

## 明确阻塞

复杂条件不为“无”、适用确认非“是”、税费分拆确认非“是”、折现口径确认非“是”、缺利率依据、负额、空值、非法日期、错币种单位、重复ID及孤立付款均有异常；无法分配到合同的异常保守阻塞全部结果，避免缺失现金流后出具不完整负债。可变付款/指数或利率重估/选择权/担保余值/豁免/独立租赁/范围缩小/期限改变/首次执行须专业处理。本款不计算使用权资产与折旧；第16条初始直接费、预付/激励及复原成本不能被负债现值替代。税费/分类/增量借款利率始终由用户确定。
