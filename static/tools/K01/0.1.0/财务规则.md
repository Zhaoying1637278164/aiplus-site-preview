# K01 财务规则

应用0.1.0，规则K01-2026-10-04.1。确定性管理成本底稿，无税率或中国/海外会计政策默认判断。依据为用户在每成本/动因/池规则输入的已确认业务依据；适用条件是同主体、期间、币种、金额单位，规则生效期由用户参数明确保存，期间超限阻断。

金额经公共Decimal解析，最多6位小数/24位数字；精度0–6由用户配置，来源超精度阻断，容差独立且非负。直接归属按来源金额；间接按池/对象动因，单笔金额×动因/有效动因合计，先半入舍到精度，再把差额给末对象或最大动因对象（并列对象ID字典序首位）。对象按ID排序，池规则按顺序运行；不产生循环或使用分摊结果当新动因。

负成本默认阻断；用户确认红冲后保留负号按同一动因分配，不取绝对值。负动因始终阻断。空金额、空动因不当零。零分母只允许阻断整次或留未分配；不等额替代。等权须显式选定并填写业务依据，不是零分母的后备。

每成本来源金额=直接+分摊+排除+未分配。排除成本需理由，排除动因需理由；停用对象不得承接直接成本，其动因列入不参与明细。缺规则/依据/有效动因列未分配。任何重复/格式/范围错误阻断运行，无部分成功输出。各币种/单位禁止混加；换汇和单位转换由用户在外部形成确定且可追溯资料。

输入参数、来源原行、规则版本、分配比例、未舍入值、舍入值、尾差调整、异常和逐池勾稽完整导出；导出不是可入账凭证。

尾差防变号：先给配置顺序的正动因对象，如调整将使其金额与来源异号，该对象最多调至零，剩余尾差按末ID倒序/最大动因降序继续承担；零动因不接尾差。每对象调整单列。例0.05、十对象等权半入为每人0.01，总尾差-0.05，末五对象各减0.01至零，前五各0.01；不产生负成本。
