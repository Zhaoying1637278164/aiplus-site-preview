# K01 成本分摊表

应用0.1.0，规则K01-2026-10-04.1：同主体、期间、币种、单位的成本归集、直接归属、对象和动因分配、尾差、勾稽与来源底稿。官网在「成本」模块打开「成本分摊表」详情，点击「开始成本分摊」即可同站使用。

解压离线包，用Chrome或Edge双击index.html，无账号、网络或安装要求。按八个业务页操作：成本归集（确定范围与四表导入）→直接归属→成本对象→分摊动因→分配规则→运行复核→来源明细→方案与底稿。可体验完全虚构样例，A总成本145、B75，排除10，来源230。

四表可独立UTF-8 CSV或XLSX导入；标准四表工作簿页签为成本、对象、动因、规则。页签、表头行和字段对应可配置；原始资料不改写，页面修订单独记录。各表可新增手工行。模板与虚构四表均可下载。

方式只接受直接/分摊/排除；对象启用填是/否；规则方法填动因/等权，顺序非负整数，依据由财务确认。金额最多6位小数，输出精度0–6，超精度源金额阻断。红冲默认阻断，确认后保留负号。动因不负，空不等于零。零分母留未分配或阻断；缺依据不强分。尾差优先末ID正动因对象或最大动因对象，并列首ID；防变号时按配置顺序继续承担。来源=直接+分摊+排除+未分配。

资料仅在浏览器内存处理，关闭/退出/清除即释放，无上传、日志、遥测、默认保存或外部请求。单文件10MB、解压30MB、20000行、200列；分配明细100000行。公式、宏、外链和用户代码不执行。每次资料/参数变化清旧结果。

无数据方案保存范围与策略；含数据工作保存四表/字段对应/修订。JSON带schema_version及应用/规则版本，恢复替换旧资料并重新计算。版本不兼容阻断。含数据下载须自行保管。完整XLSX底稿16页，分配CSV及含数据运行证据JSON可下载；金额以十进制文本输出。

不做循环分摊、多层BOM、存货计价、自动换汇、政策判断、AI/OCR或自动入账。财务人员须复核依据、未分配和排除项。Windows实机未验证。
