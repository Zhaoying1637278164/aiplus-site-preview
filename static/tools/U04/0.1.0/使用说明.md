# U04 内控检查底稿

候选0.1.0：本机个人检查记录。七页依次完成范围周期、清单要求、事实、人工评价、问题整改、证据索引、方案底稿。原官网“审计内控”模块列表/详情使用完整同站程序；集成由总控完成，本款不声明官网已发布。

下载候选离线ZIP并解压，用Chrome/Edge双击index.html。无需安装、账户、API Key，断网运行。用户文件只在浏览器内存；关闭、退出或清空会删除，需主动下载本地方案。

1. 先体验完全虚构样例，或填检查主体、周期、日期范围、依据/版本/生效日/适用条件。
2. 导入UTF-8 CSV或XLSX（2MB以内），选择页签、预览并确认替换；最多500条。八个必需字段见空白模板。公式/宏不执行，公式单元格阻止导入；公共解压30MB/200列上限。
3. 分别填写事实和人工评价。事实、清单或范围变更后原评价清空，已关闭整改改为待复核。编辑字段后须按对应保存按钮，范围自动应用。导航/选择检查项前保存；未保存编辑离开会弹出确认。
4. 关联本机PDF/PNG/JPG/TXT/CSV，单份2MB、最多100份、合计10MB。证据保留原始字节/SHA，不渲染或运行内容；同项同内容禁止重复。重新关联缺失证据必须字节和SHA相同。
5. 记录问题、整改措施、责任人和截止日；关闭须有结果、复核人、日期和本项可用证据。“资料完整”仅表示记录完整，不给控制有效性结论。
6. 主动下载方案：仅范围清单；工作数据与索引；工作数据与证据原始内容（须主动勾选）。不含证据方案恢复后明确显示内容缺失。方案schema_version=1，严格字段/版本/大小/SHA校验，损坏时不替换现有工作。方案最大20MB。
7. 下载完整七表XLSX底稿或清单CSV，导出含全部记录及來源、参数、版本、未完成事项，分页/筛选不截断。含用户数据文件自行保管。

本工具不等于企业GRC、SOX认证或独立鉴证，无企业审批、多人协作、AI、OCR、自动审计保证或送达功能。涉及金额的观察文字不参与金额汇总、换汇或会计处理。

源码候选包含锁文件、共享包、本款源、测试、构建脚本、第三方通知；在源码根运行Node22+：npm ci；npm test；npm run typecheck；npm run build -- U04。候选构建写本款candidate目录。正式打包、目录登记、官网及独立验收由总控负责。Mac Chromium本款证据见验收证据.md；Windows实机未验证。
