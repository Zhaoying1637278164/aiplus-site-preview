# U04 财务规则

规则U04-local-1，应用0.1.0，2026-10-04生效，仅个人检查记录的完整性检验，不是法规或控制有效性判断。

- 主体、检查周期、起止日、范围与目标、用户填写依据及版本、生效日和适用条件必须明确。程序不内置中国/海外监管结论。中国法规适用性由用户另行确认；无法确认不应形成评价。
- 检查ID唯一，事项、检查程序、证据要求及周期完整。周期逐项与范围精确一致；不自动跨期，执行日在范围内。缺失不是零；字符串0为原文，负数原文不用于运算。无金额计算/币种单位变换，含金额观察须在文字中保留用户原币种、单位和期间。
- 事实、执行人、执行日期与人工评价、依据、复核人、复核日分别存储/展示/导出。复核不能早于执行日。“未评价”“待补证”不算资料完整；“未发现例外”不掩盖缺失资料；“不适用”须有依据和复核，作为人工判断单列，不代表有效性通过。
- 非不适用项须关联本项可用证据。证据引用归属、SHA与字节数可验证；内容缺失及引用丢失逐项提示。“发现问题”必须有问题整改登记，但登记或关闭不自动改写人工评价。
- 整改关闭：措施、责任人、截止日、结果、复核人/日及本项可用证据均具备，才允许保存已关闭状态；其余状态仍可暂存并列为未完成。
- 范围变更清空人工评价并让已关闭整改回到待复核；事实/清单变更重置本项评价；增删证据保守重置评价。恢复仅含索引的方案保留原人工评价记录，但缺失证据阻塞资料完整标记。不是自动判定控制有效性。
- 留存原文件/页签/行号/原字段，清单编辑不改原始来源；清单模板方案不带原始额外字段或事实。全部导出含当前参数、版本、来源、异常与完整性覆盖计数。

参考方法依据：固定audit-support文档中的底稿字段/证据要求；不采用其中SOX分类、阈值或审计判断。上述是本款自行制定完整性规则，实际审计政策须由用户确认。
