# D01 财务与整理规则

应用0.1.0；规则D01-2026-10-04.1；生效2026-10-04。依据为本款任务入口、AGENTS.md和编码前规格，适用于用户主动确认的本机台账整理，不作为任何法定会计、税务或审计政策。

- 合并是按资料槽及原行顺序追加记录，不做JOIN、金额汇总、会计合并或自动换汇。币种、单位、期间原值保留，需统一口径时由用户提供已转换的静态来源。
- 目标列名称、类型、必填、源列映射必须显式可见。未对应必填列阻塞本次处理；未对应可选列为空，原始未映射列保留于来源JSON。
- 文本按逐列显式规则去首尾空格、折叠连续空白为一个空格、转换大小写；不擅自纠正部门、科目或客户名称。
- 金额使用锁定Decimal.js 10.6.0经本款独立测试验证，24位数字且最多6小数，不含千分位或括号；不作舍入，不设容差，不汇总。超安全精度的数值单元格异常，需文本提供精确原数。空值不补零，零、负值有效。
- 日期仅接受1900年及之后的有效YYYY-MM-DD。期间文本不推断年度或财政年度。
- 公式/错误单元格不执行、不采用缓存，目标字段为异常并保留原始公式标记。未映射公式只在原始来源保留；程序没有重算能力。
- 先类型/必填及键完整性核验，再检查有效候选的重复键。同键异值整组异常；完全相同目标值可以显式移出后续行并指向首行。类型异常行不参与重复比较。
- 目标列全空只有显式启用空行移出才移出。原行与原因保留；CSV末尾空记录在读取器定义的数据范围外，内嵌空行不丢弃。只含空行、没有数据行的页签不作有效资料。
- 分拆是有效记录按所选目标字段值组合分组，JSON数组键避免分隔符碰撞。键缺值行异常，最多100组；未选键时一个有效组。无有效行时0组，异常底稿仍可导出。
- 输入 = 有效 + 异常 + 重复移出 + 空行移出，互斥且逐行可追查；分拆组行数之和 = 有效行数。不跨币种/期间作金额合计或因果判断。
- 原始行、文件、页签、行号、来源槽ID、目标值、变化、参数、应用/规则版本、分类及重复首行必须在底稿保留。所有设置或资料改变使结果失效。下载只使用当前已预览的完整结果，不受列表筛选影响。
- 无数据方案schema_version=1、contains_data=false，只含配置；拒绝未知版本、含数据标记和额外非配置属性。恢复清空旧资料，不能用旧结果替代新计算。

未知中国政策不自动补充。本款没有税率、会计估计或自动入账功能，没有AI/OCR。正式发布、官网同包验证及Windows实机由总控另验。
