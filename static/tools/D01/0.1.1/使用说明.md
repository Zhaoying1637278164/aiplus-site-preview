# D01 财务台账合并拆分

候选0.1.0，2026-10-04。本线程自测tested，尚未正式打包、官网发布或accepted。Mac本机Chrome断网file://已实际运行，Windows实机未验证。

## 使用

打开候选 `progress/evidence/D01/0.1.0/candidate/index.html`。七页导航依次完成：资料清单 → 字段对应 → 清理规则 → 合并预览 → 分拆下载；来源追查和方案管理可随时使用。

1. 先体验九行完全虚构样例。默认样例答案：9行 = 有效4 + 异常3 + 重复移出2。
2. 添加本机UTF-8 CSV或XLSX。每资料槽只处理当前所选页签，页签和表头行可切换；其他页签不自动处理。最多20槽。更换资料先使旧预览失效，错误文件仍列在清单，须修正或显式移除。
3. 目标列可以删除、添加，配置文本/金额/日期及必填；每槽选择源列。初次导入只为同名列填入对应，异名列需自行选择。未采用列仍在原始JSON中。
4. 设置去首尾空格、连续空白折叠、大小写；指定重复复合键。默认保留所有同值重复。启用移出时只移出完全相同目标值的后续行；同键异值整组异常，不按首行强选。
5. 生成预览，核对输入 = 有效 + 异常 + 重复移出 + 空行移出。所有列表50行分页，筛选不改变导出范围。异常与移出行保留在完整底稿。
6. 指定分拆复合键与安全文件名前缀，更新预览后逐组下载XLSX或下载全部ZIP。ZIP包含分拆清单、逐组文件和完整处理底稿；包含原始数据。完整底稿五页：处理日志、有效、异常、重复移出、空行移出。逐组XLSX含台账和处理日志两页，记录版本、参数、本组范围。
7. 在来源追查查看文件、页签、原行、原始值、处理后值及变化；重复移出行指向首行。
8. 主动下载不含数据的JSON方案。恢复会清除当前旧资料和结果，按原槽重新替换导入，再预览。关闭/清空/离开释放内存，不默认保存。

金额保存为精确十进制文本（最多6位小数/24位数字），不填零、不汇总、不自动换汇。不执行公式或采用公式缓存，公式原文仍能追查。日期类型只接受YYYY-MM-DD。期间、币种、单位由原始字段及目标列保留，无自动财务政策判断。追加合并不做关系JOIN或合并财务报表。

每文件10MB、XLSX实际解压30MB、200列、单元格文本10000字；最多20文件、总20000数据行、100目标列、100分拆组。导出原始内容及ZIP内文件内容合计30MB；XLSX单元格32767字符限制，超限明确阻塞，来源不会截断。CSV末尾空记录由公共读取器去除，内部空行保留；XLSX范围以内的空行保留。

文件只在浏览器内存处理，不上传、不遥测、不默认持久化；无CDN、在线字体、自动更新及外部请求。宏、外链、加密、xls/xlsm拒绝；用户表达式或任意代码没有执行入口。

```sh
npm ci --offline --ignore-scripts --no-audit --no-fund
node --import tsx --test tools/D01-财务台账合并拆分/tests/engine.test.ts
npx tsc --noEmit -p tools/D01-财务台账合并拆分/tsconfig.json
```
