# T04 财务规则

应用0.2.0，规则T04-2026-10-04.2；2026-10-04制定。适用期间为各笔借款用户填写的起息日至到期日。计算依据是用户明确的合同参数、付款事实及逐笔确认；不替用户解释法律、会计或税务政策。

## 原合同计划

原合同计划独立保留，不把实际流水直接叠加为额外计划还本。

单利=期初本金×年利率%/100×年化比例。ACT/365和ACT/360按实际天数分别除365、360；ACT/ACT按自然年拆段除365/366；30E/360首尾日均封顶30，不采用NASD或二月特殊处理。起日含、止日不含。约定周期比例=间隔月/12，要求完整锚定月周期，无首尾短期。

付息间隔1/3/6/12月，首次付息日为固定月末锚点，小月夹到月末，后续大月恢复。到期还本尾期付本金；等额本金用原本金/(总期数-宽限期)，尾期结清；自定还本必须明确到期结清，不补差。等额本息仅明确约定周期：A=P×r/[1-(1+r)^(-n)]，零周期利率A=P/n，付款额舍入，尾期结清。未来利率或提前还本按剩余期数重算等额本息，保持原到期日。

原计划同日先原约定本息/自定还本，再额外提前本金，利率用于下一段。该原计划顺序是公开的计算条件，使用者必须与合同对照；实际执行的同日顺序另行明确选择，不能据此推断法律默认顺序。

## 实际、费用及确认分配

实际流水独立记录付款日、本金、利息、费用、币种单位、流水号、依据及来源文件/页签/物理行。单笔借款绑定一个主体和合同。费用台账独立记录约定金额/日期；不资本化，不参与计息基础。

先保存分配草稿，人工指定原计划本金/利息或费用目标，再整批确认。确认本金扣减实际执行余额，确认利息抵累计利息，确认费用抵费用台账；未分配现金保留待复核。总资金需求不能再把原计划本金全额与实际已付本金相加。

每个分配须为正数；实际组件可明确为0。累计分配不得超过对应实际组件及原目标金额，容差不能放行超额。跨借款、币种/单位、重复ID或付款流水、重复实际-目标组合、未选择同日顺序、未来日期和超精度整批阻塞，原工作不变。一个实际组件可部分分配或拆给多个目标。

同日实际本金的计息顺序必须选择并写合同执行依据：

- 当日起减少本金：付款日d起余额减少，之前区间[start,d)仍用原本金。
- 次日起减少本金：本金减少生效于d+1，付款当日仍用原本金计息。

约定周期只支持约定付款日当日起减少本金；周期内付款、周期内复核拆分应计利息或次日生效未实现，阻塞对应确认/实际执行结果，不能改用日息近似。实际起息日还本允许；原计划变更仍须在起息日之后。

实际执行从原本金重新滚动；复核日以前仅确认实际本金减少余额，不把已到期的原计划还本当作付款。未来保持原约定本金目标的未分配额度，末期支付剩余本金；等额本息按真实剩余本金和剩余期数重算，宽限期仍只计息。是否继续计息和末期安排须在合同执行依据明确，合同不支持该安排时不能使用该测算；不自动给逾期、罚息、展期或重组结论。

已确认实际利息仅在实际付款日进入日期事件，作为独立抵扣额度，从累计未付利息中抵扣一次；付款日前的历史未付利息不回写，余额不得转成负利息。未抵扣的已付利息独立展示为利息抵扣余额，不自动退费或抵本金。复核日未付利息和未来利息分列；未来付款利息包含此前累计未付部分，不能将两项重复相加。已到期且无未来付款日的未付本息仍展示，不自动生成展期。

## 独立预期

## 精度、来源与历史

Decimal独立40位ROUND_HALF_UP，输入最多24位数字、6位小数；每笔金额精度0–6位。段息不逐段舍入，合同付息日累计利息一次舍入；历史未付利息按各合同付息日结晶，不把已付舍入尾差带入下一期；尾期本金结清。空不补零，负金额/利率阻塞。利率0–100%，零利率明确提示。不同币种不合计或换汇；单位为对应币种基本单位“元”。容差0–1独立于精度，只比较勾稽。

本金守恒：原本金=确认实际本金+未来本金+最终未付余额。每行期初-本金减额=期末。实际本金、利息、费用分别核验，原计划及调整后排程均带原行来源和依据。

替换或修改资料、来源、合同或规则使原确认失效为草稿，保留失效审计；必须重新复核。只追加确认日之后的新流水/费用且原行、来源、范围和分配完全不变时，保留历史确认并记录追加审计；新增流水仍须单独分配确认。显式复核确认日之后的合同变更可保留不受影响历史确认，并重新核验全部容量与历史结果。保护的历史截点保留在事件集合中，不因复核日期前进而删除；截止日不是付息日时只拆分应计，不额外舍入或生成付款。历史保护比较完整实际记录、分配、来源、依据和已发生计息结果；不能改过去或撤销已保护确认。整套换借款资料须确认开启新工作，先下载原工作。

含数据工作保存原始矩阵、列映射、主体合同、实际、费用、分配、审计及历史保护；恢复先预览再确认，重新核验来源和结果。schema_version=1并严格绑定应用/规则版本，0.1.0不自动迁移。无数据方案只保留复核日/容差。关闭、清空或退出释放内存，不持久化、不上传。

未实现：复利、罚息、展期重组、新增提款、利息资本化、法律解释、有效利率会计计量、AI/OCR。Windows实机未验证。
