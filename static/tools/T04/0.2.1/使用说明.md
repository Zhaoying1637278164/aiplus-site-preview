# 借款还本付息排程

应用版本0.2.0；财务规则版本T04-2026-10-04.2。

根据合同建立原始还本付息计划，再独立记录实际本金、利息和费用。确认逐笔分配后，查看已付/未付本金、后续计息和资金安排。原合同计划及实际流水均保留。

官网使用：在观策数智工具箱官网的资金模块打开“借款还本付息排程”详情，选择同站使用。官网地址：https://aiplus-guance.streamlit.app/ 。

离线使用：从官网详情下载本款同版本离线ZIP，完整解压到本机文件夹，再双击文件夹内的index.html，用浏览器打开；不直接在ZIP内运行。无需联网、账号或开发工具。

先载入虚构样例或恢复“虚构实际执行工作.json”。全部资料只在浏览器内存处理，无上传、外部请求、遥测或默认保存；关闭、退出或清空后消失，请主动下载工作。

1. 在借款条款三步录入合同，或资料导入预览CSV/XLSX的页签、表头行及字段对应。币种分别计算，单位为对应币种基本单位“元”。
2. 自动生成到期还本、等额本金或明确约定周期的等额本息计划；自定还本单独录入或导入。利率与提前还本通过变更事项登记依据。
3. 实际还款页建立主体、合同和执行依据。明确选择当日起或次日起减少本金；记录实际本金、利息、费用和付款流水号。计划费用独立登记，不计入本金。
4. 计划实际衔接页选择实际流水、原计划目标及分配金额。保存草稿，勾选后写确认依据、整批确认；部分分配允许，重复/超额/币种不符阻塞整批。撤销须写依据，已保护历史不能撤销。期后新增流水保留历史分配，新流水另行确认。
5. 到期日历同时展示实际执行后的安排和原合同计划。版本比较页查看确认审计并保护实际历史；不将历史计划当已支付，不自动计算逾期罚息。
6. 底稿与方案页可下载同版本“使用说明.md”，以及完整XLSX、任一页CSV、含数据工作或无数据方案。恢复先预览后确认，取消保留原工作。换资料使旧确认失效；整套换借款开启新工作。

示例：本金1000，实际确认还400，剩余600；合同明确10%、ACT/365、此后365天，当日起减少本金时利息60。费用30已付10，剩余费用20，不影响利息。费用、利息、本金分别保留，不自动抵销。

所有字段必填；没有金额请明确填0，空不补零。记录ID和流水号为文本。金额精度0–6位，利率最多6位小数；容差只用于勾稽，不放行超额。导入记录保留文件、页签、物理行和原列映射。

文件/JSON最多10MB，XLSX实际解压最多30MB，200列、20000原行；最多100笔借款、每类10000条、单笔1200期。只读UTF-8 CSV和静态XLSX，不运行宏、公式、外链或用户代码。

支持日息ACT/365、ACT/360、ACT/ACT、30E/360及合同约定周期。周期内实际付款、周期次日减少本金、复利、罚息、展期、资本化、会计税务法律判断、AI/OCR未覆盖；对应合同条件不明确时先确认依据。Windows实机未验证。

已确认历史后可以推进复核日，原历史截点保留。期后新增利息只在实际付款日进入抵扣，不能改写早期未付利息；含数据工作恢复时保留来源和审计。

详细财务口径见随包财务规则；参考核验与开发交接分别保留，开发命令不属于本使用说明。
