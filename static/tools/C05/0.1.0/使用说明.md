# C05 凭证编制与核对
应用 0.1.0，完整十一页财务流程。下载离线包并解压后，用 Chrome 或 Edge 双击本文件夹内 index.html；断网可用，无需账号或安装。官网及平台实际验收状态见项目 progress/STATUS.md；Windows 实机未验证。
先载入完全虚构样例查看8条正向分录借贷318，再按业务底稿页选择CSV/XLSX、页签、表头和字段；在模板与科目页分别导入配置、编辑对应。检查开放期间、精度、红冲和辅助核算。查看分组、预览、独立检查与异常来源，按组记录复核姓名和依据，主动下载底稿与方案。
用户数据仅浏览器内存，无外部请求、账号、遥测和默认保存；关闭/退出清空。方案schema_version1；含数据工作包含原资料/配置/意见，无数据方案含模板及科目配置但不含业务数据和意见，配置仍可能含用户编码名称。恢复替换工作并重算；方案最大10MB，超限时提示拆分业务后保存。
10MB/解压30MB/20000业务行/200列；模板1000行、科目5000行、生成100000分录。公式、宏、外链不执行，格式损坏拒绝；未知映射和组内不平阻塞通过清单。非零差额无论容差均不通过。Windows实机和正式官网未验证。源码重建：npm ci、npm test、npm run typecheck、npm run build（源码快照内）。

同版本源码包包含锁文件、共享包、本款源码、测试、参考许可及构建说明。解压后使用 Node.js 22 或以上，依次运行 npm ci、npm test、npm run typecheck、npm run build -- C05，输出 release/C05/0.1.0/index.html 和 runtime.json；见 docs/source-build.md。源码重建只生成本机成品，不自动修改官网。
