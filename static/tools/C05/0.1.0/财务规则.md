# C05 财务规则
规则版本C05-2026-10-04.1，适用2026-10-04起的工具核对行为，无税率或会计政策判断。用户自行确定业务应否入账、科目、模板、生效期与开放期间。本款不使用海外ASC606、税率、审批阈值或自动冲回政策。
借贷差额=本组借方合计−贷方合计；精度与容差分开：容差只标注差额线索，非零差额始终阻塞，不自动调平。Decimal精度50位；原值最多24数字、最多6位小数；输出不静默舍入。红冲需显式开启；直接分录单行不得借贷同时非零，不得均零，空不等于0。
组键为主体+凭证组，同组期间币种单位必须唯一且期间属于用户开放期间。主体、业务ID、凭证组、模板ID和科目键保留原始文本，不自动去空格或改大小写；科目按主体+科目键精确匹配且期间处于生效范围，重复对应阻塞，未知不猜。模板多行合法，但同模板行号重复阻塞；仅金额/税额和固定系数，不执行表达式。
辅助核算取业务部门/客商/项目，按科目配置必填；摘要和依据必填。业务ID按主体+期间唯一，静态分录模式按主体+期间+业务ID+分录行号唯一。缺分组信息全局阻塞通过清单。复核意见无法绕过上述检查。
依据：项目 docs/finance-rules.md 与固定S01 Supporting Documentation Requirements、Review Checklist、Common Errors方法章节；数学平衡为确定性核对，并非会计正确性保证。
