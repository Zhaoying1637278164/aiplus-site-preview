# E03 财务规则
rule_version E03-2026-10-04.1；app_version 0.1.1；技术分摊规则有效期2026-10-04起，无自动税率、会计政策或入账判断。适用用户已经确认的人工成本与分配依据，工时真实性和成本归属政策由用户负责。方法依据见参考来源.md，以下确定性规则自主制定。

1. 三表：人工成本（唯一成本ID）；组织项目（唯一对象编码，部门编码名称、项目编码名称、启用是/否）；分摊依据（唯一依据ID，员工ID+成本项+期间+币种+单位+对象编码唯一）。全部ID为文本保留前导零。重复整组阻塞，不丢行，不自动汇总重复成本。
2. 每笔成本与依据按员工、成本项、YYYY-MM期间、币种和金额单位精确匹配，不去空格、不换汇。部门项目使用对象映射，不推断归属。无匹配、无效/停用/重复对象、无效/重复依据整组成本未分配。范围外成本列明未分配，保留原值。孤立依据也列异常。
3. 金额与权重最多6位小数、24位数字。金额必须可用选定精度精确表示，不静默舍入；零金额正常可分配；负数默认阻塞，明确勾选负成本冲减才分配。权重必须非负，零保留明细，合计必须正。
4. 比例以百分数30/70输入；合计与100差异必须在用户设定容差内（默认0，最大1百分点）；容差与金额精度分开。通过后按实际合计归一化，依据总额和比例差额公开。工时按总工时归一化，不确认工时真实性。
5. 金额最小单位BigInt、权重百万分整数，按正金额绝对值乘权重/总权重向零截断。余数最大法：余数降序、对象编码按Unicode固定顺序，逐最小单位分配；末对象法：所有余量归最后一个正权重对象。负数相同绝对分配后恢复符号。零权重不接尾差。理论金额12位仅展示，分配用整数有理数，无Decimal循环小数累计损失。
6. 逐成本原额=分配+未分配；分期间币种单位原额=分配+未分配，残差必须0。金额无效行不填零，不进入可量化汇总，异常单列“金额不可量化”。来源文件/页签/行号、原始值/修正、字段映射、权重、理论金额分子分母、尾差、参数与版本全部导出。
7. 无数据方案仅保存规则/字段映射；含数据工作明确声明原始资料和修正并须确认恢复，版本及结构校验。文件10MB、解压30MB、每表20000行200列、每格10000字；方案合计60000行并受10MB约束。页面关闭/退出/释放清内存，不持久化不上传、不执行公式宏外链用户代码。
