# E03 人工成本分摊 0.1.1

九页人工成本到部门项目分摊工作流，支持比例/工时、组织映射、期间筛选、金额精度、比例容差和尾差。输出员工到对象明细、汇总、未分配、异常、来源和完整11页签底稿。只使用用户已经确认的成本与依据，不自动确定工时真实性、费用政策、入账或换汇。

候选入口：progress/evidence/E03/0.1.1/candidate/index.html（本仓库根目录下）。双击离线打开，概览载入完全虚构样例。100按30/70分为30/70，缺依据50元留未分配。准备三表CSV/XLSX，可选择页签、表头、字段及人工修正；规则页设置，运行复核页重算，员工明细/部门项目汇总/异常与底稿页复核下载。

金额与权重最多6位小数，金额须可用所选精度精确表示。比例填30/70百分数，合计默认100；工时按合计。不同期间币种单位不混合。缺失不补零、重复整组阻塞，零正常、负数须用户勾选冲减。文件10MB、解压30MB、每表20000行200列，分配明细上限100000行。

资料仅在浏览器内存处理，不上传、遥测、日志或默认持久化，不运行宏/公式/外链。关闭、清除或退出清内存。下载无数据方案保留规则和映射；下载含数据工作包含原始资料与修正，明确确认恢复后重算，schema_version=1。

开发：Node22+，npm ci；node --import tsx --test tools/E03-人工成本分摊/tests/engine.test.ts；npm run typecheck；node --import tsx tools/E03-人工成本分摊/tests/build-candidate.ts。仅本款及公共包依赖进入候选源码，锁文件与构建说明齐备。正式官网接入、正式版本包及accepted由总控验收；Windows实机未运行。

参考、规则、独立答案、实际命令与交接见本目录对应文档。候选不等于正式上线。

本轮604笔大批验证及固定时间戳/分页修复，见0.1.1证据。旧0.1.0证据和版本包原样保留。额外Python全单元格验收需要Python3及openpyxl3.1.5；先执行tests/bulk_oracle.py生成独立预期，再执行bulk_actual.ts，最后bulk_verify.py。大批CSV/XLSX均完全虚构，示例目录提供。

正式构建的统一入口 `空白模板.csv` 是人工成本表模板，与 `人工成本模板.csv` 字节完全相同；组织项目、分摊依据各自模板仍随包提供。统一 `虚构样例.xlsx` 与 `三表虚构样例.xlsx` 字节完全相同，包含全部三表。原十项资产全部保留。
