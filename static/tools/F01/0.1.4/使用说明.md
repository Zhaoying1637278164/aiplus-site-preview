# F01 资产负债表与利润表

应用0.1.3。根据已确认的科目编码、明细键、报表项目、方向和调整编制两表底稿。九页分别设置编制范围、导入、模板、映射、调整、两张报表、异常来源及底稿恢复。

下载离线包并解压，用Chrome或Edge双击index.html；不要求账户，无网络也能使用。先体验完全虚构样例，再导入自己的CSV/XLSX。用户资料仅在浏览器内存，关闭、清空或退出清除，不上传、记录日志、遥测或默认持久化。

1. 编制工作台设置主体、币种、元/万元、两张报表各自期间与显示精度；确认适用制度、模板和方向。单位须与资料一致，不自动换汇或转换不明单位。
2. 资料导入分别选择余额与发生额、报表项目、科目映射、调整底稿；选择页签、表头行和字段。每次确认替换此类资料，旧结果立即重算。空白模板不能作为有数据表导入；无调整可以留空。
3. 余额与发生额字段：主体、期间、币种、单位、科目编码、科目名称、明细键、资料性质、借方、贷方。期间YYYY-MM；性质为期末余额或损益发生额。损益必须提供结转前净发生额，不使用已结转余额。每个编码/明细每月一行，多月和比较期缺失须提供显式零；不猜测新设/停用科目。
4. 项目模板使用BS/PL；类型明细/合计/其中；合计组成用项目ID*1或项目ID*-1，以分号分隔。BS分组流动资产、非流动资产、流动负债、非流动负债、权益、权益减项或对应合计分组；其中项不重复计入；首版BS不支持其中项。保留ASSETS/LE/NET核心合计ID及正确分组，完整覆盖对应明细，项目名称可改。无业务明细须自行逐项确认零。内置参考模板未确认零，虚构样例有人工零声明。
5. 映射使用报表+科目编码+明细键完全相等；方向借-贷/贷-借、系数1/-1。不按名称猜测或自动重分类。汇总资料缺少明细时须补充拆分余额。
6. 调整金额为报表增加/减少，按组与期间核对BS会计效应；无依据、不平或重复的整个组不进入结果。PL报告调整不自动改总账或留存。
7. 复核两表、资料覆盖、未映射、异常及来源。未映射净零仍保留行数与绝对金额；空不当零，存在阻塞标待复核，仍可导出完整复核底稿。
8. 下载两表及完整底稿（12页签）；含数据方案可恢复余额/调整，無数据方案仍含科目编码、明细、映射依据，需重新导入财务资料。方案有schema/应用/规则版本，恢复从输入重算，不信任外来结果。

文件限制10MB、解压30MB、20000行200列；模板最多250项、映射及调整各5000行。静态公式缓存也不运行，拒绝宏、外链及任意用户代码。金额最多24位数字/6小数，输出精确文本；显示和容差分开。

中国一般企业会计准则场景需用户确认适用新金融/收入/租赁准则。2026版列报准则提前或强制执行主体被阻塞；不支持小企业、金融、合并、新版五分类、完整OCI/EPS/附注。不生成现金流量表，不声称完整法定三表或账务正确性保证。

源码安装Node22+后npm ci，npm test、npm run typecheck、npm run build生成F01候选；源码附锁文件、共享包、本款代码、测试与声明。Mac Chromium测试证据在项目本款验收文件；Windows实机未验证。官网交付状态见项目进度，工具可独立离线使用。

0.1.1：导入可取消替换；余额/发生额支持逐行编辑；分页表可查询；空调整页签可导入；兼容0.1.0 schema1方案。900行虚构验收及独立Python预期见tests/fixtures。

0.1.2：宽表按字段设列宽，期间/编码/金额保持单行，表内滚动并保留表头；长依据可展开全文。手机先显示财务字段，逐行展开全部字段与来源并可直接编辑，默认每页5行；桌面20行，可选5/10/20/50、跳页及末页。完整导出不受显示分页影响。

0.1.3：覆盖分组在视图中逐项显示主体、期间、币种、单位和资料性质（含空/缺值），原组键仅在核验详情展开；计算与导出仍保留原组键，金额及财务规则不变。
