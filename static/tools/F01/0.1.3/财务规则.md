# F01 财务规则

规则 F01-CN-20261004.1；应用0.1.3。金额Decimal40位，输入最多24位数字/6小数；显示位数与勾稽容差分开，不静默改原始金额；空/公式拒绝，零负值保留。

依据：[财会〔2019〕6号](https://kjs.mof.gov.cn/zhengcefabu/201905/t20190510_3254992.htm)及附件2第2–3页余额列、第10–13页利润及备抵项目说明。适用执行企业会计准则且已执行新金融/收入/租赁的非金融企业；模板须用户确认，不能从名称猜，明细重分类和备抵减项须显式映射。比较期不得填零冒充数据。

已读取[财会〔2026〕11号](https://kjs.mof.gov.cn/zhengcefabu/202608/t20260805_3994927.htm)通知一、二、第三十二至三十四、六十八至七十一条：境内外同时或境外上市企业2027、其他境内上市2029、非上市2030起执行，允许提前。首版阻塞提前执行与达到对应年份的旧模板编制；不支持金融企业、小企业准则、合并、终止经营与新版五分类/EPS/完整OCI附注。新模板未核验完整配套格式，不自动切换。

确定性规则：资产借-贷，负债权益贷-借，仅由用户确认映射决定，备抵用系数-1；利润费用借-贷正数，收入贷-借正数，损失项目按贷-借呈负数。合计项目安全ID加减，不执行任意字符串公式。BS单期快照与上年末快照；PL独立月度区间本期/可比，不拿期末余额编损益。资产=负债+权益检查两期；调整按组查BS会计效应=0；利润合计按模板追溯。利润与留存变化不自动等同，分红/以前年度更正等缺少依据时仅提示，不调平。

未映射、无效、重复、缺月、缺比较、异主体期间币种单位、越界映射调整独立保留与阻塞完整性。即使净未映射0，绝对金额和行数不0也不能标完整。有效零项目需显式模板“确认零=是”或有效映射来源，不默认空=0。显示单位换算按用户选择元/万元，底稿原始精确金额留存。
