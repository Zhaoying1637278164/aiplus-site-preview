# K04 应用财务规则

应用0.1.0，规则K04-2026-10-04.1。本工具是盘点核查底稿，不确定会计/税务处理，不自动凭证，不定义中国默认损失认定。以下为用户确定范围的操作计算口径，2026-10-04起应用，须由本企业财务复核；参考ERPNext固定章节仅工程方法。

主体、仓库、截止日期、币种完全一致，账面快照和实盘均同截止日；其他日期须企业先提供可靠截止调整后的清单，本款不推断移动。最小键主体/仓库/物料/批次/库位，空键阻塞，同键账面重复阻塞。映射须全原键到全目标键、依据明确，重复对应阻塞，不模糊匹配。无对应按原编码，单侧分别列出。

每行数量/成本/比例Decimal严格十进制，至多6位；数量/成本非负，比例正；金额精度0–6用户指定，容差独立不用于改数。换算数量=原数量×显式比例，依据逐物料原/目标单位，成本始终每账面目标单位。实盘数量缺失不作0；零是有效值。数量和币种不能混合汇总。

重复实盘默认阻塞。重盘需批准唯一盘点行ID及依据，其他行标未采用；分区只批准全部同键、非空不重复分区记录，逐行换算后加总；不允许跳过坏行。任何实盘异常使该键不能计算，包括重盘未采用的异常行。账面重复不可绕过审批。

数量差=实际-账面，正盘盈负盘亏。单侧数量原样显示、差与金额留空。成本缺/无依据时差数量可算、金额未测算；可导入同键/同日期/同币种/同目标单位、非负且有依据估计单价，标估计。零成本有依据可测算0。逐项差×成本得精确额，再四舍五入，总额=sum逐项舍入，显示精确总与总舍入差。按目标单位数量勾稽，按币种金额勾稽，未知不进入已测算。

复核须有人员/依据，仅可确认无阻塞双侧项；确认包含计价状态，未计价确认不等于认可金额。撤销与任何参数/资料/规则改动保留事件但使旧复核失效。恢复含数据工作重算，不信任保存结果；验证复核与当前结果绑定。所有原行、未采用行、依据与事件进完整底稿。
