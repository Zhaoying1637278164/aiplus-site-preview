# E02 工资变动核对

候选0.2.0：两期工资明细按员工稳定ID及薪项核对，分离人员出现变化、同人薪项变化，提供重要变化复核、来源及勾稽底稿。九页流程，可断网双击候选HTML。官网、正式离线/源码版本包及accepted由总控完成。

所有资料只在浏览器内存，无上传、遥测、外部请求或默认保存。关闭清空；主动下载方案，默认不含数据，含数据需自行勾选。输入静态CSV/XLSX，不运行公式、宏或外链；10MB、解压30MB、20000行200列限制。

先载入虚构样例，然后选期间/币种/元单位；分别导入、选页签和表头行、确认资料；设置两侧字段及薪项对应；查看人员、差额、重要变化、原始来源、勾稽；下载六页底稿和方案。员工ID请优先文本格式保存，姓名不会作为关联键。工资缺失不证明真实离职；不计算法定个税社保。存在异常时只有部分范围可核对。

开发：根目录 npm ci；node --import tsx --test tools/E02-工资变动核对/tests/engine.test.ts；npx tsc --noEmit；node --import tsx tools/E02-工资变动核对/tests/build-candidate.ts。浏览器测试路径参见tests/browser.ts（本机Chrome路径可改）。Mac Chromium已执行情况见验收证据；Windows实机未验证。
