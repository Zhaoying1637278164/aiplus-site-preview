# M05 财务规则

应用0.1.1；规则M05-2026-10-04.2；适用2026-10-04起当前版本的本地经营复核底稿。依据为本项目共同财务规则、用户确认的指标口径和下列确定性数学定义；没有税率、会计确认或境外政策判断。

- 单报告设置主体、YYYY-MM（1900–2199）、当期/累计、金额币种和单位。实际与预算期间为本报告月；同期必须上一年同月。累计表示1月至报告月的输入累计值，不由程序把当期转累计。快照即期间末值，累计模式亦不得将快照多行相加。
- 每指标声明基础计量单位（报告单位或人/件等）和币种（报告币种/不适用）。对应每行精确一致；不自动换汇或改单位。维度按用户确认互斥；不跨指标/单位直接汇总，不用汇总行与明细同时计算。
- 模板12列全部必须存在；记录ID全表唯一；主体、指标、维度、期间、口径、场景、币种和单位不得缺失。未知指标、公式对象、空金额或非法数值均阻塞正式报告、全部事实及图表，仍保留所有诊断和原始行。
- sum：同指标/维度/场景的数值Decimal求和；snapshot：同组单行，超过一行阻塞；ratio：sum(分子)/sum(分母)×100，分母合计必须大于0。ratio数值列必须为空；非比例分子分母必须为空。允许负数分子/金额，但不把其解释为正常业务。
- Decimal precision40，半入；输入最多24位数字/6位小数；数值型超过15位数字、超安全整数或非有限拒绝；高精度原值须提供十进制文本，不能恢复原工作簿已丢失精度。金额合计/差额为十进制文本，比例/变化率以12位小数保存计算值；显示0–6位单独配置。显示舍入不影响金额计算、容差和关注判断。
- 预算差额=实际−预算；同期差额=实际−同期。sum/snapshot变化率=(实际−比较)/比较×100，仅比较值>0时成立，否则保留差额并明确不适用。ratio差额为百分点，不再计算“比例的变化率”。缺失场景不等于0，预算/同期缺失不会生成该比较事实。
- 改善方向higher/lower由用户定义；abs(预算差额)≤容差为容差内；否则按方向有利/不利，neutral为中性。关注=人工勾选或不利或abs(金额/快照变化率，比例百分点差额)≥阈值。阈值默认10、容差默认0.01只是可改参数，不是财务政策。
- 事实模板只陈述本期输入值及合法比较。每事实的values保存未显示舍入值，sources保存参与计算的每个原始行。不存在输入不生成事实/图表。不从人工注释推断因果，不将注释混入系统事实；原因、措施、责任人均显示为人工输入。
- 用户再次改报告参数、指标或资料时清除确认/注释/关注，避免旧原因挂到新数字；原始数据保持用于再校验。无数据方案恢复不含旧资料或注释，含数据方案恢复精确版本重算。

独立预期在规格与独立预期.md及tests/finance.test.ts。Windows实机未验证，海外政策不作为中国默认政策。
