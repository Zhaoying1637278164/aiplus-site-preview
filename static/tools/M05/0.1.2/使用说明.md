# M05 经营月报

候选0.1.1，本款开发自测，尚未官网公开验收，accepted由总控登记。

为经营管理层编制经营月报：输入经过核对的经营指标，配置口径，比较预算和去年同期，用输入数字生成可追溯事实，人工填写原因、措施和责任人，下载HTML报告和完整XLSX复核底稿。九个业务页面见产品与页面方案.md；不使用云AI读取实数，不编造原因，不实现OCR/实时平台。

打开candidate/0.1.1/index.html（或解压候选离线包后双击index.html）。无需账号或安装，断网可用。先载入完全虚构样例，再设置自己的主体/期间/币种/单位，导入UTF-8 CSV/XLSX。选页签和表头，确认数据导入；在指标口径页配置ID、汇总类型、基础计量单位、币种口径和改善方向。修复异常后确认来源已核对，复核预算同期、图表和事实句，补充人工原因，预览导出。

每行必须有模板12列。金额/基础数值用数值列；比例用分子/分母，数值留空。实际/预算输入报告期，同期输入上一年同月。当期和累计严格隔离。期末快照一组只一行；毛利率等按合计分子/分母重算。金额最多6位小数、24位数字。缺失不填0，不自动换币种/单位。

文件仅在浏览器内存处理，不上传、不记录财务日志、遥测或默认保存。10MB/解压30MB/工作簿合计20000数据行/100页签/200列/单格10000字。拒绝宏、外链、超链接、公式运算；含公式只能诊断，不能正式成报。任一校验异常阻塞正式报告、事实和图表，完整诊断仍可导出。

导出：独立HTML报告含所有图表/事实/人工注释，完整版含全部原始来源；摘要版来源另见完整底稿。XLSX9表保存参数、口径、比较、分子分母、事实数字绑定、注释、异常、全量来源和图表值。分页/筛选不会截断导出。浏览器打印当前预览分页范围，完整打印请打开下载HTML后打印/保存PDF。报告是本地静态文件，使用系统字体，无脚本/外部请求。

方案由用户主动下载：无数据方案保留结构，清除确认/人工注释/关注/资料；含数据工作含输入与注释。JSON schema_version=1、工具/应用/规则版本精确匹配后恢复并重算。换资料或改口径清除旧原因；关闭/退出即清除内存，尚未下载工作退出时提醒。

开发重建：Node22+，在源码ZIP解压根目录执行`npm ci`、`npm run typecheck`、`npm test`、`npm run build`。候选构建在本款candidate/0.1.1，不写正式release。源码包含锁文件、公共包、本款源码与测试、公开参考核验和第三方通知，不含node_modules、凭据、业务数据。

Mac主机Chromium的实际范围见验收证据.md；Windows实机/Safari/Edge未验证。官网接入与公开下载由总控验证。
