# T03 13周资金预测

应用版本 0.1.0。以现金日期安排连续13周收付、余额与最低资金缺口。

解压下载的离线包后，用 Chrome 或 Edge 双击本文件夹内的 `index.html`。无需安装或账号，断网可用。先换入完全虚构样例熟悉操作，再导入自己的资料。

12个业务页面：预测范围、账户期初、收款计划、付款计划、实际收支、预测口径、13周排程、资金缺口与措施、情景比较、版本与滚动、例外复核、来源与底稿。

先应用范围，再导入期初/计划/实际；CSV和XLSX均先预览页签、表头和逐物理列对应。每笔期初明确主体/账户/币种/单位/窗口起点/金额/最低余额/独立依据。实际与计划两端由用户明确批准金额关联，剩余计划不重复加算；超额整批不生效。资料覆盖需明确确认；无效资料、缺期初/日期/金额不填零。换资料或口径使旧批准失效。

批准内部调拨仅消除主体收付，账户资金逐端保留。币种单位分列，不自动换汇。情景按明确日期调整剩余计划；融资和利息费用分别录入日期并批准，仅进入情景。滚动保存旧版本，不把旧预测变为实际，新期初重新提供。

金额Decimal，输入最多18整数位/6小数位；显示HALF_UP0–6位，精确守恒和显示尾差单列。政策、授信可用性、AI/OCR、记账和银行付款不自动判断。

下载完整工作包含原始资料、参数、批准/撤销/复核、措施、历史版本；下载通用方案不含业务数据，只保留周起点、显示位数和容差。恢复先预览，取消原工作逐字段保留，确认全部替换。文件与工作10MB、解压30MB、当前全部输入累计20000行/200列；来源100/事件1000/版本50/措施100/变更1000；导出30MB且原单元格不超过390000，超限明确拒绝，可分批处理，无静默截断。

资料只在浏览器内存，不上传、不默认保存、不记录日志、不遥测；关闭页面或确认退出后清空资料，未结束的导入不会重新写入。拒绝公式及缓存、宏、外链。程序运行无需网络。
