# T03 财务规则
rule_version=T03-2026-10-04.1，适用用户明确范围的直接法现金预测，不含会计税务政策判断。金额Decimal，输入最多6位小数、18整数位；显示位数0–6与勾稽容差分别输入，负值只在明确退款/冲回并有依据时有效。
周起点必须与起始日匹配，连续13周每周7日；滚动以同周起点的新日期移动。现金日期归周，不用收入/利润/开票日期。账户期初日期必须等于窗口起点，依据必填；缺失阻塞对应账户和主体结论。期末=期初+实际收-实际付+剩余计划收-剩余计划付；下一周期初接上周期末。
实际仅截止日前记录参与预测衔接；截止后实际列例外。经明确批准的双端关联消耗实际和计划额度；同组超额全批不生效，原金额不变；未关联、退款/冲回、跨窗口计划未替代项阻塞覆盖完整结论。批准覆盖范围仅确认资料完整，不填补异常。撤销不改原资料。
同主体两端方向相反、币种单位金额与现金日期一致、同窗口、同实际/计划层的内部调拨批准才消除合并收付；账户仍逐端保留。未批准或不一致标例外，不自动抵销。不同币种单位永不直接加总。
情景只调整剩余计划日期并加入明确批准融资/费用；基础不变，不承诺融资可用。滚动保留旧版本原始资料，新期初重新提供依据。复核仅记录判断，不能解除无效输入和缺失依据。
