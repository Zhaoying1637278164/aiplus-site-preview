# X02 财务规则

规则X02-2026-10-04.2；应用0.1.1。金额使用Decimal precision40，输入最多2位小数、整数最多16位；不静默舍入。容差为独立参数0–1元，默认0.01仅为核对参数，非法参数全局拒绝。空值不能作为0；0需明确填写。

主体、期间YYYY-MM、币种及单位逐行与范围完全相同，不换汇。有效事项：ID唯一、必填资料完整、会计/税务依据、适用条件、规则版本与有效起止期间完整，期间在范围内，且用户在口径页确认分类。基础默认范围未填；虚构样例的规则及企业均虚构，不作为政策示范。

暂时差异按非负绝对额台账，性质由用户明确为应纳税或可抵扣：期末计算=期初+新增−转回；残差=填报期末−计算期末。超额转回产生负期末则阻塞。账面价值和计税基础可选，必须同时有值；只核对二者差额绝对值与期末，不据符号推定性质。永久差异记录本期发生，期初/转回必须0、期末=新增，不参与转回计划。

未来计划必须有唯一计划ID、事项ID、主体币种单位、未来YYYY-MM、金额及依据。分类未确认、事项失效、永久差异、同事项同期重复、计划负值/空值/公式、孤立计划及范围错配阻塞该计划。超排阻塞该事项全部计划；未排余额单独列示为待补，不假设转回日。各期间计划合计按性质分列；金额0允许但提示。

复核必须编制人、复核人、真实日期、意见完整，人员不能相同。复核不改变问题与金额；变更资料/范围/分类使旧复核失效。来源是原文件名、页签、真实行号，用户引用路径作为文本，不访问文件或外链。

政策背景：财会[2006]3号，自2007-01-01上市公司施行，其他企业须确认执行范围；准则18号第4–9条定义计税基础与暂时性差异，第14–20条具有转回、未来应纳税所得额等条件。解释16号第一项自2023-01-01生效，相关单项交易需具体判断。本款不自动确认递延税资产、负债、税额或抵扣资格。政策有未核实项时保持该事项待确认，不依据海外规则代入中国默认政策。

字段对应必须完整一一对应，原始所有列和行另存于内存并随含数据工作及底稿下载，不改变原始来源。事项/计划修改仅改变工作字段，原始导入仍保留；任何资料、计划或范围变化清空确认和复核，复核不覆盖阻塞项。方案大小仍10MB，含原始资料时超过上限明确阻塞下载，不静默删行。无数据方案只含范围参数，不含数据或确认。
