# X02 税会差异底稿

应用 0.1.2，完整七页财务流程。官网及平台实际验收证据见项目 progress/STATUS.md；Windows 实机未验证。

解压离线包，用Chrome/Edge打开index.html，无需安装、断网可用。用户资料仅浏览器内存处理，不上传、遥测或默认保存，关闭清除；主动下载工作JSON可恢复。

1. 概览填写主体、期间YYYY-MM、币种、单位元及核对容差；或体验完全虚构样例。
2. 在事项资料页分别导入差异事项和转回计划（UTF-8 CSV/无宏XLSX），选择页签及表头行。使用完整模板字段或逐列选择字段对应；文件10MB、解压30MB、20000行/200列。禁止宏、外链；公式行阻塞不执行。
3. 口径页选择事项，修改后保存，逐项确认性质、会计及税务依据、条件、版本及有效期。虚构示例依据不能用于实际政策。
4. 变动页核对期初+新增−转回=期末；金额以非负绝对额输入，方向由性质表达。永久差异仅本期发生，不排程。空不是零、负值或超过2位小数阻塞。
5. 转回页查看未来计划、未排余额、重复孤立计划和超排。计划由用户指定，工具不猜转回日。
6. 复核页填写不同编制/复核人、日期及意见；问题不会因填写复核而被覆盖。
7. 底稿页下载十一表XLSX、含数据工作或无数据方案，导入JSON恢复重新计算。含数据工作包括财务资料，请自行保管。更换资料或范围清除分类确认/复核；修改事项同样清除旧确认，需重新确认。

不判断税务抵扣资格、计税基础、税率、递延税资产负债确认，不生成申报或入账文件。金额汇总只覆盖有效已确认事项；阻塞项完整保留。可选账面/税基对照需同时填写，只核对差额绝对值。

源码重建（Node22+）：npm ci；npm test；npm run typecheck；npm run build -- X02。同版本源码包包含锁文件、共享包、本款代码、测试、声明与 docs/source-build.md；输出 release/X02/0.1.2/index.html 与 runtime.json。

所有表格支持全量搜索、50行分页与直接跳页，全部原行保留。口径/复核按原始行选择，重复ID可分别定位修正；计划可在转回页逐行修改，修改后清除确认与复核。320px导航换行显示全部七页；长表在自身区域横向滚动。原始导入表与工作字段表分别输出，字段对应也纳入方案和底稿。

本工具未实现AI、OCR、税务申报或自动入账。大批604事项/806计划示例全部虚构，独立整数分预期生成脚本及CSV/JSON夹具包含在源码包。浏览器验收是Mac Chromium自动化，Windows及公开官网仍未验证。
