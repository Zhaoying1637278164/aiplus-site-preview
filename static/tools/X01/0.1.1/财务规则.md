# X01 财务规则
应用0.1.0，规则X01-2026-10-04.2。金额Decimal精确加减；精度与金额容差分开；空不等于零。不执行税率适用、应纳税额或抵扣计算。
中国依据：[中华人民共和国增值税法](https://shanghai.chinatax.gov.cn/sjtax/ztzl/yshj/ldjj/202412/t474700.html)，2024-12-25通过、2026-01-01施行，第16/17条价税分离，第18条人民币计税；本工具仅三列核对，不实施法定汇率折算。外币同币种票账可核对但不代表人民币申报金额。不同单位/币种不直接比较。
红字依据：[国家税务总局公告2024年第11号](https://shanxi.chinatax.gov.cn/zdgk/detail/sx-11400-545-1801545)，第8/12条，2024-12-01生效；适用数电发票，退回、开票有误、中止和折让可红冲。用途/入账确认、确认单、抵扣转出等法律条件不能从明细核对确定，对应税务办理功能不提供。本工具红字原蓝票ID仅做资料关系核对，不替代确认单或审批。纸票作废状态为用户导出事实，不把数电票红冲当作废，作废原值保留且有效金额排除；如有账务则提示复核。
数学规则自主定义：一票一条发票头；商品明细必须由用户整理为票头，重复不自动累加；账务凭证行ID唯一。一票多账默认关闭，经用户显式配置后汇总，发票多条仍阻塞。关联键不得空，主体和客商在双方也须一致。
红字signed只接受各金额非正且至少一项负；positive要求非负且至少一项正，再转为负用于比较。原蓝票必须唯一正常票，同主体/客商/币种/单位，日期不得晚于红票；累计红冲三项绝对额不得超过蓝票。不靠容差放行原票异常。超额提示是完整本地资料范围内的线索，不证明税务违规。
月份过滤分别按各侧期间，不按开票日期代替纳税义务日期；跨期开票/记账显式阻塞或保留复核标记，工具不判断会计确认时点。导入凭证日期与期间不一致需复核。
含税/不含税/税额三列分别对应，支持显式由两项推第三项，派生值标记，绝不静默填零。不得配置税率替代缺税额。
复核人、状态和说明只记录进度；换资料/参数/字段即清旧复核。所有汇总按主体、期间、币种、单位分组，重复等仍列原始有效金额，不代表可申报或可入账。

规则.2修订：将一票多账默认值改为关闭；累计红冲超额的不含税、税额、含税三项异常使用独立ID保存复核，避免相互覆盖。金额公式、容差和税法适用范围未改变。旧规则.1方案明确拒绝；旧候选完整保留在history/pre-bulk-2026-10-04。
