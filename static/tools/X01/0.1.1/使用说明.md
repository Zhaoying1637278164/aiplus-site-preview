# X01 票账核对

应用 0.1.1，完整八页财务流程。用于财务人员将用户导出的发票明细与账务明细核对；不是发票验真、税务办理或自动开票服务。

下载离线包并解压后，用本机Chrome或Edge打开index.html，无需账户或网络。先体验完全虚构样例，再导入自己的CSV（UTF-8）或XLSX。每张发票一行票头，每条账务一行且记录ID唯一；商品明细不能当作多张同号发票累加。

一票多账默认关闭，用户确认业务依据后主动勾选才能汇总。内置虚构样例明确携带启用规则。所有表格支持全文搜索、首页/末页、前后页和页码跳转；资料首页可逐行核查全部输入，结果、异常及来源页可搜索尾部记录并追溯。

按导航依次完成：发票与账务资料 → 范围与口径 → 字段与关联规则 → 价税关系 → 票账核对 → 红字作废与重复复核 → 原始来源 → 底稿与方案恢复。含税、不含税和税额分别检查，价税差异与票账差异分开；红字对应原蓝票，作废不计有效票额但保留账务复核。跨期、重复、多对多、缺金额及币种单位不一致不会靠金额容差调平。

支持主动下载两侧模板、原始CSV、核对结果CSV、十表XLSX底稿、无数据方案及含数据工作。无数据方案只含规则和字段对应；含数据工作包含原始行、来源及复核。两种方案均schema_version=1、校验版本后重新计算。当前规则X01-2026-10-04.2；旧规则.1方案拒绝恢复，请保留旧包读取。关闭、退出或确认清空即清除内存；取消替换保留原工作。没有上传、日志、遥测、默认持久化、CDN、在线字体或外部请求。

单文件10MB，XLSX实际解压30MB，单工作簿累计20000行，两侧合计20000行，200列，单元格10000字。公式/宏/外链不执行，公式金额阻塞；仅支持CSV/XLSX，不支持xls/xlsm、扫描件、OCR、税务平台。金额最多18位整数和6位小数，精度超限拒绝，不静默舍入。不同币种与单位不自动折算。

中国税法及公告具体依据、生效期、适用条件见财务规则.md。汇总是未去重原始有效金额，含重复疑点，不是申报金额或审计结论。

程序及平台实际验收证据见项目 progress/STATUS.md；Windows 实机未验证。

同版本源码ZIP解压后在根目录执行四命令：`npm ci`、`npm test`、`npm run typecheck`、`npm run build -- X01`。构建产物位于 release/X01/0.1.1/index.html 与 runtime.json。Node.js22+；安装依赖需要网络或已缓存的锁定依赖，成品运行不需要网络。源码包包含锁文件、共享包、本款代码、测试、参考许可和构建说明 docs/source-build.md。
