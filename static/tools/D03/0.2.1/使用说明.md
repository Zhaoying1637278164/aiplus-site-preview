# D03 科目与客商对应关系 · 0.2.0

将不同系统的科目、客户/供应商和部门资料对应到企业确定的目标字典，维护范围、生效期与名称别名，逐项确认多目标冲突，保存原始来源及工作底稿。0.1.0历史包保留。本说明对应0.2.0；发布和验收记录见验收证据.md。

## 官网与离线使用

官网从主数据模块进入本款详情，选择在线使用。离线请下载并解压工具包，用Chrome或Edge双击其中的index.html；无需安装，断网可以使用。空白原始模板和目标字典模板、使用说明、财务规则、虚构XLSX和完整虚构工作JSON随同版本工具包提供。先体验虚构示例，再导入自己的CSV或XLSX。文件只在浏览器内存处理。

## 六页工作

1. **资料与字典**：导入两份本机CSV/XLSX，选择页签与表头行，指定原始类别/编码/名称/范围/业务日期列；目标字典固定“类别、目标编码、目标名称、范围”。点击完整虚构示例体验规则和异常。
2. **对应规则**：选择本次类别、范围和业务日期，维护编码或名称规则、别名及生效期。科目/客商/部门相同编码分别处理；客户及供应商都归客商，可在企业范围中进一步区分。编码保留前导零，名称规范化由用户主动选择。优先级仅排序，不解决冲突。编辑内容后需重新确认规则。
3. **待办处理**：生成五类结果，按类别/状态/范围/原值筛选。选择一条来源资料查看目标候选，填写经办人与依据后确认本行；仅影响当前原行，不自动给同码其他行套用。异常必须回源修正。逐行确认可撤销，最近20次规则/确认操作可撤销。
4. **来源追查**：原字段、文件/页签/行号、命中规则、字典原行、确认依据、字典问题和范围排除逐项查看。换文件、字段、规则或范围后旧结果和逐行确认失效。
5. **版本比较**：留存当前规则基线，按规则ID比较新增/删除/修改。恢复基线替换当前规则，并清空逐行确认，重新计算。操作登记为本机自填记录。
6. **结果底稿**：下载11页XLSX完整底稿；保存含数据工作JSON，恢复后重新计算，不采信保存结果。随时可用顶部“保存本次工作”保存资料已导入但尚未生成结果的工作。

## 保存、恢复与清除

含数据工作（schema_version:2）包含原始资料、字典、企业规则、逐行确认、操作登记和规则基线；逐行确认绑定当时原始行、字典来源、字段及命中规则，恢复资料不一致会阻断。文件不包含运行缓存，需重新计算。最近20次临时撤销栈不写入文件，恢复后可逐项撤销已确认事项。

无数据方案只保存字段选择、名称规范化、类别和日期选项；不含范围实体、资料、字典、规则原值和处理记录。恢复无数据方案清空当前工作，须重新导入资料、维护企业规则。旧0.1.0文件不直接接受，避免类别不明而串用。确认替换前提示保存工作。

工作只在当前浏览器内存。关闭、清除或宿主卸载释放资料和文件缓冲；无上传、日志、遥测、默认持久化。下载由用户主动发起，文件需要自行保管。发起下载不等于保存成功，请实际确认后离开。

## 虚构样例与限制

内置/完整工作/XLSX同一虚构样例：12=已映射3+待确认1+冲突1+未映射3+异常4，字典问题2条。XLSX第9原行故意包含不执行的公式及缓存，专门验证拒绝缓存；其余零、负、空金额原样保留。第10原行“北辰贸易”与字典名称相等，仅产生确定性候选，不自动确认。

仅以企业目标字典及用户确认作为依据，不内置会计/税务政策，不解释科目经济含义。不汇总或换算金额，不跨币种单位期间聚合，不提供AI、模糊智能、OCR、远程同步或完整主数据平台能力。

每文件10MB、解压30MB、20000行/200列、1000规则、每条50别名、编码/名称/范围100字、原始行×（规则数+字典行数）≤100万。恢复文件也受10MB限制；操作登记最多1000条，达到限额需保存工作并另建底稿。公式不执行且不采用缓存；宏、外链与用户代码不运行。CSV/XLSX编码须用文本避免上游精度丢失。Windows实机未验证。
