# D03 财务对应规则

应用0.2.0，规则D03-2026-10-03.2。依据为用户的企业目标字典、对应规则、类别、范围、生效期及逐行确认；不内置中国或海外会计税务政策，不自动判定科目经济含义或法定政策有效性。

科目、客商、部门三类必须明确且隔离。主键为类别+范围+目标编码，名称不是主键。编码严格文本相等，前导零不合并。名称去首尾空格、忽略大小写由用户主动配置，只影响匹配，不改原值；别名仅在明确名称规则内生效。未知类别、缺范围、缺日期、编码名称均空、任何公式/错误值均异常。

范围精确一致，逐行业务日期有效。规则起止含边界，空端不限。优先级只排序，多个目标即冲突，包括未确认不同目标；不按高优先级覆盖。相同目标多规则只应用一次，保留全部规则ID。至少一条命中规则已确认且目标字典唯一时应用；只有未确认规则为待确认。撤销规则确认不意味着消除其多目标冲突，需修改规则或逐行复核选定目标。

字典同类别同范围目标编码必须唯一；重复或同键另有无效记录，不得选有效行绕过。编码或名称与字典完全相等可生成确定性候选，始终不自动应用。无编辑距离、概率或AI推断。人工选取只允许当前行同类别同范围唯一有效目标，须填写经办人与依据；异常行不能绕过。此确认只影响当前来源行，不改企业通用规则，不套用其他行。

逐行判断保存原始行、目标字典原行、字段及命中规则作为确认依据。换数据/字段/范围/规则清空当前判断；恢复后依据不一致拒绝确认。撤销回到规则原分类，保留操作登记。基线只比较规则内容；恢复基线清空当前判断并重新计算。

输入行=纳入+排除；纳入=已映射+待确认+冲突+未映射+异常。日期过滤遇无效日期保留纳入异常，不默默排除。排除行保留来源和原因，不算已对应。每原行唯一输出，所有原字段/文件/页签/行号保留。金额、币种、单位、期间只按原值保留：不汇总、不补零、不删除零负值、不自动换汇，不进行金额精度或容差计算。科目金额不是本工具确认会计分录的依据。

方案和含数据工作明确区分；schema_version:2，应用/规则版本严格一致。恢复重算且不接收运行缓存。版本比较、人工记录不等于企业审批或审计认证。独立手算答案见规格与独立预期.md。
