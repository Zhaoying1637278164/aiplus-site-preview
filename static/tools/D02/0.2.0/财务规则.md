# D02 财务规则

规则版本 D02-2026-10-03.1，应用版本0.1.0。2026-10-03起适用于中国企业结构化双表确定性核对；不涉及法定税率或会计政策判断。依据：用户批准的D02任务卡、[共同口径](../../docs/finance-rules.md)，参考工作步骤见参考来源。

文本复合键用JSON数组编码，前导零保留；文本去空格/大小写统一须启用。唯一一对一比较；同键任侧多条整组歧义，不强配、不相互抵消。无效关键字段与其对方记录同组无效，不伪造缺失。

金额十进制最多6位小数、24位数字；容差非负，默认0；左减右，绝对差额小于等于容差为一致。不支持隐式千分位、括号负数和自动舍入。空值无效、零合法、负值合法。币种须3位大写代码，冲突或缺失阻断比较，不换汇。

日期YYYY-MM-DD，校验真实日历且年份≥1900；Excel日期用UTC日读取。比较期间可选为文本字段，首版不猜表格所属期间。

公式不执行且不采用缓存，有公式字段进入无效输入。六类结果互斥覆盖两侧原行；每类列组数、左右行数，逐字段保留原值、规范值、差额、容差判定和源行。

界面要求用户确认两表主体、期间和金额单位一致（或已映射比较字段）；换数据/页签后重新确认。超过JavaScript安全精度的数值金额无效，须以原始十进制文本提供。允许合法输入相减产生更大的差额，差额不套用输入位数上限。

当前页面/方案/离线已实现并经Mac Chromium实测；官网和源码重建状态见progress/STATUS.md。Windows实机未验证。

## 0.2.0 当前业务规则补充

应用0.2.0；规则D02-2026-10-03.2。2026-10-03起用于同粒度一对一账表核对底稿，无中国或海外会计税务政策自动判断。原0.1.0冻结文件仍使用原版本，不能覆盖。

具体范围需说明主体、双方期间、单位、发生额/余额、税口径、每行粒度并确认。异期间须注明跨期追查目的；单位和方向不同请回源整理，不自动转换。最多20个范围条件；同方条件同时满足才纳入。范围值为空、公式或非法日期阻断运行，保留全部排除原行与理由；筛选后一方为空不能标一致。

Decimal40位精度按币种/金额字段分别核算。输入行数＝纳入＋排除；纳入＝六类覆盖。可计金额输入＝纳入＋排除，纳入＝配对＋单侧＋不可比参考金额；无效金额行数分别列示，不补零。配对原始差额＝第一方−第二方＝容差内差额＋超差额；容差内原差额保留，不置零。歧义和无效只作参考金额，不纳入配对差额，币种无效仅统计原行数量，所有金额汇总格为null并显示“不可汇总”，不得混加、不得置0；原始金额在来源明细保留。有效币种才计算金额守恒。

复核未复核→追查中→已说明待复核→复核通过；退回/撤销通过回追查中，需要人员和操作依据。说明/通过需原因及说明；所有操作留历史、时间、自填人员和可选证据索引。状态不改原值、金额和类别。不可比资料即使全部复核也不能标完成。无未决及不可比资料时可标“本次核对已复核”，不等同账务准确/已入账或身份签名。

每项历史最多100条，事项全量历史最多10000条，单字段10000字；更换资料、页签、表头、口径/筛选均令当前结果与复核失效，旧运行仅供历史摘要。无数据方案schema2保留映射、文本处理、容差与筛选字段定义，清空实际主体/期间/来源名/目的/筛选值，不包含复核或结果；恢复后重选范围值和确认。0.1.0无数据规则明确迁移，其他版本拒绝。

含数据工作底稿schema2限制10MB，完整验证结构、行列/原行标识、版本、重算结果、排除与金额勾稽、复核事件回放及末态；不能验证身份或防止整体重新伪造，因此复核为本机自填记录。输出超过恢复上限会拒绝JSON保存并提示用XLSX/缩小事项。只保存当前有效运行；过期运行不可冒充当前。暂不支持附件、任意外链、用户代码执行。
