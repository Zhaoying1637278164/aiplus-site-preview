# R05 坏账计提表

版本0.1.0，阶段tested。正式程序与源码包已由总控生成，官网接入及最终accepted仍待独立验收。Windows实机未验证。

本款依据用户已批准的组合损失参数或个别评估金额，测算截止日坏账准备，并用独立账面期初/期末及有符号本期变动形成复核底稿。八页覆盖工作总览、余额/账面、评估分配、参数依据、测算、准备变动、例外复核、版本比较和底稿。

## 使用

1. 解压离线包后双击同目录 index.html，项目正式构建在 release/R05/0.1.0/index.html。官网接入验收后由原应收「坏账计提表」条目进入同版本业务程序；当前官网接入仍待验。
2. 可主动载入完全虚构样例：组合1000×5%=50、200×5%=10，个别300损失90；CNY目标150，独立账面期初120，加计提50、转回-10、核销-20、收回5，账面桥145。未来100不回写，目标与账面差5。
3. 下载中文多资料模板.xlsx，填五类资料。每类CSV/XLSX独立导入，选择页签与表头，确认才替换；取消保留原工作。对已批准参数的修订须明确确认新内容已获批准且当前依据适用。
4. 用户可主动选择R04底稿的「逐票勾稽」静态页签，明确确认主体、截止日和客户/单据ID、币种/单位/含税口径。不会读取R04内存或按逾期直接决定损失率；原始R04列和行来源保留。其他格式需整理为本款模板。
5. 每条应收主体/客户ID/单据ID恰好指定一条已确认组合或个别分配，指定参数ID+外部版本。不以姓名合并，不自动取第一组或最新参数。个别金额不可超过资产，组合不可再叠加个别金额。
6. 参数须用户外部已评估提供、已批准、生效期覆盖截止，并明确企业适用资格及条件、审批日期与依据。损失率格式百分比填5表示5%，小数填0.05表示5%；无官方固定比例，无默认损失政策。
7. 重新计算，在例外页修订对应原行、查看缺失账面/变动和差异；复核记录不会解除阻塞。资料/规则修改清除旧结果、旧复核失效，参数/规则变更自动保留修改前完整比较版本。外部版本名由用户维护，工作修订另行记录；最多5个比较版本，可先主动下载再移除，原内容仍留事件。
8. 主动下载完整XLSX、含数据完整工作JSON或不含数据方案。完整工作含明细、事件、版本和复核；不含数据方案只含设置与损失参数（主体和批准依据仍保留），不含明细/账面/变动/事件/历史版本/复核，恢复清空旧资料。含数据恢复从原始资料重算。

## 口径与边界

金额Decimal40位，输入最多6小数/24数字，精度0..6，容差只标记差异。组合汇总后舍入，逐行向下取精度，尾差按余量降序及原输入顺序分配并保留归属；精度不足致金额超过资产时阻塞并要求提高精度。各主体/币种/单位/含税口径分别计算，空不为零，不自动换汇/换单位，负额隔离。

首版仅支持用户确认已执行CAS22的普通收入应收款，未含重大融资或含融资且已选择简化方法，并已提供整个存续期外部损失评估。财政部2017修订原文与2021官方实施问答的边界已核验；完整应用指南全文未取得。三阶段、贷款/财务担保/关联借款、租赁/合同资产、购入已信用减值、现金流折现等范围具体阻塞；无AI/OCR、记账分录或自动满足ECL准则的承诺。

## 隐私、限额与追溯

只在浏览器内存读、算、导出，不上传、记录到服务器、遥测、默认持久化、CDN/字体联网；关闭/退出/dispose清内存。拒绝宏、外链、公式及缓存、任意用户代码。公共文件10MB、解压30MB、20000行/200列，本款总资料5000行、事件/复核各200条、比较5版、工作及导出10MB、底稿12000行，超限阻塞不截断。Excel底稿长事件/历史版本以9000字片段存于「长文本分段」，用文本ID和顺序完整拼接；不丢失原轨迹。

界面事件表显示财务动作、影响行数/范围、工作修订，主动打开完整事件或单独下载；完整JSON及XLSX仍保存原始前后值。原行保留文件/页签/原始行号，手工修订也保留原记录。

## 开发与接入

沿用根锁文件：`npm ci`；`node --import tsx --test tools/R05-坏账计提表/tests/*.test.ts`；`npm run typecheck`；候选构建 `node --import tsx tools/R05-坏账计提表/tests/candidate-build.ts`；Mac Chromium浏览器 `node --import tsx tools/R05-坏账计提表/tests/browser.ts`。业务引擎与React分离，program.tsx导出ToolProgram，main.tsx同组件离线挂载，releaseAssets返回真实中文模板及完全虚构样例。
