# R05 财务规则 2026-10-03.1

应用0.1.0。用于用户已批准参数的测算与复核，不能替代企业预期信用损失评估、会计政策选择或账务审批。

1. 截止余额必须来自用户主动导入的静态资料，时点确认=已确认，截止日一致；主体/客户ID/单据ID/币种/单位/含税口径必填，编号原样保留。客户姓名不作为关联键。负余额隔离、空金额不可量化；无净额抵消。
2. 每个主体+客户ID+单据ID必须恰好有一条已确认评估分配，组合或个别互斥；重复/无分配/撤销等不被忽略。参数ID+版本必须唯一，分配指定该版本，不自动挑选未来/最新版本。组合依据与个别依据必须存在。
3. 参数必须用户外部已评估提供、已批准，企业适用资格=已执行CAS22，减值口径=整个存续期，适用条件=收入应收无重大融资 或 收入应收融资已选简化；资格依据、条件依据、批准依据、批准日、生效起止、币种单位税口径均明确；批准/生效日不能晚于截止，结束不能早于截止。其余范围阻塞对应明细。参数可保留草稿，但不参与计算。
4. 法源是财政部2017修订第22号第四十六/四十七/第五十八至六十三条及官方2021-04-25问答。通知按2018/2019/2021分批执行，2020通知有特殊延期，不依据当前日期推定企业资格。无官方固定账龄损失率，逾期不能自动判断损失。完整应用指南尚未全文核验，三阶段、现金流折现、购入信用减值等未实现，阻塞对应功能。
5. 组合损失率格式明确百分比（值5表示5%，不得写5%）或小数（值0.05表示5%），区间0..100%含两端；空不为0。个别参数率可空，但分配的金额必须0..正余额且有外部依据；不得再叠加组合率。已有准备是账面资料，不减计提基数，不采用本工具输出充当账面。
6. 输入最多6小数24数字，Decimal40位；计算精度0..6。组合先按同参数/同口径精确汇总后四舍五入，逐行向下取精度后按余量降序、原行顺序平局分配最小单位，守恒差必须0。个别金额四舍五入需展示差额；舍入后若超过资产则阻塞，不能用容差放行。
7. 每个主体/币种/单位/含税口径单独汇总，汇总展示正额、负额、阻塞金额、不可量化条数及可计算部分；存在未计算/负额时完整目标留空，而非把可算部分当完整目标。无换汇/换单位。
8. 独立账面资料必须按范围唯一，期初日=本期开始日（期初余额）、期末日=截止日，非负期初/期末准备与来源依据明确。已确认完整变动声明：已完整提供 或 本期无变动。资料缺失不能补0。
9. 变动用户确认且有批准依据/批准日、生效日：计提/收回金额>=0，转回/核销<=0；同一ID重复阻塞。收回仅指用户确认增加准备的有符号账面变动，不自动推导收款分录。期前/未来单列，不回写本期；任何本期异常使桥留空并显示已验证部分。期初+有效变动=桥，桥-独立期末准备、目标-独立期末分别核对；桥负额阻塞。不同变化类型不能替代完整账务逻辑。
10. 资料/规则每次修改增工作修订号，旧结果清除、旧复核失效并留历史事件；主动命名快照比较逐单据新增/删除、基数、准备、参数版本与口径不可比。含数据JSON包含原始资料/版本/事件/复核，恢复从原始重算；无数据方案仅参数表/工作设置，清明细/分配/账面/变动/事件/快照/复核。方案中参数不携带客户或单据字段。

11. 修订已批准参数需再次确认新内容已获批准且当前日期/依据适用；修改参数或工作规则自动保存修改前完整原始版本。最多5版，主动移除保留完整内容于事件；外部参数版本名与本工作修订号分别记录。R04静态逐票输出导入需用户明确主体/时点/ID及口径；正应收/零/负余额状态可转换，异常/未来状态未确认并阻塞，无自动损失率。
