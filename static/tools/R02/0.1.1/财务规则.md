# R02 财务规则

规则版本R02-CN-2026-10-03.1。中国企业会计准则第14号收入（2017修订）适用性、合同资格、履约义务划分、时段/时点、总额/净额、分配额与变更类型由用户专业判断并提供依据；本工具不自动决定，缺失阻塞。准则第三条排除范围不在本工具默认处理范围。生效范围见参考来源；不替代小企业/政府等不同准则。

时间首尾日都含，UTC日期避免时区偏移。用户批准按日时，各月权重为覆盖日数；涉及月份等额首尾各一份，需用户明确接受；月内折算各月权重为覆盖日数/该月天数。按日截止日可拆当月；月口径月末到期。里程碑是用户批准的时点或产出进度依据，未完成只显示未来/待履约计划，真实完成日决定截至日到期额。完成不等于记账。

基础额非负、零允许。最多24位数字6位小数；货币精度0–6，输入额须能精确表示，禁止静默舍入总额；累计份额取整、末期守恒；容差独立用于实际差异警告，不能掩盖排程守恒。Decimal独立clone精度60。币种单位均为用户显式输入，合同内一致，跨合同总览分别列示，不自动换汇。

合同额独立于履约分配额，分配合计以用户已确定的收入交易价格为准，不能用合同含税总额替代；票款不导入引擎。实际收入另表，负冲回允许但依据必填，重复/无关联/币种单位冲突不自动并入。保留实际原记录，截止日后的收入单独列示。

变更采用用户已批准的新总分配额和未来期间，只从一个新月份重排，生效月不能含已确认记录且不能在冻结期。历史计划保留；历史已确认不变。新剩余=新总额-历史计划-当期调整；终止须剩余零；需累计追补/冲回由用户指定当期调整，不自动生成政策判断。退款只按批准的收入调整版本生效，不能由退款票款直接推导。每次变更有稳定ID、版本、依据，按月份严格递增；原版本快照留存。跨月/不确定专业判断由用户拆分批准，本款不自动执行准则所有复杂场景。

工作下载含schema_version、应用/规则版本、是否含数据；含数据全工作保留原行/参数/版本，恢复重算；无数据方案只保留规则参数、不得保留客户金额。关闭释放内存；无上传/遥测/日志/默认持久化；公式缓存绝不采用。

恢复允许严格限定的惰性公式原文/缓存元数据以保存待处理原行；公式与缓存不参与财务计算，不执行任意对象。未完成里程碑按截止日仅计里程碑，不能将未来周期服务混入此列。
