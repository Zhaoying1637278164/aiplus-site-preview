# R02 收入确认排程表

源码候选0.1.0。用于中国企业财务把已批准的履约分配额排到期间，并和独立账面收入核对。八页：工作总览、合同与履约事项、排程口径、里程碑、已确认收入、月度排程、变更与调整、异常与底稿。

## 操作

1. 工作总览可体验完全虚构样例，或到合同与履约事项导入自己的静态CSV/XLSX。每类中文模板可单独下载；XLSX选择页签与表头行。可手工新增/修改记录，修改前保留内存版本。
2. 合同金额与收入交易价格分别输入；每项履约分配额合计须勾稽收入交易价格。明确合同ID、客户ID、履约ID；与R01仅能用户主动导入明确ID，不自动读其他工具。
3. 用户填“适用中国收入准则：是”、确认类型“时段/时点”、总額净额“总额/净额”、判断依据。排程方法“按日/月份等额/月内折算/里程碑”；时点须用里程碑。没有批准依据会阻塞，不能自动判断。
4. 里程碑填写金额、计划日期；完成时填真实完成日和验收依据。已确认收入从独立账面记录导入，不从合同、开票或回款推导。
5. 设置截止日、金额精度和差异容差、冻结月份后计算。按日含首尾日；月口径按月末到期。累计份额取整、逐期取差，末期累计严格回到总额。极小金额允许零月份，不产生无依据负收入或越总额累计。
6. 变更从未冻结且无已确认记录的月份首日开始。用户批准新分配额、未来期间、当期调整和处理方式“重排/终止”。已确认原记录不变；需要冲回由用户明确批准负调整。月中变更及里程碑直接变更首版阻塞，须人工拆分批准。
7. 检查异常与底稿；阻塞事项不计有效金额，导出明确为待复核。查看原行保留文件、页签、行号、原始字段。汇总分币种/单位，不自动换汇。
8. 主动下载含数据完整工作、无数据方案或XLSX完整底稿。含数据工作保存客户、金额、来源、参数和最多20份版本；无数据方案只含参数，恢复会清空資料。含数据工作恢复严格检查并重算。换数据/参数旧结果失效。

## 安全与限制

全部文件仅在浏览器内存读取计算，无上传、日志、遥测或默认持久化；关闭清除。仅静态UTF-8 CSV及XLSX，10MB/文件、解压30MB、20000行/200列、单元格10000字；宏、外链与代码不执行，公式及缓存不作金额。金额最多24位数字/6位小数；原额超过所选精度阻塞，空不补零。单事项最多1200月、总排程20000行；导出分表每页签最多20000行，完整底稿限100万单元格/10MB，超限提示用户先保存完整工作后减少版本。

专业判断仍由用户负责。未实现合同审批、开票接口、CRM、AI/OCR；不自动处理复杂政策。候选本机Mac Chrome验证不等于官网或Windows验收。正式登记、发布、同版本源码ZIP及accepted由总控独立处理。

开发：根目录`node --import tsx --test tools/R02-收入确认排程表/tests/*.test.ts`；`npx tsc --noEmit -p tools/R02-收入确认排程表/tsconfig.json`；`node --import tsx tools/R02-收入确认排程表/tests/build-candidate.ts`。候选仅输出到progress/evidence/R02，`tests/browser.ts`使用本机Chrome断网验证。
