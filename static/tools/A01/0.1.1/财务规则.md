# A01 财务规则 2026-10-04.1

适用：用户确认执行中国企业会计准则、月度、单一主体币种单位。财会〔2006〕3号自2007-01-01上市公司实施、鼓励其他企业执行；本工具不适用于政府/小企业准则。全部金额必须显式填写，最多6位输入小数、计算精度40位，结果0–6位HALF_UP；勾稽容差单独设定不改变计算。账面净值=原值-累计折摊-累计减值；不得低于零/剩余残值，应折额取净值-残值。

固定资产：准则4第14–20条，按月；单独土地及提足折旧不提。新增下月提，减少当月提完转出（财政部2023-12-25引用应用指南）。无形：准则6第16–21条，有限寿命自可供使用月起摊；减少月停止；无法可靠判断收益方式用直线法；非零残值必须第三方购买承诺或活跃市场依据；不确定寿命不摊销。用户提供起始月须符合上述时点，不得任意跳过。

期初累计为排程起点以前已入账的实际累计；剩余月显式填写。直线额=分段应折额/剩余月，末期补差。年数总和按整年寿命，年权重N…1除N(N+1)/2再除12；双倍余额递减每年期初账面额×2/N/12，最后24月按剩余净额直线。两加速法仅固定资产、无期初折摊/减值、整年寿命且不少于3年，或未来变更建立全新分段；原加速资产期初年基数无法验证阻塞。工作量法=分段应折额×本期工作量/总剩余工作量，必须完整逐月数据（零也填），合计总量相等且非负；仅按实际工作量分摊，不按缺失补零。

事件：必须批准人/依据，一资产同月一事件，生效在排程内。追加净资本化金额增加原值；减值增加减值准备并减少后续基础（不允许冲回，不代替减值判断）；变更须给剩余月/新残值/新方法，按会计估计未来适用。追加/减值/变更在生效月月初使用新剩余基础，生效月应由财务按实际可供使用及批准时间决定；新增部分若应次月开始，以次月作为生效月。无形处置月不摊，固定处置月照提，月末将全部原值/累计/减值转出，单列处置净值。只处理整项处置，替换部分/持有待售/重新启用复杂事项阻塞而非猜算。

确认截至月保存每行完整数值/来源/政策/事件；重新计算若任何已确认行变化则阻塞，不覆盖历史。换数据是新工作，必须明确同意清空确认；恢复保留历史并重算。方案不是防篡改审计系统，不支持数字签名或多人审批。

税法：实施条例2008-01-01施行，第59/60固定直线/次月/最低年限，第67无形直线及通常10年，残值与会计规则不同。税务排程功能明确阻塞：尚未核验特定主体、计税基础、优惠条件及例外，无税会自动调平。会计减值不自动减少计税基础（第56条）。不确定规则只阻塞对应功能，不编造政策。原链接、日期、章节见参考来源。
