# T06 外币敞口与汇兑测算

应用版本0.1.0，规则版本T06-CAS19-20261004.2。用于期末外币余额、汇兑变化与汇率情景的财务复核。

用当前浏览器完成单一主体、余额日和本位币的外币余额复核。提供九个业务页面，保留逐笔账面与期末折算、收益符号、币种敞口、明确管理抵销、汇率情景、异常复核、原始行与维护记录。金额和数量不混合，收益正、损失负。

## 打开工具

官网使用：在AI+观策数智财务工具箱的“资金”模块进入“外币敞口与汇兑测算”详情并打开工具，在同站页面完成资料导入、计算、复核和下载。返回资金详情或关闭工具会清空本次内存资料，请先下载需要保留的工作。

离线使用：在工具详情下载离线包，将ZIP完整解压到一个文件夹，用Chrome或Edge双击其中的index.html。无需联网，断网也能导入、计算、恢复和下载底稿；不要直接在压缩包预览窗口运行。说明、模板、虚构样例和第三方声明随离线包提供。

第一次使用可先点击“体验虚构样例”，再点击“重新测算”。所有样例完全虚构，不是市场汇率或实际企业资料。点击“下载虚构样例 XLSX”可取得余额、期末汇率和情景三个页签；自己的资料可参照各页面的空白CSV模板准备。

页面导航依次为工作范围、余额资料、手工汇率、货币性复核、币种敞口、期末汇兑、汇率情景、差异与来源、工作与底稿；可随时返回修改。修改资料或规则会清除旧结果，须重新测算。

## 使用步骤

1. 在“工作范围”填写主体、余额日、本位币、金额小数位、历史参考复核容差和政策适用依据。确认本主体本期执行企业会计准则的依据与普通货币性期末试算范围。2007-01-01之前仅保留数学试算，勾选不能解除生效日期阻塞。
2. 在“余额资料”导入UTF-8 CSV/XLSX。选择页签、表头行及字段对应，确认后导入；也可逐笔新增。外币数量、账面本位币金额和资产/负债方向分别提供，金额单位统一元。禁止空值补零。负数冲回须填写有效原笔ID与说明，单位、范围、方向、政策和抵销组必须与原笔完全一致（包括空组），累计数量及账面不能超过原笔。
3. 在“手工汇率”导入或逐币种录入期末汇率。1 USD=7.1 CNY是本位币/外币；1 CNY=0.140845070422535211 USD是反向。更改方向不会自动改数值，须重新确认，未确认不能测算。
4. 在“货币性复核”逐笔设置分类、普通或特殊政策、依据，最后批准。导入时旧批准清除。普通预付预收不自动判为货币性；未知、非货币性和特殊政策阻塞对应普通会计结论。
5. 在“币种敞口”明确管理抵销组和依据，批准后仅同主体同日同币种组内抵销。管理抵销不修改会计汇兑，不代表财报列报抵销或法律净额结算。
6. 重新测算，在“期末汇兑”复核逐笔和汇总。资产损益=期末−账面，负债损益=账面−期末。账面使用用户提供的当前值，历史汇率仅做差异核查。逐笔舍入与总量重算尾差保留。
7. 在“汇率情景”录入归一汇率变动百分比或绝对本位币/外币汇率，重新测算后查看逐笔变化和币种汇总。净USD60，基准7.1的+1%情景变化4.26CNY。
8. 在“差异与来源”追查原始行、修改前后记录，填写问题复核人和备注。备注不能解除硬校验，修正资料后重新测算。
9. 在“工作与底稿”主动下载完整13页XLSX、逐页CSV，以及可恢复工作JSON。含数据工作保留全部资料；无数据方案不含余额、原表、维护及复核，但包含规则与用户汇率/情景假设及依据文本。恢复后重新计算，不信任缓存结果。旧规则版本JSON会明确拒绝，须重新导入原始资料并复核批准。

## 文件与隐私

文件只在当前浏览器内存读取、计算和导出，无上传、日志输出、遥测、在线汇率或默认持久化；关闭或清除即释放本次工作。不运行宏、公式、外链或用户代码；XLSX含公式或错误单元格拒绝，CSV中的公式文本只作文本或无效数字，导出防止表格公式注入。

单文件10MB，解压30MB，公共最多20000行/200列/单元格10000字符；本款余额1000条、汇率100条、情景100条，来源快照30份、维护/复核5000条。超限须分批处理。源数字超安全精度须改用十进制文本，金额/数量最多6位小数，汇率最多18位；Decimal80位中间计算，逐笔half-up舍入至0–6位。容差只作历史参考差异复核，不调整结果。

所有示例完全虚构。普通会计结论有适用条件，非货币性、资本化借款、套期、境外净投资、缺乏可兑换性及其他特殊政策不在普通当期损益实现范围；未知明确阻塞。此工具不记账、不估计市场汇率、不做税务、境外报表折算或套保交易建议。余额是同日静态余额，情景不预测收付款，也不把管理净额当作到期匹配套保。
