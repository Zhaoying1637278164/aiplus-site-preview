# T06 财务规则

规则T06-CAS19-20261004.2，访问核对2026-10-04。金额单位统一元；用户显式选择非CNY本位币可以计算，不能跨本位币汇总或宣称人民币报表已编制。

依据财政部[《企业会计准则第19号——外币折算》](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/200806/t20080618_46229.htm)（财会〔2006〕3号）：第3条特殊借款费用、套期和现金流量适用其他准则；第4–8条本位币选择；第10条初始确认；第11条货币性定义和期末折算；第12–15条境外报表折算不属于本工具。[财会〔2006〕3号施行通知](https://kjs.mof.gov.cn/zhengcefabu/200805/t20080522_33653.htm)落款2006-02-15，规定自2007-01-01在上市公司施行、鼓励其他企业执行，适用主体须由用户确认执行企业会计准则。历史适用范围不能自动推及所有企业。本款只提供用户确认适用的普通货币性期末试算，不自动入账。

财政部[2021-03-02预收预付款实施问答](https://kjs.mof.gov.cn/zt/kjzzss/sswd/wbzs/202103/t20210302_3664191.htm)：普通预收/预付款属于历史成本非货币性，不按期末汇率产生汇兑。退款请求权等变化须用户另行判断，本款不按科目名称自动分类。

财政部[解释第20号正式通知](https://kjs.mof.gov.cn/zhengcefabu/202606/t20260615_3991686.htm)（财会〔2026〕7号，2026-06-04落款，官网2026-06-17刊发）：第二部分可兑换性评估、估计汇率、披露和衔接；第三部分自公布日起施行，2026-01-01至施行日新增业务按解释调整。本款不估计不可兑换货币的汇率，也不生成首次执行/披露会计结论。未确认可兑换或不可兑换一律阻塞对应普通损益。

普通货币性余额：归一汇率r=直接报价或1/反向报价；期末V=外币数量×r；资产损益V−账面，负债损益账面−V。收益正、损失负。当前账面可能是初始或上期末值，历史汇率仅用于异常核查，不覆盖已有账面。每笔按用户精度舍入，损益以舍入期末减账面舍入计算；原始未舍入差额与舍入差同时导出。净敞口=资产数量−负债数量；情景变化=归一情景汇率估值−基准估值，方向同损益。期末总量重算与逐笔期末合计之差保留，不以容差调平。

分类/依据/批准缺失、政策不适用、非货币性、资本化、套期、境外净投资、不可兑换及其他待确认项目都阻塞普通当期损益；有效货币性可保留数学估值和情景但清楚标为政策阻塞。任何部分结果有排除行均显示覆盖，不能称全部资产损益。

管理敞口抵销仅用户明确选择同一组并批准依据，在主体/币种/时点/本位币内计算min(资产,负债)，空组不抵销，不视为法律净额结算或财报列报抵销。禁止跨币种相加数量。负数必须明示冲回及原笔，累计不得超过原正数，零有效。异常复核备注不能解除硬校验。

生效期硬校验：余额日早于2007-01-01，数学估值保留，普通损益全部阻塞。2007年及以后仍需用户确认本主体本期采用准则并填写依据，工具不独立认证主体的准则采用资格。

冲回原笔须通过ID唯一、主体、期间、本位币、币种、单位、金额、货币性分类和唯一有效汇率的基础校验，且原数量为正、账面非负、不是另一冲回。冲回与原笔的政策及抵销组完全相同，包括空组。只对有效关联冲回累计，超额则排除该原笔的全部有效关联冲回；无效行不污染累计。原笔政策未批准或缺依据时，冲回保留数学试算但阻塞普通损益。管理抵销还检查不超过剩余资产和负债，未抵销敞口非负；不截断数字掩盖问题。
