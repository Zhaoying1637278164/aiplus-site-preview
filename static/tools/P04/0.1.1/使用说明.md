# P04 供应商对账

本款归原应付模块 `tool-ap-06`。TypeScript + React 原生工作区与离线HTML使用同一 ToolProgram；候选宿主不是官网。所有数据在浏览器内存，退出清空，主动下载保存。无AI/OCR、付款、记账、税务判断、换汇或邮件外发。

## 财务工作

11页：范围总览 → 本方资料 → 对方资料 → 往来口径 → 供应商对应 → 单据关联 → 收付衔接 → 差异复核 → 版本比较 → 来源底稿 → 本地对账单。

分别保留双方期初、增加、付款与期末；标准化方向须批准。每方 `期初+增加-付款-期末` 和双方差异衔接分别检查，差异=本方−对方。流水四项与仅期末快照分开，缺失不补零。虚构样例本方100+80−60=120，对方100+80−50=130，付款差10、期末差−10。

供应商名称不作键；001与1不同。不同编码须批准一对一对应。稳定单据键只提严格候选、用户确认；人工支持部分关联/一对多/多对一。双端累计不得超实际标准金额，容差不放宽额度。批次任一坏行/重复ID/超额则全批隔离；撤销保留日期依据并恢复双端。

## 输入与输出

.xlsx / UTF-8 .csv：单据ID、供应商ID、名称、主体、期间、币种、单位、税口径、明确业务类型、金额、稳定关联键、原期间、到期日。文本编码保留前导零，数字编码不猜补零。导入预览可选页签/表头物理行，映射按物理列号，同名表头完整原值保留。只有确认才替换或追加；取消不改工作。重复同内容导入幂等，不增加事件；冲突追加保留完整原行、重复整组阻塞，可依据批准替换新资料恢复。

完整XLSX/逐表CSV包含汇总、标准化往来、原始单元格、字段映射、范围规则、供应商对应、确认关联、事件、异常勾稽、复核、基线/版本差异、隔离批次、关联/隔离导入原始单元格、历史原始单元格/规则/关联复核、基线来源。完整历史工作JSON另保留原版本、原始公式对象（不执行）、资料、规则与批准。CSV危险文本安全前缀，XLSX不创建公式。

本地CSV对账单含四项、差异、范围与来源；保留异常，非账务确认。无数据方案只带规则与对应，明确contains_data=false；确认恢复清空全部原业务、事件、关联、复核、隔离和基线。含数据工作重算原始资料并重放确认撤销；非法方案保留旧工作。恢复预览取消完整旧工作相等。基线包含原资料和规则，恢复验证重算一致，口径/新资料保留基线便于比较；旧关联/复核失效留事件。

## 安全及边界

单文件与整个JSON工作10MB，ZIP声明和实际解压30MB，全部工作簿页签/双方业务资料20000行、200列，文本单元格10000字；2000事件/有效关联、100来源/隔离批次、2000对应。导出每页签25万行、全工作200万格、单文件10MB；超限明确拒绝而不截断。XLSX对象单元格32767字以上拒绝，完整历史可用工作JSON。达到历史或导出限额应减少当前范围，不能假定所有最大限制可同时达到。

不上传、不日志用户资料、不遥测、不默认存储、不外部请求/CDN/在线字体/自动更新；宏/外链/危险ZIP拒绝，公式缓存不参与计算。关闭浏览器清除运行内存；方案仅主动下载保存。日期/期间/方向不被关联或修订改写。财务政策仅批准输入与确定性勾稽，尚未核验的自动政策判断不提供。
