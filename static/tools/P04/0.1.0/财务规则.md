# P04 财务规则 0.1.0

规则版本P04-2026-10-03.1，应用0.1.0；依据为用户批准输入及确定性数学勾稽，适用明确主体/期间/供应商编码/币种/单位/税口径，非中国或外国会计税务政策。本工具不判断发票应付、含税拆税、付款合法性或实际余额正确性。

标准化：每方每类型原金额×批准方向（+1或−1），正期初/增加/期末为往来，正付款为减少，负付款为退款；未经批准阻塞该方计算。原金额/期间/到期日与物理来源独立保存。名称不关联；文本ID前导零不处理。用户精度0—6，Decimal40有效位计算，18整数位/6小数位输入上限；超过批准小数精度拒绝，不四舍五入。容差仅用于比较/勾稽，不放行额度。无换汇或单位折算。

期间流水：每供应商期初/期末恰一条，增加/付款至少一条（用户可明确0证明无发生），缺项不补零，类型冲突阻塞。每方残差=期初+增加−付款−期末；差异=本方−对方，差异桥残差=期初差+增加差−付款差−期末差。期末快照只读期末，不接受任何流水行，不显示伪造期初发生额勾稽。没有完整有效资料的方汇总全部缺失，独立异常追到具体行。

同ID默认可比较；不同ID须批准一对一供应商对应。不同名称同ID仍展示原名称，名称不替代ID。范围不一致、空值、格式、未批准方向、重复ID包含坏行、缺必需类别，均隔离并阻塞汇总。任一ID重复同方全部记录隔离，不能挑有效行。新资料相同内容与映射重导入幂等；不同内容追加重复冲突阻塞，批准替换保留旧版本。

分配：源行ID唯一且有效、同供应商组与类型、标准金额>0、双方剩余额度足够。负/零金额可勾稽但不能关联分配。批次原子验证全部记录，两端逐项累计；任何重复ID、无效金额、源行不唯一、跨范围或超额全批拒绝，保存完整隔离原数据，不先来先占。严格稳定键候选必须双方唯一且剩余等额，仍须用户依据批准。人工一对多、多对一以多条分配体现；不自动调整余额。

确认事件保存关联、日期、依据。撤销只针对活动关联，须日期/依据，重复撤销拒绝，恢复原两端额度。资料、方向、供应商对应修订使原活动关联与复核失效，版本事件保存原资料/映射/规则/批准/活动关联/复核/基线。用户可重新确认。保存基线包含原资料与原口径，恢复独立重算基线；资料变更保留基线供比较，现旧缺项时变化不补零。复核状态不解除技术异常和额度规则。

恢复含数据工作：版本与schema一致、上限与结构验证，分段使用历史资料重新验证确认/撤销，当前原资料重算，拒绝超额、无效撤销、篡改基线。无数据方案仅规则/批准对应，不含任何业务/事件/隔离/复核/基线。取消/非法恢复不改变旧工作；确认替换。退出取消保留完整工作；确认清空并dispose；重入空工作。

独立手算与边界见规格与独立预期.md。所有样例完全虚构。未提供自动会计税务政策；对应功能边界明确，不借海外默认政策代替中国输入。
