# E05 费用分析看板

0.2.1候选，十页费用分析工作流。费用资料、组织科目映射、金额口径、期间总览、部门科目结构、趋势、固定变动分类、供应商项目、异常复核、明细来源与可恢复底稿。预算实际计算归B02。

用Chrome/Edge打开候选index.html，先载入完全虚构样例；自己的静态CSV/XLSX在浏览器内存导入，选择页签和表头并确认替换。映射可以不导入（保留原编码）；一旦导入，费用须有唯一有效期对应。金额字段可配置，必填ID、期间、主体、部门、科目、币种、单位、选用金额；原金额还需金额口径。选择口径并勾选确认后分析。含税/不含税静态列缺失会阻塞，不按税率估算。

期间总览选择币种、原单位、趋势起止期间、本期/比较期及维度。部门科目、分类及可用供应商/项目结构点击名称打开同一筛选下的明细。缺供应商列或没有有效供应商值显式不可用；部分缺值单列未提供。明细查看原始行与映射来源，底稿保留16张表、精确金额和完整参数。

金额使用Decimal精确计算，0容差勾稽；显示0—6小数、元/千元/万元不改原值。零保留；负数为冲销/退款复核线索；重复ID整组排除。无资料月份和不存在的比较期不补零；比较期<=0时不算增幅。净总额<=0时结构占比不可解释。异常复核状态不改金额也不绕过阻塞。

用户数据只在浏览器内存处理，不上传、不写日志、不遥测、不默认持久化、无CDN及外部请求。关闭、清空或退出即清除。方案由用户主动下载；无数据方案仅参数，恢复清空资料并要求重新确认；含数据工作包含三表与复核，恢复重新计算。含数据JSON最大30MB，导入原始文件每个10MB、解压30MB、20000行、200列；公式/宏/外链不执行。
