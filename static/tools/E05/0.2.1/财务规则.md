# E05 财务规则

规则E05-2026-10-04.2，管理分析口径，自2026-10-04版本起生效。无税法判断、自动换汇、预算计算或会计认定。

1. 一行一笔费用记录，ID全表唯一；重复ID全组排除。期间YYYY-MM（1900—2199），主体、原部门、原科目、币种、单位、金额必填。单位仅元/千元/万元，转换回原币种元后Decimal求和；分析必须选择同一币种和原单位，不混加。金额最多六位小数，最多24位数字；空、公式、危险数值无效，零保留，负值保留并复核。
2. 金额选择原金额/含税金额/不含税金额。原金额需资料声明含税/不含税/账面费用，并用户确认；选含税/不含税仅读取对应静态列，不按税率推导或混用缺失列。每行声明须与选择一致；依据未知阻塞该行。此为用户管理口径而非税务扣除政策。
3. 部门映射字段原部门/目标部门/开始期间/结束期间；科目映射原科目/目标科目/固定变动/开始期间/结束期间/依据。映射按全表原编码、行期间匹配；原编码须跨主体统一，不支持同编码在不同主体的不同映射，须先提供唯一编码。仅当导入映射表时要求唯一有效映射；重叠、多目标、缺映射排除对应费用。不导入则保留原维度，不自行猜测。固定/变动/混合由用户明确输入或科目映射；没有分类为未分类，纳入守恒。
4. 有效金额按筛选期间、币种、单位和维度范围选取；全部部门、科目、分类与可用供应商/项目结构均守恒于所选明细净额。缺维度列标不可用；有列部分缺失以「未提供」列示覆盖。占比=分组净额/总净额，总净额<=0时占比不可解释，留空。负值占比保留，非成本因果。
5. 比较范围沿用所有维度/币种/单位筛选，但单独选择本期/比较期；不受趋势起止范围影响。任一期无记录则金额及差额/增幅留空；上期<=0则增幅不可比；增幅分母为比较期金额，不将新增科目当无限增幅。逐月缺资料留空不补零。分组差额为记录存在的双方金额变化，缺一方不可比；明细可以复核每期组成。
6. 单笔绝对金额关注阈值、期间增幅阈值均用户输入，与显示精度及守恒容差分离；阈值默认10000元/30%仅示范无中国政策含义。守恒容差固定0，金额不逐行四舍五入；显示精度0—6位仅影响显示；导出提供精确十进制元值与显示单位值。复核状态与依据不改原值、不移除异常，换资料和口径清除旧复核。
7. 来源含文件/页签/原行/原单元格、映射规则行；每组保留费用来源键。本期总额不是全年推断。未纳入、未选择、有效所选分别列示计数；问题行原资料保留在底稿。
