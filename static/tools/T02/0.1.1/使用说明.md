# T02 资金日报
应用 0.1.1。解压离线包后，用 Chrome 或 Edge 双击 index.html；无需安装，断网可用。先体验完全虚构样例，再导入本机资料。用户数据只在浏览器内存，关闭或退出清空。源码包包含锁文件、共享包、本款代码、测试、说明与声明。Windows 实机未验证；官网验收状态见项目 progress/STATUS.md。

打开总控后续交付的离线包index.html，以Chrome/Edge使用。先载入完全虚构样例，再维护自己的主体账户和每日日末余额依据，导入本机静态CSV/XLSX，映射物理列，确认追加或替换。数据只在浏览器内存，无账号、API Key、上传或默认持久化；关页清除。

1. 账户与余额：范围、单位币种、账户ID、每日独立余额、无交易依据；金额空不等于0。
2. 收付款资料：页签/表头行/物理列映射、预览取消确认、原行搜索筛选分页追查。
3. 分类与调拨：规则建议逐行批准；双边调拨精确匹配后批准，撤销保留历史。
4. 日结与连续：逐日核对计算期末与独立期末，按前日同键批准日结结转。完整期间资料先维护再逐日批准。
5. 资金日报：主体日期币种单位分组，账户变化保留双方，合并只剔除批准调拨；未分类仍保留实际收支，不冒充法定现金流量表。
6. 可用资金：日末受限/锁定/明确无受限依据逐项批准；对象重复、重叠、超余额和已支付再次锁定阻塞。没有依据未知。
7. 异常复核：逐项说明不消除阻塞。修订变化旧批准和复核全部失效。
8. 版本与底稿：16表完整XLSX和逐表CSV，原始单元格/物理对应/来源守恒/事件与比较；主动下载含数据完整工作或无数据通用方案，恢复先预览。无数据确认清空全部私有资料，取消保留。

CSV危险文本前加单引号防止表格软件执行，完整原文保留在XLSX静态文字/含数据JSON中；原始文件的公式及缓存、宏、外部关系一律拒绝。文件10MB、实际解压30MB、20000行/200列、100规则、范围366天。金额最多24数字位和6小数位，业务容差只用于余额差、不用于调拨。

不提供网银支付、实时余额、多人流程、自动换汇或OCR/AI。本款归原资金模块中的资金日报，不替代资金管理平台或流水归集。
