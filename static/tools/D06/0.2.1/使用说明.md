# 财务明细核查 · D06 · 0.2.0

供财务人员核查本期单据/余额明细，按业务依据检查必填、重复、字段类型、允许值、金额范围及逐行余额勾稽，逐项追查和复核。原始资料不改写，异常及未执行项目保留；复核说明不是法定会计或审计结论。

五页：资料及核查范围 → 核查项目维护 → 异常待办 → 来源追查 → 核查结果与底稿。导入UTF-8 CSV或XLSX，选择页签及表头行，明确期间/币种/单位范围。范围留空表示全部值，排除原行仍保留在完整底稿。不同币种、期间和单位不汇总、不自动换算。勾稽字段的一致口径须经办人逐项确认，否则只阻塞勾稽项目。

在核查项目页维护六类规则、启停、业务依据、适用条件、自填版本及有效期间；使用真实资料前须按自身业务修改样例规则。缺列、缺依据、有效期间不适用或未确认勾稽的项目单独未执行。空值不补零，零与负数独立；金额使用Decimal，输入最多6位小数/24位数字，容差独立非负且含等号。

异常待办保留每条问题的原文件、页签、行号、实际值、要求及差额。填写经办人和依据后记录复核，撤销也须填写依据并保留历史。复核不消除异常或改变来源；资料、规则或范围变化时旧核查和复核失效。本机自填人员不提供身份认证、审批或多人协作。未提交草稿离页可取消保留或确认放弃。

完整XLSX底稿含核查摘要、范围参数、全部执行情况、启停规则及业务依据、全量异常、复核历史、全量来源和排除行。长文本另按顺序分段，完整内容不截断。含数据JSON工作保存原行、配置及复核，恢复严格校验并重算；复核绑定原行及参数，外部改动拒绝恢复。无数据方案只含配置，恢复明确清除旧资料及复核，并要求重新确认勾稽口径。旧0.1.x无数据方案仅由历史plan.ts接口兼容；新版UI请使用0.2.0 schema_version:2方案，不自动猜测迁移。

资料只在浏览器内存处理，不上传、记录日志、遥测或默认持久化。关闭、清除或原生入口dispose释放内存。主动下载工作后请确认实际保存，再离开。公式、缓存、宏、外链和用户代码不执行。每文件10MB、解压30MB、20000数据行、200列、100规则、50万行字段组合、5万异常；工作JSON也有10MB限制，复核上下文完整快照会增加大小，超限应减少资料范围或分批保存，不截断。

虚构样例8行：17异常、7问题行、1未命中行，错误6行/警告6行重叠。CNY且2026-09范围：6行纳入、2行排除、13异常、5问题行、1未命中行。XLSX最后一行有故意构造的公式，仅测试拒绝缓存，不执行。

下载离线包后解压，用Chrome或Edge双击index.html，断网也可运行。官网下载与独立离线使用同版本程序；实际验收状态见根progress/STATUS.md。先用全虚构样例，再导入本机资料；导出含数据底稿后可主动恢复工作。
