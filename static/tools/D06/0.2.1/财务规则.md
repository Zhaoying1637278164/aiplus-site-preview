# D06 财务规则

应用0.2.0，规则D06-2026-10-03.1。适用财务明细核查，依据为用户指定字段字典、允许值及勾稽约束；不内置税务、会计政策，不形成审计结论。用户应按业务有效期调整规则，本版本不自动判定政策有效性。

必填仅提示空值；复合唯一键按文本检查，保留前导零，整组重复均标记而不删除。金额采用Decimal，最多6位小数、24位数字；危险的Excel数值精度拒绝。日期仅接受真实的YYYY-MM-DD。空不等于零，负数合法，是否提示负数由金额范围设置；上下限与容差边界含等号。

勾稽式仅允许明确的加减字段组合，差额=左式−目标，逐行按abs(差额)>容差判断。字段币种、金额单位、期间须由用户确认一致，不跨行混加，不自动换汇。允许值可用于检查币种及期间；缺少列使对应规则未执行，不宣称全部通过。空值、公式与非法金额可能无法判断，保留错误/警告与原因。

公式与Excel错误值不执行、不使用缓存，系统另行提示。原文件/页签/原行与原始值保留于报告，全量行状态保证输入行=问题行并集+未命中行；错误行和警告行可重叠，不直接相加。

独立人工答案在规格与独立预期.md。六类检查并非中国法定财务政策，法定业务要求仍需单独配置依据、条件和有效期。

## 0.2.0工作流程补充

正式财务名称为「财务明细核查」，模块为结账辅助。应用版本0.2.0；基础金额规则版本D06-2026-10-03.1保持不变，工作保存schema_version:2。每条业务规则另有自填版本、依据、适用条件、启停及生效/终止期间；缺少必要依据或核查期间与规则有效期不符只阻塞该项，不套用海外政策。

范围按经办人选定的期间、币种、单位字段及精确文本值过滤。空范围是全部值，空单元格不是任何已指定值；不补零、不猜币种、单位和期间。逐行金额勾稽须明确确认各参与字段口径一致；缺确认未执行。不同原行不相加，不自动换汇或把万元转元。默认单位为样例提示，必须由经办人按实际资料确认。

复核是逐条异常的自填说明；经办人、依据必填，允许撤销并保留历史。所有已复核仍保留原始异常，不能宣称账务正确。资料/参数修改使复核清空；JSON复核绑定完整资料及配置快照，恢复时比较后重新计算。此绑定用于变更检测，不是签名或身份认证。底稿长文本按分段顺序保留完整内容；错误/警告可能重叠，纳入行=问题行+未命中行，输入行=纳入+排除。缺失资料不会补零或强行调平。
