# F05 财报分析看板

候选0.1.0。已确认财务报表及附注的八页分析工作：报表与范围 → 项目对应 → 指标与口径 → 分析总览 → 资产负债结构 → 盈利现金与趋势 → 差异与来源 → 底稿与恢复。候选不是accepted或官网已发布。

解压候选离线包，用Chrome/Edge双击index.html，先体验完全虚构样例，再导入自己的CSV/XLSX长表。无需账户、联网或API Key。报表/方案仅浏览器内存，关闭页面清除；主动下载含数据工作（含资料/复核）或无数据方案（不含资料/复核）可恢复。输入10MB、解压30MB、20000累计行、200列、60组合、500原项目、100指标限制。不支持xls/xlsm、扫描件、公式执行或任意代码。

## 输入与配置

每行：主体、范围（个别/合并）、开始日、结束日、币种（三字母）、单位（元/千元/万元）、口径（制度版本/期间类型/重述及业务范围）、已确认（是）、报表（BS/PL/CF/SUP）、项目、时点（期初/期末/本期/平均）、金额、依据。

BS为期初/期末，PL/CF为本期，SUP为平均/本期并须依据。期初为开始日前一天；流量区间同年，费用通常正数、现金净流出为负。CSV为UTF-8逗号分隔，XLSX选择页签表头和字段后预览；静态原金额最多6小数24数字。原项目未知先对应，不自动猜测；同组同项目重复阻塞。

可自定义中文项目名、标准映射、有限加减指标分子分母、依据条件有效期；平均余额可选期初期末简单平均或用户提供平均。显示位和勾稽容差分开；单位通过输入显式选择，不自动转换。同范围同期用户同行假设须依据，仅显示数值差。

## 输出与判断

默认23指标包括结构、偿债、毛利净利、现金质量、收益率和周转；7项报表勾稽；所有本期较晚组合对基期组合变化（不可比项阻塞）。来源精确至文件/页签/原行/金额单元格。缺期初或平均余额不以期末替代；分母零负阻塞；基期零负只保留绝对变化。缺期间或不同币种、单位、口径不比较，不换汇，不年化。

底稿下载包含十一张表，保留原始资料、公式、输入、残差、问题、来源、参数、同行假设、复核与应用/规则版本。含数据工作JSON与无数据方案JSON带schema_version=1并恢复重算。CSV公式样式文本会安全转义；XLSX所有金额按文本保存。修改资料/规则清旧复核，复核不改数学结果。

## 边界与使用环境

不提供投资评级、审计意见、AI解释、OCR或业务明细盈利分析，不判断法定会计分类与应执行的列报版本；中国规则依据和分主体施行期见财务规则。Mac Chromium实际验收见验收证据；Windows实机未验证。官网和正式发布由总控独立验收，原站经营分析看板仍含其他工具能力。
