# F05 财务规则

应用0.1.0；规则F05-2026-10-04.1。规则为管理分析数学口径，不是会计政策判断或法定报表编制。适用于用户已确认且映射定义相同的报表及补充资料；默认指标生效2014-07-01，无终止日，可配置有效期。

## 中国口径与可比前提

依据CAS30财会〔2014〕7号第8、12–14、16条（2014-07-01实施），记录企业、个别/合并、期间、币种单位、列报口径和可比资料。2026修订财会〔2026〕11号施行通知：境内外同时上市及境外上市采用国际准则/企业准则企业2027-01-01，其他境内上市2029-01-01，企业准则非上市2030-01-01，允许提前执行；执行新准则后不再执行2014版本。第68–69条要求首次执行调整比较列报并披露相关调节信息。

本款不自动判断主体执行哪版、不自动重述；输入口径必须明确版本、期间类型、业务范围及重述依据。比较期口径不同即阻塞；用户只有核实并提供同口径数据后才可重新导入。新版经营利润不自动映射2014营业利润；中文展示名可改，稳定项目ID/定义须经用户确认。金融企业按流动性列报如不提供流动分类，则流动比率与分类占比阻塞，不强制分类。

## 数据与公式

同组键为主体/范围/开始日/结束日/币种/单位/口径。仅已确认=是参加计算。BS期初/期末，PL/CF本期，SUP本期/平均。费用通常以正数扣减，负值保留用于复核；CF净流出为负。SUP利息、EBIT、平均余额须依据，货币资金不等于现金等价物。

金额Decimal40位，输入最多24数字6小数；显示位0–6与绝对勾稽容差独立。导出金额/比率为原精度十进制文本。空、公式、缺期间、缺项目、重复同组标准项目/角色均阻塞引用；不补零、猜单位、换汇、执行公式。

- 结构：流动/非流动资产÷资产；流动/非流动负债/权益÷资产；保留分类/平衡残差，不把明细与总数重复叠加。
- 负债率=负债÷资产；流动=流动资产÷流动负债；速动=(流动资产-存货)÷流动负债，名称明确简化口径；货币资金比率=货币资金÷流动负债（不称现金等价物覆盖）；营运资金=流动资产-流动负债。
- 毛利=收入-成本；毛利率=毛利÷收入；净利率=净利润÷收入；营业利润率=用户确认定义的营业利润÷收入；经营现金净利比=经营净现金÷净利；经营现金收入比=经营净现金÷收入；EBIT利息保障=明确补充EBIT÷明确利息支出。不由财务费用猜利息。
- ROA=净利润÷平均总资产；ROE=净利润÷平均权益，均为本期不年化；总资产/应收周转=收入÷相应平均余额；存货周转=成本÷平均存货。期初期末简单平均与用户SUP平均两种方式可选，不以期末代替平均；缺期初/平均依据阻塞，负/零平均分母阻塞。合并ROE为净利润/全部权益，不冒充归母ROE。
- 所有比率分母必须>0，分子负值可展示并提示，不给好坏评级。比率百分数乘100，倍数不乘。
- 变化：本期-基期；增长率=差额÷正基期×100；基期0/负阻塞增长率但保留绝对差额。比较的主体范围币种单位口径一致，开始/结束月日相同、同年区间且本期年份晚于基期；全年闰年可比，任意错位期间不自动比较；不推导同比月度缺失数据。比率变化显示百分点/倍数，不计算比率的增长率。
- 7项独立勾稽：流动+非流动资产=总资产；流动+非流动负债=总负债；负债+权益=资产；利润总额-所得税=净利；经营+投资+筹资+汇率=现金净增；期初现金+净增=期末现金；收入-成本=提供的毛利（未提供毛利则阻塞，不循环验证计算毛利）。

自定义指标只允许1–8项有限加减、固定角色引用、百分比/倍数/金额，必须名称依据条件有效期，不执行任意代码。同行值是用户输入假设，须来源期间币种/单位适用口径明确，与相应结果单位一致；显示差值不判评级。指标停用、有效期外明确显示状态，不静默删除。

每项结果保留公式参数、来源行/文件/页签/金额单元格、参与金额、版本、问题及残差。复核记录不改变数学结果；资料/映射/指标/参数变化清复核，恢复仅载入经验证工作并重算；无数据方案明确不含资料和复核。
