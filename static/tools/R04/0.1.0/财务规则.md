# R04 财务规则
规则R04-2026-10-03.1；应用0.1.0。分析与催收复核，不计算坏账、风险等级、DSO或自动分录。

- 快照：用户确认完整截止日未结余额，快照日=截止日。核销调整只来源核对，永不再次扣减。
- 推导：期初日<截止日；期初行声明期初余额，新增有效日晚于期初；期初+本期发生−核销+退款/撤销−红字+批准调整=截止余额。期初前事件单列，截止后事件/发生不回写历史。
- 发生ID/事件ID全表唯一；同票客户ID/币种/单位/含税/发生日/到期日一致。退款/撤销关联原核销ID，同票同维度，日期不早于原事件，累计不超原核销；红字关联发生ID不超原发生正额。重复/非法/超额整票阻塞，不先占；逐有效日核销不超可用正余额。负期初单列。
- 原金额最多6位小数，显示0–6位；容差仅勾稽不改余额、不放宽超额。币种单位含税分组不换算。
- 发生账龄=截止−发生；可选发生/到期分档（未到期单列）；逾期=max(截止−到期,0)，到期当天0。UTC有效日期整日差。缺发生仅阻塞发生账龄，缺到期仅阻塞逾期/到期分档。
- 整数闭区间首档0，邻档下限=前档上限+1，末档无上限，不重叠无空洞。分档+无法分档+未到期=有效正应收。负/零单列不净入；无效/未来/范围外全留原行。
- 修订需原值/新值/依据。换资料/参数使复核失效；基线存资料与规则重算，完整恢复重算；方案清资料/事件/复核/基线。

中国准则范围/生效期与官方第47/53/63条见参考来源。批准依据是用户输入，不代判断会计合法性。缺依据阻塞调整。Windows未验证。

补充执行边界：每票必须显式期初（新票零期初亦需输入；零期初可声明未来发生日）；同日退款/撤销不为当日超额原核销提供额度，缺时点关系按保守规则整票复核。重复ID从全部可读取原/修订明确ID建立，其他字段无效也不免检。计算已按票/日期/口径索引，支持20000行；超大完整JSON/底稿明确阻塞，不截断明细。
