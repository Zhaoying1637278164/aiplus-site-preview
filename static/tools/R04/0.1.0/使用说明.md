# R04 应收账龄与逾期分析

本地八页财务工作：工作总览 → 应收资料 → 核销与调整 → 截止与账龄口径 → 账龄分析 → 逾期与客户待办 → 例外与来源 → 版本比较与底稿。

版本0.1.0。解压离线包后双击同目录 index.html；项目正式构建在 release/R04/0.1.0/index.html。官网接入与最终accepted仍待总控验收。正式离线浏览器检查见本项目版本证据；Windows实机未验证。

先选择来源模式。截止日未结快照必须确认与本次日期一致，核销仅来源核对不扣减；期初推导必须明确每票期初（新票也明确零期初）、本期发生、核销/红字/退款撤销与批准调整。本次范围完整性需要用户明确确认。

导入UTF-8 CSV或XLSX，选择页签、表头行、业务列映射，预览后确认换入；取消保留旧工作。字段见空白应收模板与核销调整模板。客户ID、应收ID、记录/事件ID明确，前导零以静态文本提供。使用完全虚构31行样例可体验分页与搜索。

发生账龄与逾期独立显示，到期当天不逾期；缺日期对应计算未知，不填零。区间整数闭区间、完整无重叠无空洞。正应收分档守恒，负余额、零、无法量化、未来及范围外分别披露；币种/单位/含税各自计算，不换汇。不计算坏账、信用风险或AI/OCR。

重复、非法关联及超额整票阻塞，包括无效金额行的重复ID。修订在原资料上叠加并保留前后值及依据；换资料/规则复核失效。原行索引0起，文件原始行保留。

完整XLSX为22表：版本范围、参数、区间、原始应收、原始核销调整、映射、修订、逐票、分档守恒、客户、发生月、逾期待办、例外、事件应用、操作事件、复核、版本比较、基线参数、基线应收、基线核销调整、基线修订、基线映射。金额原精度导出；显示精度仅用于展示。

完整工作JSON含数据及基线，恢复从原始资料重算；无数据方案只含规则，恢复清旧资料/事件/复核/基线。下载JSON有schema_version、含数据标识和版本。关闭、确认退出及宿主dispose清内存，请主动下载保存。无上传、遥测、日志、默认持久化、外部请求、CDN或在线字体。

限制：10MB文件/工作、30MB解压、20000行、200列、单元格10000字、最多2000修订/事件；完整底稿展开最多60000行/20MB，输出10MB，加入来源后最多200列，过大明确阻塞。禁止宏/外链/公式和缓存执行，仅静态值。会计合法性与完整性需用户审核，依据和适用范围见财务规则及参考来源。
