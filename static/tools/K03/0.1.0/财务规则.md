# K03 财务规则

规则K03-2026-10-04.2，自2026-10-04本应用0.1.0起适用。自主管理分析规则，非会计估值/减值政策。来源方法见参考来源；退货、红字、负库存特殊处理需用户填写已确认业务依据。

1. 六键分组：主体、仓库、物料、币种、数量单位、金额单位，完全相同才可比较，不换汇不换算。同组混用批次/无批次阻塞，名称仅展示。空不补零。
2. 期初层为开始前一日余额，数量成本非负，零量非零金额阻塞；原入库日可空（未知），不晚于期初。收发不早于开始日，期后排除并保留；同日正整数顺序不得重复；同组期初和收发记录ID跨表也须唯一，不能混淆来源层。
3. 入/出库数量正数，金额非负，必须为账面成本而非售价。Decimal40位，输入最多18整数6小数；金额/数量显示6位，比例6位；数量/金额容差分别仅判断不调账。
4. 退货默认阻塞。启用后销退关联在前出库、同组批次、数量不超原单剩余可退、金额=原单位成本×退量，按原消耗层恢复年龄；购退关联在前入库且原层余量足够、同单位成本移除，不计销售出库。红字默认阻塞，启用仅支持数量金额同时为负的全额入/出库冲销，关联在前原单，已经部分退货不可再全冲。不猜测跨期原单，购退关联期初不支持。
5. 负库存默认阻塞组，或有依据时隔离组；历史任何时点数量或成本负数均异常，该组不生成正常库龄/周转。不自动用后续入库中和。能识别的无效行隔离其组，无法识别组的无效行阻塞全体。
6. 库龄=截止−原入库日，当日0天。递增整数区间上限，末档大于最大上限。批次按来源追踪，同批多入库日仍FIFO推定；无批次FIFO估算，未知独立桶。消耗金额按原层成本比例扣除，尾量整取；分层数量和成本在内部保持Decimal40位，不逐层预先舍入。销退按原消耗层的累计已退数量计算目标比例，再取本次增量，避免多次退货逐笔舍入漂移。显示/导出按同组六位总量统一分配：各层先向下取6位，再按小数余额从大到小补一个微单位，平手按来源日期顺序；不会产生负尾层。保留未舍入量额，微量来源显示0仍保留该来源。层成本和账面成本差额超容差，该组库龄金额阻塞、数量保留，不调平。库龄不等于减值。
7. 期间含首尾。平均可选(期初+期末)/2或每日日末余额按天数加权（含无变动日）。数量周转=净出库量/平均量；成本周转=净出库成本/平均价值。销退/红字调整原方向，购退不计销售出库。分母≤0或净出<0不可计算；净出0且分母>0次数0、天数空；天数=实际期间天数/次数，不自动年化，不输出Infinity。
8. 可选截止表日期等于截止日，以六键和批次勾稽；缺/多组及差额异常，不以空代0。呆滞为年龄≥阈值的复核线索；未知单列待核，非减值判断。层勾稽失败呆滞金额也为空。
9. 保留文件/页签/行、参数、版本、异常与勾稽；换资料/映射/规则清结果和复核。复核备注不能解除阻塞，导出全量十页不受过滤影响。明确“本期无收发”操作可创建零活动台账，读取失败不当零活动。

2026-10-04返修：层数量和层成本勾稽比较六位表示总量，量额容差仍独立；负来源量额和真实零量非零成本直接阻塞，绝不通过过滤隐藏。完成全部来源勾稽/合法性检查后才决定库存、库龄、周转和截止核对的阻塞状态。旧规则.1方案不得作为新规则.2恢复输入；请以新模板/工作重算。
