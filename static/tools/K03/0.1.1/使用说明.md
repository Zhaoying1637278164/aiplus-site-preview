# 存货库龄与周转使用说明

应用0.1.0，规则K03-2026-10-04.2。
官网入口：https://aiplus-guance.streamlit.app/~/+/?tool=K03 。离线包解压后用Chrome/Edge双击index.html，无需安装、账号或网络。Mac Chromium已实际验证本版本的离线使用；Windows实机未验证。

1. 资料导入：先载入完全虚构样例。下载期初/收发/截止三份模板与虚构CSV/XLSX。期初是期间开始前一日的余额层，每组提供期初；零期初用0/0行。收发为完整期间台账，成本必须是存货账面成本，不能用售价。批次可空；期初原入库日可空并显示未知。
2. 自己的资料每角色选择一个本机UTF-8 CSV或XLSX，选择页签与表头，配置中文字段对应，再“应用所选资料”。文件10MB、解压30MB、200列20000行，禁止宏外链，不执行公式，公式对象不作为数据。本期确实无收发可点“确认本期无收发”，不会把读取失败当零活动。可选截止核对表能帮助复核量额；不提供则没有此项账表勾稽。
3. 分析规则：设起止日、平均库存口径、库龄上限、呆滞阈值、量额容差，确认成本。退货/全红字必须关联本期间先前原单；启用需填写实际规则依据。不支持跨期猜单。按主体/仓库/物料/币种/数量单位/金额单位分组，不能自动换汇换算。填复核人后计算。
4. 收发台账和截止库存查看余额与成本勾稽；库龄页看批次追踪、批次内FIFO推定、无批次估算及未知日期。微量来源层保留未舍入量额，六位展示按分组统一分配尾差，显示0不表示真实来源为零；旧规则.1工作不兼容，须用新工作文件。周转显示平均分母与净出分子，零分母和无出库天数不可算。呆滞只是复核线索，不自动推断减值。
5. 任意表输入关键词查询，翻页查看全部。来源按钮可展开文件/页签/行与原始单元格。异常页填复核判断，不会绕过阻塞。更换资料、字段或规则会清空旧结果与复核，必须重算。
6. 底稿与恢复：下载完整十页XLSX及各页CSV（全量，不受查询影响），下载无数据规则方案或含资料与复核的工作JSON。明确是否含数据，含数据文件需自行保管；重新选JSON恢复后重算核对。schema_version=1，仅当前工具/应用/规则版本可恢复。
7. 用户资料只在浏览器内存，不上传、写日志、遥测或默认保存。关闭/退出清空；退出提示可取消或确认，重入不会带回资料。需保留时先主动下载工作。页面下载均为本地生成。

完整底稿：截止库存、库龄区间汇总、库龄来源层、周转分析、收发台账、截止核对、呆滞复核、异常复核、原始资料、参数与版本。财务规则、参考和第三方通知随包保留。
