# P02财务规则

规则版本P02-2026-10-03.1，应用0.1.0；适用于用户明确的截止时点未付正余额快照及之后拟付款，非会计政策、税务或银行指令。依据为用户导入来源/合同到期/批准安排与资金输入，计算方法为确定性加减。没有自动新增、实际付款或滚动应付。生效范围为用户选择的截止日及其后13周排程；期间外计划仍计逐单已安排并单列，不丢失。

原到期日永不随拟付日改变。原逾期=max(截止日-原到期日,0)，未知为null；预计延期=max(拟付日-原到期日,0)，提前=max(原到期日-拟付日,0)。按周起始日划分7天公历周期，第一周自截止日次日所属周开始，截止日前计划阻塞。

按主体/供应商/单据键查来源；来源行ID及单据键重复整组阻塞。未付空/缺币种单位税口径/截止不一致/无依据无效；零保留；负数隔离为贷项/退款待批准，不抵销正余额。应付原单余额、计划金额最多6小数并受用户财务精度限制，超位阻塞不舍入；显示位数等于财务精度；容差独立只检查勾稽，不允许超付。金额Decimal，禁止换汇换单位。

计划ID重复即使另一行金额无效也整组阻塞；一单所有非撤销静态有效计划金额超过可付余额，或关联计划存在无效行，则该单全部确认结果阻塞。草稿占用拟安排校验但不计确认；撤销保留原内容不计。确认需用户依据，调整后回到草稿；通过异常复核不能跳过阻塞。已确认计划+未安排=有效正余额；异常资料使组完整性为不完整，不用局部数值冒充完整总额。

资金按主体/币种/单位/税口径/账户/周起日匹配，限额为用户已批准本周独立额度，非自动滚存现金。资金池ID与主体/币种/单位/税口径/周唯一，禁止同一资金多账户重复用；重叠/重复额度整组未知。占用只包含有效已确认计划，缺额度未知，超限=max(占用-限额,0)，不压缩计划。未确认草稿另披露。自动建议首版不提供。

实际已付记录仅接受用户截止日前静态记录，独立存储、校验、展示与底稿，不从时点余额再次扣减。负数退款、贷项自动安排/抵销，折扣、利息、税额、会计判断、融资、OCR/AI均未实现并阻塞自动推断。用户含税口径只作分组标签。
