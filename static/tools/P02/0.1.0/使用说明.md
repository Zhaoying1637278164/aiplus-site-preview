# P02 付款计划表

企业财务使用截止时点未付余额安排部分付款、延期、批次与每周账户资金限额。TypeScript业务引擎与React八个业务页分离；ToolProgram供原生官网挂载，main.tsx供同一程序离线入口。

应用 0.1.0。下载离线包并解压后，用 Chrome 或 Edge 双击本文件夹内的 index.html；无需安装，断网也可使用。先载入完全虚构样例，再导入自己的资料。源码包包含锁文件、共享包、本款源码、测试、构建说明和第三方声明。Windows 实机未验证；官网最终验收状态见项目 progress/STATUS.md。

## 使用

1. 工作总览设置截止日、周起始日、财务精度及独立勾稽容差。可以先载入完全虚构样例，确认替换，计算。
2. 应付资料导入UTF-8 CSV或XLSX，选择资料类别和页签，预览后确认替换。表头第1行，必须包含所选类别模板全部字段；不猜列名。编号按文本输入以保留前导零。
3. 付款安排录入草稿：计划ID、来源行ID、主体/供应商/单据ID、批次、账户、拟付日期、金额。支持一单多次；依据确认或撤销；修订后回草稿。单据原合同到期日保留。
4. 到期与排程查看供应商/逐单下钻、原逾期、预计延期、提前、13周期初－确认＝期末及13周外安排。
5. 资金限额输入已批准账户/资金池/每周静态额度。缺额度显示未知，重复资金池阻塞、超限展示差额，不改付款金额。
6. 差异与复核按原始行定位修订；填依据记录复核。复核不解除业务阻塞。资料、计划、资金与规则变更后结果和旧复核失效，请重新计算。
7. 版本比较保存内存基线并查看原始数据、规则、事件前后变化。替换/修订/确认/撤销留事件；不默认持久化。
8. 来源与底稿下载含数据JSON工作、无数据配置、18张XLSX完整底稿及对应CSV。恢复前预览：取消保留旧工作；确认替换。含数据重算四原始表，无数据清全部旧资料、事件、复核和基线。

所有明细20行分页、搜索、横向滚动；操作列固定在右侧，窄屏不逐字竖排。关闭或确认退出清内存；未下载的资料不能恢复。用户文件不上传、不写日志、无遥测、无默认保存、无CDN/字体/外部请求。单文件10MB、XLSX实际解压30MB、单表20000行/200列，工作累计5000行/60000格/JSON10MB，底稿超过250000格或10MB阻塞下载。

## 输入口径

- 应付资料是截止时点未付余额，不是发票原总额。范围含主体ID、供应商ID、单据ID、币种、金额单位、含税口径、截止时点、来源行ID与来源依据。到期日空保留未知，不填今天。
- 原到期日独立于拟付款日；原逾期以截止日衡量，预计延期/提前以拟付款日衡量。周起始日可选，跨月跨年按真实公历。
- 草稿/已确认/撤销分别披露，仅有效已确认计逐单/周/资金占用。重复ID或单据内累计超额整组阻塞；容差不能放行超付。
- 实际付款记录单独保存，限定截止日前，经用户来源批准，只披露不再次扣减已提供的未付余额快照。未实现滚动新增减已付口径。
- 币种、单位、主体及含税口径分组，不换汇换单位，不按供应商名称合并。金额Decimal；空、零、负数不同。负数贷项/退款隔离待批准，不自动抵销或安排支付。异常范围明确不完整，不把可计算部分当完整总额。

## 边界

计划不是银行付款指令。不发起支付、企业审批、自动融资、系统记账；无AI/OCR、自动建议排序、自动折扣/利息/税额/贷项抵销/会计政策判断。用户静态已批准输入只作确定性计算，没有中国或外国默认税率/政策。

## 开发与验证

在项目根目录使用Node22+及npm锁文件依赖。

- 本款测试：`node --import tsx --test tools/P02-付款计划表/tests/engine.test.ts`
- 本款类型检查：`./node_modules/.bin/tsc --noEmit -p tools/P02-付款计划表/tests/tsconfig.json`（包含公共pako声明）。
- 非正式候选构建：`node --import tsx tools/P02-付款计划表/tests/build-candidate.ts`，只写本款证据目录。
- 候选断网验收：`node --import tsx tools/P02-付款计划表/tests/browser.ts`；本机Chromium路径可通过P02_CHROME设置。
- 正式构建/发布/源码重建只由总控运行根脚本，不能运行本款候选脚本冒充正式交付。
