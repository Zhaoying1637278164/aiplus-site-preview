# U03 询证函编制

候选0.1.0；正式登记、打包与官网验收由总控完成，目前不能称accepted。

打开候选index.html，七页完整流程：往来余额→函证对象→抬头与模板→金额与来源复核→询证函预览→函证控制清单→方案与恢复。先载入完全虚构样例。支持UTF-8 CSV或静态XLSX，选择页签与表头行后确认替换。余额字段明细ID、对象ID、科目、截止日、币种、单位、余额；对象字段对象ID、对象抬头、地址、联系人。使用文本金额保留精度，编号保留前导零，不自动猜测字段。

设定发函单位与项目指定回复地址、截止日、币种单位、正数方向、模板名称版本、命名前缀及HTML/TXT格式。负余额反向列示，零余额单列，不将借贷抵消。可导入纯文本TXT模板，必需占位符缺失或未知占位符会阻塞。HTML按文本转义，不执行模板HTML/代码。

先解除全部异常阻塞，再逐对象确认抬头/地址/余额/来源；下载当前函件或全部函件ZIP。控制清单发送、控制人、回函、差异跟进留空，实际发送和回函由项目另行登记。完整XLSX底稿含控制空表、逐行余额来源、异常、参数勾稽、原始余额与原始对象。输出金额为十进制文本。分页不减少全量导出。

方案需要主动下载：无数据方案只包含抬头、模板及参数；含数据方案包括原始资料及确认记录，恢复重新计算和校验。换资料、模板或任何参数清除确认。用户文件仅在浏览器内存，不上传、遥测、日志或默认持久化；退出或关闭释放内存。文件10MB，XLSX实际解压30MB，20000行200列；TXT30KB/10000字，单函1MB，函件ZIP30MB，底稿文本8MB。文件失败不覆盖旧资料。XLS/XLSM/密码文件/宏/外链不支持，公式不执行且用于必填字段会阻塞。

边界：不自动发函、选样、判定函证充分适当或出具审计意见；银行等专用格式和自动审计合规判断未核验中国政策，功能阻塞。请使用项目批准模板，独立确认地址和回复方式。HTML可本机手动打印；没有自动PDF/DOCX承诺。Windows实机与公开官网未验证。

开发：根目录npm ci；npm exec tsc -- --noEmit -p tools/U03-询证函编制/tsconfig.json；node --import tsx --test tools/U03-询证函编制/tests/*.test.ts；node --import tsx tools/U03-询证函编制/scripts/build-candidate.ts。候选程序与runtime.json使用相同源码。源码包提供锁文件、共享包、测试、声明和重建说明，不含node_modules/凭据/业务资料。
