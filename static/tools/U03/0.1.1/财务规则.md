# U03 财务规则

应用0.1.0；规则U03-2026-10-04.1；适用普通企业往来余额资料编制，自2026-10-04起用于此版本。无税率/会计政策/审计意见判断。来源：项目共同口径docs/finance-rules.md；ICAEW 2021-08-19 Part19章节4/10/12仅工程方法参考，不是中国函证政策。

1. 对象ID/明细ID精确匹配，不自动去空格或改变大小写，前导零保留。每条余额明细ID唯一，对象ID关联唯一对象档案；重复不合并，空金额不为零，公式单元格阻塞。缺少对象抬头或地址阻塞。未引用对象警告但不生成函件。
2. 截止日、币种、单位逐行与参数完全一致，不混期、不加总币种、不自动换汇。只接受ISO大写三字母币种、元/千元/万元明确单位；只允许有效日历日期。
3. 余额最多24数字、6小数，Decimal.clone精度50。金额数值超过安全整数或非有限拒绝，建议金额文本。正数方向由用户指定借方或贷方；负数反向列示；零明确显示零余额。账户与方向逐行列示，不跨借贷净额抵消；借方/贷方/有符号原始余额分别回勾，残差须为0，比较容差固定0，显示保留原始精度最多6位。
4. 对象函件汇总借方/贷方，与来源有效行方向合计衔接；任何阻塞异常禁止生成所有函件，未复核对象禁止下载函件。零余额可生成但需人工确认。控制表仅列编制/复核状态，发送、回函、差异处理字段为空。
5. 所有输出包含应用规则版本、截止日、币种单位、方向参数、模板名称版本、原文件/页签/行号及明细ID；函件本机HTML/TXT，不自动发送，打印PDF由浏览器手动操作且未作PDF生成承诺。
6. 纯文本模板allowlist占位符，不执行代码/HTML。必须包含对象抬头、截止日、逐行余额、币种单位、发函单位、回复地址。未知占位符和未替换占位符阻塞；允许用户命名，下载名去危险字符、序号防重。银行等专用格式/审计合规自动判断未核验中国政策，阻塞该能力，不影响一般资料编制。
