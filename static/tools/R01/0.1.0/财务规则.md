# R01 财务规则

规则版本R01-2026-10-03.1，应用候选0.1.0。依据本项目管理台账规格与用户显式配置，自2026-10-03用于本款；不是法定会计或税务政策。

合同金额、净开票、净回款、独立收入分别列示。全量有效票未收款=所有有效净发票原额－明确分配至发票的净款额；未关联合同的票额仍保留在全量余额和客户余额。合同已关联票余额另为“分配给合同的净票额－该合同明确分配至票的净款额”；合同未收款=合同额－分配给合同的全部净款额。无票号回款作为预收单列，不抵票余额。负余额保留提示，不裁零。未分配票/款与无效记录不得混入合同余额；有效未分配票必须保留在全量票余额，即使客户没有合同。

输入每行必须币种、单位、含税口径及日期，与工作范围严格一致。累计纳入截止日前资料；本期为起点至截止日。没有历史资料不能声称完整应收；工作总览明确输入资料完整性由经办确认。不同范围排除并追溯，不自动换汇、换单位或按税率推算。收入独立资料须与配置范围一致，空表示未提供；即使合同/票/款存在也不生成收入。

所有关联只用稳定ID，禁止客户名称自动合并。重复稳定ID所有重复行阻塞；负票需类型红字并引用正票，退款引用正回款，同客户、原单有效、日期不早于原单，累计冲减不超原金额；撤销状态须撤销日期，截止日前撤销排除，截止日后撤销保持历史有效。

分配来源金额同方向，零分配禁止；总分配绝对额不超来源单据；超过则整来源组无效。分配日期不早于来源及合同；指定发票的款需有票→合同关系。超合同开票、超票收款、负余额作为待复核线索，不当作合理业务。红字单独负余额保留，引用不自动核销原票。撤销/退款/红字不是删除原行。

Decimal40位，金额≤24位数字、6位小数。计算值不按显示精度舍入；精度0–6控制显示，容差只标识余额状态，不改变金额或准许超分配。每单金额=有效分配+未分配，合同关联票－票回款=合同已关联票余额；全量净票－明确票核销=全量有效票余额=合同关联票余额＋未关联合同票额；客户全量票余额合计=全量票余额，其余合同指标客户汇总=合同汇总，勾稽残差必须为0。

缺失值不补零；数值金额超安全精度拒绝，建议文本原十进制。所有字段公式与缓存拒绝。仅静态CSV/XLSX/严格版本JSON，10MB文件/30MB解压/2万行/200列/单元格1万字。工作主动下载保存，含数据明确标记。关闭或卸载清除内存。不自动入账、开票、审批或推断法律收入确认。
