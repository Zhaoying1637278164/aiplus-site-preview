# R01 合同开票回款台账

应收模块完整管理台账候选0.1.0。源码与本款候选自测已实现；尚未正式打包、官网发布或accepted。

## 使用流程

打开本款候选index.html，从工作总览设置期间起点、截止日、币种、单位、含税口径、显示小数和余额容差。可先体验完全虚构样例。依次维护合同、开票、回款；在关联与分配页逐条指定单据ID、合同ID、可选发票ID及金额；计算后查看待处理、客户余额和结果底稿。合同/票/款/独立收入分别展示；无独立收入资料显示未提供，不自动按合同或票确认收入。

九页分别为工作总览、合同台账、开票记录、回款记录、关联与分配、待处理、客户余额、来源与收入、结果底稿。允许部分分配和多目标；稳定ID重复阻塞全部重复行，不按同名客户猜测；来源超额分配整组阻塞。不填票ID的回款分配作为预收，未分配款保留待处理，超额收款负余额保留复核。

每类有CSV模板；实际CSV/XLSX导入时选页签和表头行，必需列须用标准模板字段名，其他列保留。同类导入替换该类全部记录，其余类型保留并重新校验。正票/收款非负，红字/退款负数并引用原单ID；撤销必须填撤销日期，用截止日重建历史。

## 保存与导出

主动下载含数据工作JSON保留本次全部资料、参数、复核备注、变更历史；无数据方案只保留规则，恢复清空资料。schema_version=1、应用/规则版本严格匹配；恢复后重新计算，不相信保存的结果。结果底稿8页签含合同/客户/单据余额、有效分配、问题、参数勾稽、原始来源及历史。金额以原始十进制文本导出，未提供收入明确标记。

数据仅浏览器内存；关闭/退出清除。不上传、不写日志、不遥测或默认持久化。不执行公式、缓存、宏、外链或任意用户代码。10MB文件/30MB解压/2万行/200列/单元格1万字；含数据工作JSON超10MB拒绝输出不可恢复文件。金额≤24位数字/6位小数，精度和容差独立，无自动换汇或换单位。
