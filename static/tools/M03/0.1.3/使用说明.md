# M03 盈亏平衡与定价测算

候选0.1.2，面向财务经营分析的八页完整测算：资料与口径、成本结构、盈亏平衡、目标利润定价、折扣与销量情景、敏感性、异常与来源、导出与恢复。用用户给定假设解释销量和定价的成本约束，不预测需求或竞争价格。正式打包、原官网接入与accepted由总控验收。

## 使用

候选HTML见 progress/evidence/M03/0.1.2/candidate/index.html。双击并断网使用，无账号、API、CDN或字体下载。先载入完全虚构样例，标准方案价格20、单位变动成本12、固定成本8000、销量1500，保本1000件、利润4000元。再载入本机CSV/XLSX，选择页签、表头和字段，确认后替换资料；原始来源保留，编辑假设列在覆盖记录。

每行是独立方案，不把多产品固定成本合并。单期YYYY-MM、同币种三位代码、单位元/件、整件销量、不含税；用户确认成本口径、假设依据和相关销量范围。空值不是0，不执行公式、宏、外链或用户代码。文件10MB、解压30MB、20000行、200列；金额最多12位整数6位小数；不自动换汇。

第3页看收入/成本/利润及保本与来源，第4页看目标利润量、净价/标价下限和最大折扣；第5页添加命名销量成本情景；第6页设置敏感性与显示位数/容差。范围外输出仅线性外推，不作为可实现目标。第7页全量异常及来源分页，最后一页下载9张全量底稿/结果CSV/模板/样例，和含数据工作或无数据方案。敏感性全底稿默认首个有效方案，当前方案在第6页单独下载。最多100000个方案×情景组合，超过请分批。

含数据工作含原始数据、假设覆盖、情景与参数，请自行保管；无数据方案只含参数/情景，恢复清空现有资料。schema_version1应用/规则版本严格校验。用户数据只在浏览器内存，无上传遥测默认存储，关闭即清除；官网退出需确认，清空亦需确认。
