# M03 财务规则

应用0.1.2；规则M03-2026-10-04.2，2026-10-04起适用于用户明确确认的线性本量利假设，无税率/会计政策判断。代数方法参考ACCA官方CVP analysis的equation、contribution、target profit、margin of safety与limitations章节；链接和实际阅读位置见参考来源.md。中国企业管理测算使用用户的不含税成本/价格，不将海外示例货币、税率或会计政策作为默认政策。

## 输入与适用范围

每行是独立方案；不跨方案汇总固定成本，不跨币种期间相加。期间YYYY-MM（1900–2199），币种三位大写代码，金额单位元，单价元/件，数量整件。不存在汇率或自动换单位。成本口径与假设依据必填，用户确认收入与成本同口径；本款不判断净额/总额、税额或成本资本化。

最多12位整数/6位小数金额，销量0至10亿整件。空值、公式、负单价/成本/销量/目标、折扣超0–100、重复方案ID、无效范围、超精度阻塞本行；重复ID全组阻塞。零不是空。负目标利润不在本版本；零销量利润=负固定成本，不反推价格。金额为Decimal(80位)自主计算，整件/最低价的向上取整使用BigInt精确有理数除法；共享Decimal配置不影响本款克隆实例。显示0–6位与勾稽容差独立；不因显示或容差改变原始值。

## 可执行公式

净单价 p = 标价×(1−折扣/100)，单位贡献 c = p−单位变动成本 v。
收入=p×销量 q，变动成本=v×q，贡献=c×q，利润=c×q−固定成本 f。勾稽=收入−变动成本−固定成本−利润，精确应为0。

c>0时理论保本量=f/c（理论循环小数近似至30位），整件保本量=ceil(f/c)，该量利润=c×整件保本量−f；整件目标量=ceil((f+目标利润)/c)。可执行数量取精确有理数ceil，不ceil近似小数。
c≤0且f>0：无有限扩张保本量与目标量。c=0、f=0：任何销量保本，最小量0；正目标不可达。c<0、f=0：仅q=0保本，销售增加扩大亏损，目标0最小量0，正目标不可达。

q>0：达到目标的最低净价=(v×q+f+目标利润)/q，精确向上到0.01元。保留折扣所需标价=(v×q+f+目标利润)/(q×(1−折扣/100))，折扣100%不可反推；同样向上到分。最大折扣=100×[1−(v×q+f+目标利润)/(q×标价)]，使用精确有理数向下6位小数；负值表示必须提价，不截断到0。零销量/零标价不适用。价格输出仅成本约束，不保证市场接受。

安全边际件=q−整件保本量；安全边际%=安全边际件/q×100，q=0不适用。贡献率%=c/p×100，p=0不适用。目标差距=利润−目标利润；显示理论近似值不用于整件计算。

## 情景与敏感性

情景折扣替换原折扣；销量、单位变动成本、固定成本百分比变化相对当前有效基准，范围−100至1000%，销量向下取整，最高10亿件。每个情景有名称与依据；最多30个且名称不重复。不赋予概率，不从折扣推断销量，不输出真实市场弹性。敏感性每轴1–11个不重复百分比，范围−100至1000%，价格变动标价，数量向下整件；固定折扣与成本，每方案最多121格。

用户适用最低/最高销量是成本假设范围，不是模型预测的产能。当前销量或保本/目标量范围外明确提示，当前利润标范围外外推；不能称已确认经营目标。不含多产品销售组合、阶梯/半固定成本自动推断。输出全量来源和限制，保留被排除行。

## 文件与工作

用户文件浏览器内存处理，无上传日志遥测默认持久化；CSV UTF-8/XLSX，10MB/解压30MB/20000行/200列/单元格10000字。共享ZIP守卫拒绝宏/外链/危险条目；共享IO只读取公式文本，不运行；公式不可参与本款计算。恢复JSON10MB，严格版本/资料/覆盖/参数/条数校验，schema_version1、M03、当前应用规则。无数据方案恢复清空原资料；恢复含/无数据均先确认，取消保留当前工作。异步导入/恢复/导出在清空、替换或dispose后失效。编辑为有来源的覆盖记录；换资料清覆盖；退出确认、dispose清状态与监听。底稿以十进制文本输出，不执行Excel公式；CSV对可能执行公式的非数值文本加前导单引号防护，XLSX以静态字符串写出，原始值在工作JSON保留；9张底稿全量、筛选无影响，情景组合最多100000，超限分批。
