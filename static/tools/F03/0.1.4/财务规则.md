# F03 财务规则

应用0.1.3；规则F03-2026-10-04.1。属于输入财报的数学核对，不代替会计确认、计量、编制或审计。内置1900-01-01至9999-12-31是数学规则允许输入的日期范围，不表示会计准则在1900年生效；准则公布/执行日期如下独立记录。自定义规则的日期为用户确认的适用范围。

依据：财政部第30号2014准则第二十九至三十四条（2014-07-01执行）及2026修订版通知（按企业类别2027/2029/2030执行且允许提前），第31号第二、四、七、十六、十九条（2006发布）。只采用跨格式稳定的加总和现金构成关系，不套用旧利润表全行分类，不选择企业适用准则。自定义关系须填写依据/条件/有效起止日并明确属于用户确认规则。资料起止日必须位于规则有效区间；停用或过期单列。

确定等式：资产=流动+非流动；负债=流动+非流动；资产=负债+权益；负债权益总计=负债+权益；利润总额=营业利润+营业外收入−营业外支出；净利润=利润总额−所得税费用；综合收益=净利润+其他综合收益税后；现金净增加=经营+投资+筹资净额+汇率影响；期末现金=期初现金+净增加；PL净利润=CF补充资料净利润（同一利润范围）；期初/期末现金=BS货币资金−BR不属于现金的货币资金+BR货币资金之外的现金等价物；期末未分配利润=期初未分配利润+净利润−利润分配−盈余公积提取+其他留存调整（BR全部构成经用户确认，调整带依据）。

提示关系：净利润与经营现金流差异，只给出金额和复核建议，不判断该差额为错误；不得改成确定等式。货币资金不能直接等于现金及等价物，缺少构成项不默认零。留存利润桥接不能省略分红、转入转出、前期差错、合并口径等调整；本工具采用用户完整确认的汇总桥接，不自行分类。

粒度=主体×报表范围×期间开始日×期间结束日×币种×金额单位。期初为开始日前一天，期末为结束日，流量为区间。人民币/其他币种/元/千元/万元独立，不换汇、不自动乘除。已启用关系必需的项目在组合内须恰有一条；空、公式、无对应、重复、无效日期或元数据全部保留；相关等式阻塞。未对应行不丢弃，独立提示不在当前规则覆盖内；通过的等式不覆盖此类行。

Decimal独立克隆precision40，输入最多24位数字及6位小数，支持0和负数，禁科学计数和千分位。运算保留输入精度；显示2/4/6位只影响画面，导出差额/项值精确十进制文本。容差非负、同币种单位，以abs(左−右)≤容差为通过；精度与容差独立。

结果保留公式、依据、条件、生效期、实际容差、app/rule版本、左右值、差额、所有参与项原始行/文件/页签/单元格、数据异常和人工说明。人工复核不能消除差额或阻塞；换资料/映射/规则清除复核，避免误用旧处理状态。


0.1.3补充：利润范围必须由用户明确确认采用全体所有者净利润，未混入归母利润/不同补充资料范围；未确认阻塞PL2/PL3/X1/X4，新导入重置。此确认与现金/留存全部构成确认分别保留，不可互相替代。数学关系核对日期范围和中国政策生效期仍分开；未声称覆盖全部中国会计政策。

0.1.3可读性返修不修改财务算法、金额容差、确认条件、有效期或来源。默认财务身份与卡片是完整底稿的视图投影，所有技术字段保留在完整详情/原导出列；转换仅发生于React视图，数学与导出仍独立。
