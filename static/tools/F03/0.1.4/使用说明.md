# F03 财务报表勾稽

应用0.1.3候选；尚未官网最终accepted。七页完成资料导入、项目对应、规则、结果、差异复核、来源、底稿与工作。

解压候选离线包，用Chrome/Edge双击index.html。先体验完全虚构样例：13确定等式通过，净利润80与经营现金流70的差额10仅提示。再用模板录入本机资料，可导入CSV/XLSX并选择页签、表头及异名字段。每行一个报表项目金额，BS/PL/CF/BR，期初/期末/本期；期间开始日和结束日表示同一流量区间，期初为开始日前一天。支持CNY等三位币种代码、元/千元/万元，不自动换算；个别和合并分开。

完全同名项目自动对应，异名手工确认。重复、缺失、公式金额、币种/单位/期间/范围不一致会阻塞相关关系；缺失不补零。规则页确认现金构成与留存桥接资料完整，各桥接项仍需依据。内置关系可启停、修改容差、降级提示；新增标准项目加减关系须填依据、条件和有效期，不支持任意公式语言。净利润与经营现金流不能升级为硬等式。

差异页记录复核人/状态/说明，不改变数学结果。来源页保留文件/页签/行号/金额单元格和原始字段。下载九张表XLSX底稿、结果CSV及当前资料。全部金额计算按原始精度，导出精确文本；显示2/4/6位不改变容差。

主动保存无数据方案或含数据完整工作JSON(schema_version=1)，明确包含数据。恢复重新校验并重算；无数据恢复清空资料，新导入重新确认桥接。换资料/规则/映射清除旧复核。仅内存读取计算；没有上传、日志、遥测、默认持久化、CDN、在线字体、更新或外部请求。关闭/清空/退出清除工作。文件10MB、解压30MB、20000行、200列、单格10000字、100个资料组合；宏/外链拒绝，公式不运行。程序通过CSP阻断网络。

边界：勾稽通过只指当前已启用规则及已对应资料，不代表审计通过、报表无错、附注完整或全部法定财报。未对应/不参加规则行独立列示。无AI/OCR、账套连接、自动调平或完整报表生成。中国财务政策适用与报表确认由用户负责；本款只核对跨格式稳定汇总关系。Mac Chromium实际验收以证据为准，Windows实机未验证。

源码包Node22+四命令：npm ci；npm test；npm run typecheck；npm run build。安装可用缓存，成品断网运行。公开官网归入原结账模块tool-close-09「报表数据溯源」，原生program只加载F03当前包，由总控接入验收。


0.1.3规模交付：604行完全虚构资料、17个主体/范围/期间/币种/单位组合，连续12月及年度资料独立核对。体验按钮和604行CSV/XLSX可下载；后者第二页签第二行表头，金额列名为本期列报。全表25行分页可跳首末页；规则每页5条，九张底稿表可逐表预览全行。尾行来源J605（CSV）/J606（XLSX）。新资料必须重新确认同利润范围及桥接完整性。规范长表仍非任意宽式财报自动识别。

XLSX生成时明确写入固定应用文档时间及ZIP成员时间，确保公开虚构版本资产可逐字节重建；这不是对用户报表期间或来源日期的修改。实际导出仍保留用户输入原期间与每行来源。预期由独立Python Decimal生成，源码含生成脚本与全部输入。

0.1.3财务可读性：底稿默认先显示中文主体/期间、财务关系、状态和精确差额；来源默认为项目、原金额与金额单元格。技术ID和完整结构保留在可展开详情及导出；原始字段以中文名称和值显示。手机改为每页5条财务卡片，标准项目编辑与查看差异入口直接显示，顶部可输入页码并跳首末页。桌面每页25行。九表列和全部资料仍完整保留，详见界面字段映射.md。0.1.1冻结产物保留，当前源码/说明/程序版本0.1.3，不兼容旧版本JSON直接恢复。

0.1.3窄屏计数返修：结果计数以完整数字单行显示，手机单列卡片；超长计数独占一行，并按卡片可用宽度适配字号，不舍入、不缩写、不截断。工具自身手机头部、导航和口径栏收紧，七页入口和状态全部保留，官网框架由总控负责复验。0.1.2候选及正式包原字节保留。
