# M02 量价结构差异分析

候选 0.1.2，九页财务工作链。先下载并解压离线包，再用Chrome/Edge双击 index.html，断网使用。所有数据仅浏览器内存，关闭、清除或退出即清空；无上传、日志、遥测、默认保存或外部请求。

1. 载入完全虚构样例，或分别导入基期、本期CSV / xlsx，选页签和表头后确认。
2. 比较口径页设置不同的 YYYY-MM 期间，检查两侧字段对应、币种、金额单位、数量单位、口径、分类与产品ID。可配置顺序与共同样本范围；确认后计算。
3. 数据检查页先复核缺失/重复/公式、期间外排除、收入与毛利覆盖。成本缺失只阻塞毛利；无另一侧记录是新增/退出，不伪造来源零。
4. 样本范围页检查共同、新增、退出、零负值与阻塞项目；收入、毛利桥接页检查因素、原始金额偏离及舍入残差。
5. 业务层级查看分类和产品；来源追查选择项目定位两侧原行。所有表支持全量搜索和50行分页至末行，无截断。
6. 保存与导出：无数据方案只含参数，含数据工作包含两期完整原资料；恢复后重算。Excel含桥接汇总、分类贡献、收入与毛利产品贡献、来源检查、参数版本及两侧原始资料；CSV全产品全指标。分页搜索不影响导出。

每文件10MB，xlsx解压30MB，20000行200列。拒绝xls/xlsm/宏/外链；公式一律阻塞，不读取缓存作为输入。数值最多18位整数6位小数，不接受千分位和科学计数法，空不等于零；金额以十进制文本导出。单价/单位成本须用标记的金额单位/数量单位。跨币种单位分区，无自动换汇。

原始收入/成本可选：未映射按数量×单价/单位成本计算；映射后空值阻塞相应指标，原始金额与数量价格模型的偏离单列。此工具分解金额毛利，不将毛利率变化自动归因，不作因果或会计税务判断。

应用0.1.2，规则M02-2026-10-05.3，schema_version=1，只接受当前版本。Windows实机未验证；公开官网同包同结果与正式发布由总控验收。使用状态和实际证据见验收证据.md。
