# M02 财务规则

规则 M02-2026-10-05.3，应用0.1.2。适用于已确认两期、最细业务粒度的数学底稿，自2026-10-04版本启用，无税率/会计政策判断，无会计政策生效期要求。参考FTI 2024-05-03方法边界，顺序替换公式自主设计；不是经营因果证明。

## 输入与范围

基期、本期分别选择YYYY-MM，期间外行单列并保留原值。键为[币种,金额单位,数量单位,口径,分类,产品ID]结构化编码。分区为前四项，不跨币种单位汇总；单价和单位成本必须与数量及金额单位匹配。重复键不自动汇总或选第一行，整组阻塞且全部来源可达。缺失数值为null，永不填零。

单价/数量均为正数且双侧存在的项目为共同；仅单侧为新增/退出；双侧存在但任一数量/单价为零或负数，整项变化列零负值，不计算份额。关键字段/公式阻塞所有指标；单位成本或原始成本缺失只阻塞毛利。共同样本范围仅包含共同正数项目，其余金额在明细保留但不进桥接。新增与退出不推断业务生命周期，可能来自范围变化，应复核。

## 顺序替换

每分区、每指标分别构造有效共同样本（收入与毛利覆盖可能不同）。Q_t=Σq_it，s_it=q_it/Q_t，模型收入=q*p；模型毛利=q*(p-c)。从Q0、s0、p0、c0出发，按用户选定顺序替换Q、s、p、c为本期值，F=Q*s*(p-c)。收入固定c=0。每因素金额=替换后F-替换前F，成本因素带毛利影响符号。不同顺序分配交互项不同，均保留回勾，不能互当因果。

原始收入字段未映射时使用q*p；原始成本未映射时使用q*c。映射原始金额时不可缺失。共同样本原始金额偏离变化=(本期实际-本期模型)-(基期实际-基期模型)。新增/退出/零负值用实际金额全量列示，不再加模型偏离以免重复。

分区本期-基期 = Σ因素 + 新增金额 - 退出金额 + 零负值变化 + 原始金额偏离变化 + 舍入残差。阻塞已知金额、未知行数及范围外项目数单列，桥接仅覆盖有效范围；容差通过不代表原始资料完整。分类由产品贡献加总，不重新用分类均价分解。

## 精度与来源

输入最多18位整数6位小数，Decimal独立clone70位有效数字。因素逐行四舍五入至配置0–6位；实际金额保留乘积精度，舍入残差=实际变化-全部已输出贡献，不隐性归入结构。容差与精度独立，默认0.000001，仅判残差绝对值；不能静默抹掉差额。图表Number只做比例，所有表与底稿使用十进制文本。每项保留全部原文件/页签/行、原值、参数、应用及规则版本。

换资料和参数清除旧结果；方案含/不含数据明确，恢复验证schema及当前应用/规则并重新计算。计算无汇率获取与自动转换；需要换汇时用户应先准备口径一致、汇率方向日期来源已核验的资料，本款仍保留币种分区。Windows和公开同包验收见实际证据。

0.1.2保留全部既有财务公式与范围，规则版本.2仅用于恢复与操作边界版本隔离。缺数量/单价归待复核（原版界面归零负值但指标已阻塞），不改变金额纳入规则；收入/毛利覆盖与原始偏离仍独立。组合双侧40000行上限由每侧20000行校验保证；方案文件最大10MB。全24顺序、0–6精度、两范围两容差有独立Fraction预期验证。
