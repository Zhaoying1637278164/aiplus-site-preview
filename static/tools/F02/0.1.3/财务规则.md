# F02 财务规则

规则 F02-CAS31-2026-10-04.2；应用0.1.2。适用执行中国企业会计准则的一般企业个别报表辅助编制，2007-01-01起（财会〔2006〕3号通知原适用上市公司、鼓励其他企业；使用者须确认执行该体系）。不默认适用于小企业准则、政府、民非、金融企业或合并报表。

已读财政部《企业会计准则第31号》第二至十九条：第二条现金及现金等价物定义；第四、五、八、十、十三、十五条分类、总额与直接法；第七条汇率影响单列；第十六至十九条附注。原文网址 https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/200806/t20080618_46250.htm 。本款不自动判断现金等价物：纳入账户必须有人工确认依据；不可随时支付的账户明确排除。没有采用仅凭“三个月”自动判断的规则。

1. 固定主体、月度期间、币种、单位；范围外原行保留，不转换币种单位。期间与日期不一致阻塞；2007年前或未确认准则阻塞。
2. 收支金额绝对数，方向流入/流出；0保留，负数阻塞，冲销用真实反向项目并说明依据。精度最多6位/24数字，Decimal40位，禁止隐式空值补0。
3. 项目依准则总额分方向汇总；无已确认项目依据时仅按用户业务类型完全匹配且生效的唯一规则分类；多条命中/冲突阻塞，不从摘要/余额猜测。处置长期资产净额、取得/处置营业单位净额等需额外净额及附注证据，本版对应三个项目阻塞，不以普通收支替代。
4. 内部划转只在同主体、期间、币种、单位、两纳入现金账户间，划转ID恰好两行、不同账户、互指对方账户、反方向、金额完全相等且每行有依据时排除流量表；仍逐账户勾稽。与排除账户划转不可内部抵销。
5. 调整重分类金额非负，有唯一关联收支行，同账户同方向、原项目等于原分类，累计不超过原行金额；目标同方向，减少原项目、增加目标，净流量不变。补录须有账户、方向、目标、凭据说明，增加原账户收支；同时提示补录并要求复核。不允许无来源凑平。调整异常不部分应用。
6. 非现金事项单列原行和依据，不进入现金流量或余额；本款不从非现金事项生成间接法附注。
7. 经营/投资/筹资净额=各类流入−流出；净增加=三类净额+逐纳入账户输入的汇率影响。整体残差=期初+净增加−期末，逐账户残差=期初+原始收支净额+有效补录+汇率影响−期末。未分类金额仍参与原始收支勾稽；报表勾稽另列未分类净额，不能以轧差解除阻塞。
8. 所有必填金额含汇率影响必须显式提供，无影响填0；资料未提供则对应量为null。容差默认0，容差内非零残差标“非零残差待确认”并保持阻塞，禁止容差掩盖未分类或坏行。
9. 收支完整性与账户范围由用户明确确认；即使勾稽为0，也仅表示给定资料对得上。所有报表均为辅助底稿，完整间接法调节附注、非现金重大投资筹资披露和现金构成附注仍须财务人员另行编制。

## 0.1.2 连续多月辅助编制

CAS31第二条一定期间收支、第七条汇率影响、第八条直接法。新增已读CAS32第2、6（三）、7、12条：中期短于完整年度；法定中期现金流量表为年初至中期末及上年可比。本版允许明确起止月的月度/季度/累计辅助底稿；季度自身流量并非完整法定中期报表，不提供比较期及完整附注。原文：https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/200806/t20080618_46249.htm ，实际原始HTML在0.1.2/cas32.html。沿用财会〔2006〕3号适用依据，不采用外国规则。

每账户每月一行，每月分别核对期初+实际收支含补录+汇率影响−期末。区间取首月期初/末月期末，项目收支、汇率影响按实际月份累计；不累计各月余额。每账户上月期末必须与下月期初相等；账户任一缺月、纳入范围/性质变化分别阻塞，范围变化需专项口径资料，本版不自动补0或凑平。每月均须确认收支完整，包括已确认零发生月份；未确认不能猜中间月为0。ID按月唯一，内部划转不得跨月自动配对。

保持单主体、单币种、单单位；异币种单位原行列为范围外并保留，不混加、不换汇。区间最多120个月，起止月份严格检验。月内和区间账户残差同时保留；相反残差不轧差放行。完整附注、特殊净额项目、间接法及金融/合并继续未实现并阻塞对应业务。
