# 现金流量表编制

应用0.1.2候选。一般企业、中国企业会计准则、单主体连续月度区间单币种单单位的直接法辅助编制。只有现金余额不能自动还原收支；间接法调节附注、合并、特殊净额、金融行业格式、自动汇率折算未实现。

解压离线包，Chrome/Edge打开index.html；无需账号，断网运行。九页完整工作区：范围、账户余额、收支、项目、划转、调整非现金、报表、来源、底稿恢复。先体验完全虚构样例，再导入自己的静态xlsx或UTF8 CSV；页签及表头行可选，原列可映射。按四类空白模板提供账户、现金收支、可选调整及非现金事项。必填金额空不补零，无汇率影响明确填0。

账户纳入依据、资料完整性须明确确认；流水金额使用绝对数、流入/流出方向。项目分类需原行依据或唯一业务类型规则。内部划转两腿互指、等额反方向且两账户均纳入。重分类关联原行，不改现金净额；补录必须有实际凭据。未知分类流入和流出单列，即使净额零也阻塞。逐账户与整体残差均显示。所有输出为辅助底稿，完整附注另编。

财务资料只在浏览器内存，不上传、遥测或默认持久化，退出与关闭清除。主动下载含数据工作方案以保存全部原资料/规则/复核，无数据方案仅规则；schema_version1，恢复重新核算。每次换资料或口径清除旧结果与复核。

底稿下载为十三张静态表，保留范围版本、报表、净额余额、逐账户、分类来源、项目组成、划转、问题、覆盖、四种原资料。允许下载阻塞底稿用于排查，不能据此宣称报表完成。

单文件10MiB、解压30MiB、单表20000行/200列，金额6小数/24数字，Decimal40位。禁止宏、公式、外链和任意用户代码。仅虚构资料用于本项目验证。Mac Chromium候选验证见验收证据；Windows实机未验证；正式官网和accepted由总控验收。

源码包：Node22以上，npm ci；npm test；npm run typecheck；npm run build -- F02。构建输出 progress/evidence/F02/0.1.2/candidate，可使用F02_OUT改变输出目录。成品无外部依赖。依赖通知随包保留。

0.1.2支持明确起止月份，单月起止相同；季度选三个月，累计选年初到截止月。每账户每月期初期末及汇率影响、每月收支完整性都须明确。月度与区间分别核对，缺月、范围变更、余额断续阻塞。所有表格可搜索、逐页到末行；导出十三表包含区间与逐月事实及全部原始资料，恢复方案重新计算。替换资料、恢复和退出均可取消，确认后清旧结果。季度自身流量和累计辅助底稿不等同完整法定中期报告，比较期与附注另编。
