# K02 财务规则

版本 K02-2026-10-04.1；适用期由用户批准起止月限定。本工具为管理成本底稿数学分析，无会计或税务政策判断。依据：用户提供的有效标准、耗用凭据和批准口径；海外参考仅启发工作结构，不是中国政策。

标准键：主体/期间/标准对象/标准项目/币种/金额单位/产出单位/耗用单位。标准产出 B，单位允许耗用 u，标准价 SP。实际对象项目经显式对应后，在完全相同范围汇总实际产出 O、耗用 AQ 和逐笔 qty×price 得 AC。基准耗用 B×u，可比标准允许量 SQ=O×u（或有独立依据的允许量覆盖）；基准成本 BC=B×u×SP；可比成本 SC=SQ×SP；产出因素 SC−BC，包含明确批准的允许量覆盖影响。

符号：实际减标准；正值为成本增加（不利），负值为成本降低（有利），仅算术方向，不作原因推断。

三种可配置分解：
- 先量后价：用量=(AQ−SQ)×SP；价格=AC−AQ×SP；交叉项包含在价格项中，另显示交叉项诊断但不重复相加；精度残差为0。
- 先价后量：AP=AC/AQ，以12位小数四舍五入用于分解；价格=SQ×(AP−SP)；用量=(AQ−SQ)×AP；交叉项包含在用量项；残差=AC−AQ×AP。
- 交叉项单列：用量=(AQ−SQ)×SP；价格=SQ×(AP−SP)；交叉=(AQ−SQ)×(AP−SP)；残差=AC−AQ×AP。

AC为逐笔数量×单价重建成本；可选账面成本须同组逐笔齐备，空代表未提供而非零。若提供账面总额LC，实际终点采用LC，未解释差额=LC−AC；没有独立来源原因时不归因。部分账面值缺失阻塞整组。每项和连同未解释差额精确回到实际成本−SC；BC+产出因素+价量因素+精度残差+未解释差额=实际成本。Decimal独立克隆100位有效数字；输入最多24位数字/6位小数；乘加不舍入；AP只在明确12位分解口径舍入。显示0–6位不改变原值；容差只判断残差需复核，永不删除或调整残差。

零允许。AQ=0且AC=0时AP缺失：价项0、量项−SQ×SP、交叉诊断不适用；不假造价格。负产出/负耗用/负价格/负标准阻塞对应行，红冲须先以有依据净耗用资料整理，禁止工具自动抵消。空、公式、错误单元格、重复ID或业务键、缺少产出/标准/对应/来源依据、不一致范围和生效期外均不可比单列。不能用已有材料推断缺少材料为0。标准有项目而实际缺耗用，必须显式提供0行才可比较。

每个标准组最多对应一个实际对象项目，防止同一标准或产出重复扩张。重复阻塞整组；不做模糊对应、不换汇或换单位。金额按主体/期间/币种/金额单位分组，不能跨币种混加。原始行与所有计算参数随证据和底稿保存。复核文字记录依据，不覆盖系统分类。
