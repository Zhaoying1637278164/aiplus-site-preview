# K02 成本差异分析

应用0.1.0，规则K02-2026-10-04.1。官网工具库的成本模块内选择「成本差异分析」，进入详情后开始工作。不需要账号或API Key。离线使用时下载工具包并解压，用 Chrome 或 Edge 双击文件夹里的 index.html，断网也可运行。先体验完全虚构样例，再导入自己的资料。

按九页导航导入标准成本、实际产出、实际耗用、对象对应四表（CSV/XLSX）。XLSX可选页签与表头；非标准列名在字段对应内指定。所有资料须保留主体、月期间、币种、金额单位、产出单位和依据。标准还需标准版本、标准产出、单位允许耗用和标准单价。对象对应是明确的实际到标准关系；不猜测。耗用表账面成本列可全部留空，金额以数量×单价重建；若提供账面金额须逐笔齐备，与价量重建金额的差额独立列示为未解释差额。

可比口径页设置生效期、分解顺序、复核容差与显示位数，填写批准人和依据，再勾选批准并计算。按实际完成产出×单位允许量重建可比标准，允许覆盖必须有单独依据。默认先量后价，交叉含入价格；也可先价后量或交叉单列。均价需要时按12位计算，精度残差不调平。正值成本增加，负值成本减少；不推断经营原因。

桥接展示原标准→产出调整→可比标准→价量因素/交叉项/残差→实际成本。源行页查每个项目的标准、产出、对应和所有耗用来源，单列不可比、未使用和完整覆盖；复核说明只留痕、不改变计算。

底稿页下载13页XLSX、明细CSV、含原始资料的JSON证据；主动下载含数据工作或无数据方案。恢复后须重新批准计算。换资料/字段/规则清除批准及旧结果；无数据方案恢复时清空原资料。退出或清空清除内存，没有自动保存。

限制：每文件10MB/解压30MB/20000数据行/200列；最多6位输入小数、24位数字，金额使用Decimal，输出XLSX为精确文本。公式、宏、外链和用户代码不执行。空不等于零，缺耗用必须提供有依据的显式零记录；负耗用/负价需先整理净耗用依据。本款不换汇、不换单位，不将不同范围连接，不自动记账或决定会计税务政策，不提供AI/OCR。

只用完全虚构样例开发；用户文件仅浏览器内存导入计算导出，无上传、持久化、遥测、外部请求。含数据下载请自行保管。Windows实机未验证。离线包、同版本源码、四类模板、说明和完全虚构样例在工具详情内分别提供。源码重建说明见源码包中的 docs/source-build.md。
