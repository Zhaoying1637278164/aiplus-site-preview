# A03 财务规则 · A03-2026-10-04.1

依据详见参考来源.md。适用2007-01-01起执行企业会计准则的企业，普通固定资产、无形资产出售/转让/报废/毁损个人底稿。非政府会计、非持有待售、非交换/重组/合并交易。用户必须确认适用条件。未核验税率与特殊交易自动判断功能阻塞。

1. 每条资料的主体、批次、期间、币种、单位须与方案一致；处置日在期间内，账面日在处置日前或同日。三类表均保留原文件、页签、行号与原值；资产及处置ID重复阻塞，不凭名称配对。
2. 账面原值、累计折摊、减值非负；补提折摊非负且有依据；累计折摊+补提+减值不得超过原值。不自动测算折摊。日截止≤处置日；月截止仅固定资产、必须等于处置月末，作为当月整体金额归属，处置后不另计日折旧；无形资产不能选月末。
3. 全部处置直接使用完整账面构成。比例处置比例在(0,1)，三构成额按输入精度四舍五入到6位，原值减处置额为保留额，余量不再次舍入。指定金额处置须三个明确金额且各自不超过总额；处置净值与保留净值皆非负。部分处置必须有分配依据。比例额精度与显示精度分离。
4. 对价非负。含税：不含税收入=对价−明确销项税额；不含税：应收总额=对价+销项税额。销项税额不能缺失，确认零也须有依据，不猜税率，不把销项税计入费用。不自动决定VAT简易计税/抵扣/优惠/所得税。
5. 税费状态“确认零”要求依据且无明细；“明细”要求至少一条匹配明细。每条税费为非负损益金额+可抵扣税额=支付/应付总额；其他税费不允许可抵扣税。种类/税费ID/依据必填，重复ID阻塞。费用明细按处置ID归属，不静默分摊，不相关行也保留并阻塞整批导出。
6. 净值=原值−截止累计折摊−减值。处置损益=不含税收入−处置净值−处置费用−其他税费。正收益、负损失、零损益各自保留。合计只纳入有效处置，同时公开阻塞数量，存在阻塞不能导出正式测算底稿。
7. 借贷底稿由“补提→转销→对价→税费→结转”生成，每阶段与每处置精确平衡，科目映射须人工确认。固定/无形原值累计科目分开；清理过渡科目、费用负担、应收/应付、销项/抵扣税、损益分类由用户确认；本工具不自动认定资产处置收益/营业外列报，不入账。
8. 金额Decimal40位、最多输入24位数字/6位小数；空不等于零，负值不接受为普通资产处置（红冲另案），零原值及零对价允许。精度0–6仅控制显示；容差仅用作账面核对不改变公式。未提供可选“账面净值”保留未核对状态；提供时超容差阻塞。
9. 导出包含参数、应用规则版本、复核依据、全部原始资料、有效结果、阻塞、余量和分录。更改资料/参数/映射/复核输入使原复核失效。关闭或退出清空内存；方案用户主动下载，schema_version=1，明确含数据，不含数据只保存规则与映射。
