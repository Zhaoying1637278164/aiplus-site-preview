# A03 资产处置测算 0.1.0
解压后用Chrome/Edge打开index.html。断网也能运行；无需账号。八页导航依次完成批次、账面、截止折摊、税费、分配、复核、分录、导出。
三类文件支持UTF-8 CSV及xlsx，选择页签/表头行后映射字段。每文件10MB，解压30MB，20000行200列；拒绝宏、外链、公式单元格。编号使用文本保留前导零。
金额单位元/万元、币种、主体、期间须一致。折摊金额由已确认底稿提供，不自动计提；处置月仅固定资产允许，属于整月金额归属。税额、费用不可空。无费用必须填写确认零及依据；销项税与费用分开。
部分处置选择比例或指定三个账面构成金额，填写依据。剩余账面不会自动写回企业台账。科目映射必须确认；每项损益复核填写人名和依据才可下载测算底稿。诊断底稿可保留阻塞及全部原始资料。
任一数据/规则改动使复核失效。方案主动下载，包含数据或仅参数由用户选；恢复后重新确认科目并复核。页面退出清空内存，不上传、遥测、自动持久化或请求外网。
适用于采用企业会计准则的普通固定/无形资产。特殊交易自动处理阻塞，不决定税率、不入账、不审批、无AI/OCR。Windows实机、正式官网验收由总控另行验证。
