# B05 预算版本与假设对比

候选0.1.0，七页独立工作链：版本登记、比较口径、变化明细、假设对比、金额桥接、来源与异常、保存与导出。总控尚未正式官网验收，不标accepted。

解压候选离线包，Chrome/Edge双击index.html，断网也可使用。先载入完全虚构样例；再分别导入两份独立CSV或xlsx，选择页签/表头并确认。进入比较口径页配置左右字段和业务维度、金额、期间、币种、单位、口径版本。假设字段可选，金额缺失不会补零。

计算后新增、删除、变化、相同、口径变化、待复核分开复核。重复比较键默认整组阻塞；只有确认同粒度可加时选择汇总。不同期间币种单位不混算。相同口径金额桥接原可比+新增-删除+共同项变化=新可比；口径变更及异常金额另列。假设只比较提供的静态字段，不猜原因，不提供量价归因。

所有表50行分页，首页/上下页/末页和搜索可访问全部记录；导出全量六页xlsx（变化、桥接、假设、两侧来源、参数版本），不按分页截断。金额写为十进制文本。

用户文件只在浏览器内存读取计算导出，不上传、不遥测、不默认持久化。关闭清除。主动下载无数据方案（只有参数）或含数据工作（两份原始资料），schema_version=1，应用/规则严格匹配；恢复后重新计算。无数据方案恢复后重新导入两侧文件。

上限10MB文件、30MB解压、20000行/200列、单元格10000字符；仅UTF-8 CSV/xlsx，不支持xls/xlsm/密码文件、宏、公式和外链执行；假设公式或金额公式阻塞。候选Mac Chromium实测见验收证据，Windows实机未验证。

源码：Node22+，npm ci；npm test；npm run typecheck；npm run build -- B05。本款候选ZIP采用隔离package.json，四命令只构建本款，不覆盖其他工具或release。官网总控使用src/program.tsx的ToolProgram原生mount，源码业务模块engine.ts独立于React。
