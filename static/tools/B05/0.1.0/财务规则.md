# B05 财务规则

规则B05-2026-10-04.1，自2026-10-04起适用本款确定性版本底稿，无会计税务政策判断。依据为用户确认的比较粒度/字段/口径及本项目共同口径。

金额最多6位小数24位数字，Decimal精度40；输出保留原精度，显示不舍入。比较容差决定相同/变化，重要性仅标记，不删差额。币种/单位/期间进入分区，不换汇、不合并单位，YYYY-MM期间有效。口径版本不同的共同项不进入可比桥接。

业务维度结构化编码，去首尾空格可选。不默认忽略大小写。新增表示旧版不存在，删除表示新版不存在，缺失金额不视为0。重复键默认整组待复核，含对侧；用户主动选同粒度汇总时全部来源保留，口径版本/假设冲突整组阻塞。汇总不代表记录逐一匹配。

各分区桥接：新版可比合计−旧版可比合计=新增金额−删除金额+共同项原始差额。容差内差额仍完整进入桥接。阻塞金额按两侧单列，空金额未计入金额而保留行数。全来源行数=有效可比来源+阻塞来源。

假设字段可选对应，只比较静态值，空值明确缺失；不解析公式、不运行任意计算、不声称量价或因果金额归因。无假设时仅金额差异。范围改变造成新增删除，由用户复核不是错误结论。
