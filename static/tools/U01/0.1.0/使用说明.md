# U01 凭证异常检查

候选0.1.0，八页凭证复核工作流。只提供线索，不认定舞弊、不生成审计结论；未命中不等于无风险。尚未官网验收或accepted。

解压候选离线ZIP后双击index.html，用Chrome/Edge运行，无需安装或账户。先载入完全虚构样例，再在「凭证范围」导入UTF-8 CSV/XLSX、选择页签/表头确认换入；核对字段及主体、期间、币种、单位。金额必须静态十进制，空不补零，负数保留原方向，公式单元格不可用。

「检查条件」配置八条规则及依据、生效期；「执行覆盖」查看逐项未执行原因；「异常复核」填写人、日期、依据及状态；「凭证勾稽」「原始来源」追查全部组成行。每表25行分页与筛选，来源定位可返回全部。

「底稿与恢复」导出十表完整底稿或线索CSV，导出不受筛选影响。主动下载无数据方案或含数据工作，后者含原始资料和复核信息，请自行保管。恢复无数据方案清资料，含数据工作重算并清复核。成功换资料/改参数也清复核；失败导入保留旧工作。

所有文件在浏览器内存处理，无上传、遥测、默认存储、CDN或外部请求。10MB输入、解压30MB、20000行、200列、单元格10000字限制。不执行宏、公式、外链或用户代码。关闭、清空或确认退出清内存及下载URL。

Mac主机Chromium验收状态见验收证据.md；Windows实机未验证。官网/正式包/发布及独立验收交总控。

源码独立候选快照包含锁文件、共享包、本款代码、测试、固定虚构样例、构建脚本及许可。四命令：npm ci；npm test；npm run typecheck；npm run build -- U01（生成本款candidate/0.1.0，不写正式release）。源码包根脚本针对本款，原工程公共package.json未改。标准原工程正式构建与发布仍由总控办理。
