# U01 财务规则

规则版本 U01-2026-10-04.1，应用0.1.0。以下为自定义凭证筛查的产品定义，生效于本版本；不是法律、会计税务政策或审计准则的默认规定。阈值、关键词、特殊日期、科目组合由用户确认。依据为用户内部复核要求，须填写依据和生效期；政策不明确时关闭对应检查。

范围严格匹配主体、期间（YYYY-MM）、币种及单位，不换汇。标识不足不能确认范围，列为范围不可判定；日期与期间不一致列数据异常。凭证分组键为主体＋期间＋凭证ID＋币种＋单位，不按凭证ID跨主体合并。原行来源为文件＋页签＋物理行号；重复行ID不丢行。

规则：借贷差额绝对值超过独立容差（凭证级）；行单边绝对金额max(|借|,|贷|)达到阈值；非零单边金额为所设整数倍；周末/指定特殊日期；摘要包含字面关键词；制单人等于审核人；同凭证出现用户指定的两个不同科目；相同凭证行ID重复。另独立展示字段缺失、双边非零、负数、日期期间不一致等数据质量线索。

每条规则有已执行和未执行对象。缺失必需列使整条规则未执行；对应行缺失/公式/非法金额使该对象未执行；凭证级任何组成行所需值不可用使整组未执行。重复检查需要整组行ID完整。借贷和金额相关规则均要求两个金额显式提供；空不等于零。关联科目完整性不足时不声称未命中。

金额公共amount解析，最多6位小数、24位数字，Decimal精度40。阈值非负、倍数正数，容差非负；不得先四舍五入后判定；展示六位原精度或原值。借贷合计与差额按分组核对，不跨单位币种总加。负数不自动转方向。整数倍用十进制余数，零不触发。

复核只记录待复核、已补充解释、需跟进和依据，不输出通过或审计结论。换资料/范围/字段/规则均清旧复核，恢复重算也清复核。导出包含全部来源、范围例外、参数和版本、规则覆盖、线索、勾稽、质量问题与复核。未命中不等于无风险；本工具不验证资料完整性和真实性。
