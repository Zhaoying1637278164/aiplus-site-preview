# C03 待摊费用排程

应用 0.1.1。下载离线包并解压后，用 Chrome 或 Edge 双击本文件夹内 index.html；断网可用，无需账号或安装。官网与平台实际验收状态见项目 progress/STATUS.md；Windows 实机未验证。

十页完整工作：概览 → 费用台账 → 摊销规则 → 月度排程 → 本期底稿 → 变更管理 → 余额核对 → 来源追溯 → 方案与导出 → 使用说明。
先用完全虚构样例理解口径，再填空白模板；列名保持不变，金额/实际已摊均必填，0是有效值，空不是0。未来新事项可验证并追加，已有事项ID重复或进入已确认期间会阻塞；历史保留。固定中文列名见空白模板；CSV必须UTF-8，XLSX可选页签。不读宏、外链、公式、密码文件；不上传、不存日志、不遥测、不默认保存，关闭清空。

规则按月等额或实际日历天数（含首尾日），首尾月分别选择，精度2/4/6位，尾差指定首/末期。尾差导致单期反向时阻塞并提示提高精度。确认本期仅锁定计划，不能替代实际记账；变更需明确依据，只从未来月份生效，支持剩余重排或立即结清。延长受益期需另建新方案由财务复核，本版不自动修改锁定事项起止日。

余额页可追加新的实际已摊累计及截至期，保留原始台账、确认计划和更新依据。实际减计划为复核差额，不自动调平。币种单位逐项保留，不换汇、不跨币种汇总。负值限用户已经批准的红冲，底稿保留带符号金额和科目，不自动生成记账凭证。

主动下载含数据方案（原始行、规则、变更、确认、实际更新）用于恢复；无数据方案只含规则。恢复先核验版本、来源和历史金额，不兼容/篡改失败不会替换现有工作。八张XLSX底稿包括排程、本期、余额、原始来源、实际更新、变更、确认与规则勾稽，金额写静态文本。CSV导出对公式起始字符加单引号保护，负数也可能有此前缀；计算仍使用原金额。源码包含锁文件、共享包、工具代码、测试、说明与完整第三方声明，无node_modules。

源码包解压后：Node22+，npm ci；npm test；npm run typecheck；npm run build。输出release/C03/0.1.1/index.html及runtime.json。构建需安装依赖，成品不联网。源码重建只生成本机成品，不自动修改官网。

边界：不自动判断资产资本化、税务政策，不记账/审批，无AI/OCR。财务须先确定费用性质、金额、受益期间、科目和红冲依据。容量文件10MB/解压30MB/20000行200列，本款500事项/240月/1000变更及实际更新/240确认；含数据方案超过10MB时须拆分工作。方案校验不是外部审计数字签名。

返修候选（同0.1.0，未冻结/未发布）：台账、排程、本期、确认历史明细、变更、余额、实际更新、守恒、来源全部支持50行分页、事项/期间/来源文本搜索。搜索和导出范围分离，导出始终全量；来源匹配使用事项原始文件/页签/行号。“查看原始台账行”直接打开台账并定位事项。确认/规则/恢复/变更/实际更新/追加/换资料后清空页码和旧定位；历史表展示锁定明细，能逐项复核。桌面导航吸顶，320px导航在自身横向滚动并吸顶，长页面仍能切换。
