# C03 财务规则

规则C03-2026-10-04.1，应用0.1.0。适用于用户已经确认费用性质、金额和受益期的内部底稿；2026-10-04起用于本版，不是法定会计政策生效日。政策、税务、资本化、科目选择由用户确认，工具不自动判断。
按月：覆盖受益期的月份等权，可选含首/尾月份；排除的是整个月，不保留该月金额。按日：覆盖实际日历天数，首尾日均计，首/尾月排除仍移除整月。无可摊期间即阻塞。尾差期明确选首期/末期；每期Decimal按指定2/4/6位四舍五入，尾差一次归入选定期；输入金额必须已符合该精度，禁止静默改写。
空不是零；零合法，负数为用户已批准红冲的同方向排程，余额允许负数。单位只允许元/千元/万元，币种须三位大写代码，不换汇。各币种单位独立汇总；不跨币种加总。计算容差独立输入，仅用于实际已摊与计划的复核，精度不受容差改变。
本期确认将计划金额、原输入和规则快照冻结。确认不是实际入账；已摊金额是另行输入实际账务累计。确认按期间顺序，可跨空白月；相同月不可重复确认，不能确认早于已有确认的月份。变更必须说明依据，只允许在最新已确认期间以后生效；剩余重排：修订总额减以前期间计划，除以剩余权重；立即结清：生效期一次分配剩余，后续为零。变更后余额守恒，修订额不得跨零/低于已摊锁定额；已确认历史不能改写。
所有输出保留事项、月份、金额、累计、余额、原始文件页签行、参数、版本、异常及差额。计划累计和确认累计不是实际累计。恢复验证历史快照金额，缺失/伪造/版本不一致阻塞。无法检测外部人为修改后重新构造的完整方案；不作为数字签名审计证据。
文件<=10MB，XLSX解压<=30MB，<=20000行/200列；本款最多500事项、每事项240月、总排程120000行、变更1000、确认240。禁止公式（包括CSV公式文本）、宏、外链，不运行代码。无上传/默认持久化，退出清空。

补充：余额页实际累计追加须有依据及更晚截至期，原始行与计划保持不变；修订总额不得低于最近实际累计绝对值。逐期四舍五入后若尾差造成反向金额，阻塞并提示提高精度，禁止隐含红冲。无确认时改精度会从原始金额重算。含数据方案最大10MB，确认与变更在超限前阻塞。

新增台账：可追加唯一新事项ID，第一可摊期必须晚于最新确认期；不得借追加覆盖已有事项或倒填历史。
