# P03财务规则
应用0.1.0，rule_version=P03-2026-10-03.1；生效2026-10-03起，仅用于用户已批准可核销额度的确定性业务底稿。无会计/税务政策自动判断，无默认税率科目分录；用户需明确批准范围、额度、日期和依据。未采用海外政策。

## 基线与截止
完整历史：原批准可用本金 - 截止日有效确认核销 = 剩余预付；结算批准额度 - 同范围有效核销 = 剩余结算额度。
快照：两端输入均为基线日待核销余额。仅核销业务日大于基线且不晚于截止的有效确认占用；基线前历史保留但不再扣。截止不可早于基线。基线前核销在基线后撤销需用户批准修订快照，不能擅自恢复本金。快照后新增来源不能混入基线余额，改用完整历史模式。未来来源不纳入汇总。

## 分配与撤销
分配稳定ID明确两端关系，禁止相似金额/名称/顺序自动确认。草稿不占用；已确认且日期不晚于截止，且未在截止前撤销才有效。撤销业务日不能早于确认日，撤销保留原记录与依据。截止后撤销不回写历史；撤销截止前恢复两端额度。退款红字独立隔离，关联余额标未知并阻塞，未实现自动退款与跨合同政策。

两端须同主体ID、供应商ID、合同ID、币种、金额单位、含税口径。两端确认累计分别不得超过批准额度；超额/重复/无效关联/冲突传播到关联组，所有该组合法余额停止输出，不先来先占。不会在超額时静默减少分配。合法组逐端原额度=已核销+未核销，按范围单独汇总。

## 数据与精度
金额Decimal十进制，默认输入2位可选0至6位；超过精度拒绝不舍入。显示精确文本；容差只标识守恒检查，不扩大限额。空/零/负各独立异常，负不抵正；未知余额为null不补零。币种/单位不转换。同名不同ID不合并，前导零保留。日历日期严格YYYY-MM-DD，实际账龄按UTC公历天数（非时区瞬间）计算，预计到期后天数独立显示，不作信用判断。

## 版本和证据
同ID同内容跨批次重导不重复占用；同批重复ID含一行无效金额全组阻塞。冲突双方隔离，显式选择有批准依据、事件保留原候选。原行依据修订与规则变化清复核、保留上次结果及版本比较；确认历史普通编辑禁止，允许明确撤销/有依据版本冲突选择。复核只是处理说明，不能解除数学或关联阻塞。

原文件/页签/行号、参数、规则版本、异常、分配、余额、事件及上次基线进入16页签底稿。含数据工作恢复从原行重算；无数据方案不得携带业务关联/批准/事件。详见独立预期与测试证据。
