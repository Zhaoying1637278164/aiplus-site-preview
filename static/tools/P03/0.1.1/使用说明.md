# P03 预付款核销

应用 0.1.1。解压离线包后，用 Chrome 或 Edge 双击本文件夹内的 index.html；无需安装，断网可用。先查看完全虚构样例，再导入自己的资料。用户数据只在浏览器内存处理，关闭即清除，不要求账户或 API Key，不上传或默认保存。Windows 实机未验证。源码包包含锁文件、共享包、工具源码、测试、构建说明和第三方声明；官网验收状态见项目 progress/STATUS.md。

## 使用流程
1. 工作总览选择截止日、完整历史本金或余额快照，填写依据后应用口径。
2. 导入预付台账与结算资料，预览选择页签和字段映射，确认合并或批准替换。金额必须为实际预付本金/明确批准额度，票面额仅作说明。
3. 人工分配填写稳定分配ID、两端ID、十进制金额、业务日与批准依据；草稿不占额度。核销资料也可导入CSV/XLSX。
4. 确认与撤销页逐条明确确认。超额失败原工作保持；撤销保留原记录、日期和依据，按截止日回溯。
5. 查看余额、实际预付账龄、预计到期后天数和范围守恒；异常页记录复核或明确选择冲突版本。复核不能强行解除阻塞。
6. 来源与底稿页下载全部16页签底稿、4类当前标准资料CSV、含数据工作或无数据方案。方案恢复先预览再确认，取消保留当前全部工作。

## 输入
预付：预付ID、主体ID、供应商ID、合同ID、币种、金额单位、含税口径、业务日、金额、批准依据；供应商名称与预计结算日可选。
结算：结算ID和同一范围字段、业务日、批准可核销金额、批准依据；票面金额仅说明。
核销：分配ID、预付ID、结算ID、金额、业务日、草稿/已确认/撤销、批准依据；撤销需撤销日与依据。
退款红字资料单独隔离，不自动净入本金；关联余额阻塞，需明确批准修订来源。

使用模板或在预览映射现有列，编号前导零须以文本保留。金额无千分位、最多6位小数，超过所选输入精度拒绝；币种、单位与含税口径不自动转换。单文件10MB、解压30MB、单工作20000原行、200列、事件/冲突各2000、工作/下载10MB，超限分批。XLS/XLSM、宏、外链、加密文件不支持；公式及缓存值禁止使用。

## 边界
不发起付款，不自动记账、抵税或提供分录，不判断发票可抵扣资格；批准额度由用户输入。禁止自动相似/名称匹配、跨合同核销。草稿不减余额，双端累计超额阻塞整个关联组，相同ID同内容重导幂等，变更冲突明确选择并留版本。快照两端均为同一基线日批准余额，不再扣基线前核销；基线前核销之后撤销阻塞并要求修订批准快照。快照模式新增预付/结算请改完整历史模式。

账龄按严格公历从实际预付日计算，预计到期后天数独立展示，不默认风险分档。字段映射保留导入时完整原始单元格，可查看原值；XLSX底稿与含数据恢复同时保留原值和当前标准值。疑似CSV文本公式导出加安全前缀，完整原值在底稿中保留。

所有统计按主体/供应商ID/合同/币种/单位/含税口径隔离，名称不作关联键，未知不补零。
