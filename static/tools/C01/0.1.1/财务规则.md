# C01 财务规则

规则版本C01-CLOSE-20261004.1；应用0.1.0；生效2026-10-04，用于本机单人工作记录。规则依据是本项目规格与已读S01依赖/状态章节，不是中国法定会计、税务政策。用户自行确认企业结账安排；不自动记账、不改变ERP期间、不进行企业审批。

期间必须有效YYYY-MM；主体、币种、单位必填，不自动换汇。本期任务基于月末加用户相对自然日[-31,90]，含0与负数；不隐含周末/法定假日调整。截止日必须不早于前置截止日。观察日显式输入；逾期是未完成且观察日晚于截止日。

每期仅复制模板字段（ID、名称、责任备注、相对日、前置ID、必需证据及模板来源），不带状态、事项、证据或前期完成日期。任务开始与完成需前置全部有效完成；完成需必需证据全部有效且关联事项关闭。上游状态/执行说明/证据/事项变化保守撤销自身及所有后继完成，留变更记录。证据只标字节完整、人工关联，不表示内容充分适当或审计保证。

未结事项必须任务、责任、期限、说明。金额可空，空不等于0；金额单位与币种严格等同本期，使用Decimal精确到2位，超精度拒绝；负值保留符号。统计仅为未结事项金额登记之和，不当资产负债或损益；不设重要性阈值/自动豁免。

封板需全部任务完成、无未处理事项、附件SHA有效；摘要绑定本期任务、证据、事项。封板后所有业务改动拒绝；重开需原因，保留旧摘要。完整归档包含原附件字节，方案不含数据仅模板；用户主动下载后才有持久副本。恢复验证版本、结构、附件字节/SHA/引用及封板摘要。不默认存储，无日志上传、遥测或外部请求。
