# 月结工作台

候选0.1.0。本机单人月结管理：期间建档、模板跨期复制、依赖与截止安排、执行、证据、未结事项、变更记录、封板归档和工作恢复。Windows实机及官网集成尚未验证；候选不计accepted。

下载离线ZIP，解压后用Chrome或Edge双击index.html。无需安装、登录或联网。先载入完全虚构样例体验，实际业务资料仅在浏览器内存处理，无上传、遥测、默认存储或外部请求。关闭/退出清空；请主动下载恢复资料。勿将虚构样例作为会计依据。

## 完整工作流程

1. 「任务模板」导入单页签xlsx或UTF-8 CSV，或直接编辑草稿。6列必须完整：任务ID、任务名、责任备注、相对截止日、依赖ID、必需证据。依赖ID用分号，证据要求填是/否。检查后保存模板。
2. 「期间建档」填YYYY-MM、主体、3位大写币种、单位和观察日。模板可取当前模板或某前期任务；只复制模板，不带任何完成状态、事项、附件。
3. 「依赖与日程」检查前置及截止。截止按月末加相对自然日(-31至90)，0为月末，不自动调整周末节假日。观察日严格晚于截止且任务未完成则逾期。
4. 「本期执行」选任务填写执行说明及原因。前置完成才允许进行/完成，必需证据缺失或关联事项待处理不能完成。上游说明/状态、附件、事项变化保守撤销自身及后继完成，需重新确认。
5. 「证据管理」选择任务添加本机文件，保存原字节、文件名、来源和SHA256。只下载原件，不执行、不预览附件。移除会明确定位缺失并撤销相关完成。
6. 「未结事项」登记责任、期限、说明、来源。金额可空，空不是零；按本期币种/单位精确2位，超精度拒绝，不换汇。处理后填说明，关联任务须重新完成。
7. 「变更记录」查看动作、目标、原因及前后值。此为本机记录，不是企业审批/不可篡改审计认证。
8. 「封板与恢复」查看阻塞项，全部完成、证据齐全、事项已处理才可封板。封板后不可改业务；填写原因重开，保留旧摘要。封板不改变ERP期间。
9. 下载六页月结底稿、完整恢复JSON或完整归档ZIP。完整包包含所有期间和原附件，打开后验证SHA及封板摘要。模板方案明确无数据，仅模板字段和来源，不能恢复本期进度。恢复校验通过并确认替换才换资料；失败保留当前工作。

## 文件范围与边界

表格导入复用共享io，拒绝宏、外链、公式与错误单元格，不运行用户代码。证据允许txt/csv/xlsx/pdf/png/jpg；非表格只按字节保管，文件内容由用户确认。每文件10MiB、全部附件20MiB、恢复JSON与ZIP解压30MiB；最多100期间、每期1000任务/证据/事项、总10000任务、20000变更记录。ZIP仅支持本工具导出的单work.json，验证实际解压体积。

不提供企业审批、多人同步、ERP连接、AI/OCR、会计政策或税务判断。封板及证据完整不代表财务内容正确或审计保证。期间、币种、单位不能混用；未结金额只是事项登记之和，不是报表余额。

## 源码重建

源码包保留锁文件、共享 packages、C01 源码/测试/参考/说明与依赖声明；不含 node_modules、其他业务数据或凭据。在解压后的源码包根目录执行四命令：`npm ci`、`npm test`、`npm run typecheck`、`npm run build -- C01`。两类源码包的脚本定义与输出位置如下。

- **本款候选源码包**：包内 `package.json` 将测试与类型检查限定在 C01 作用域；构建入口为 `tools/C01-月结工作台/tests/build.ts`，输出 `tools/C01-月结工作台/candidate/0.1.0`，不写正式 `release`。在完整工程中单独重建候选，可执行 `node --import tsx --test tools/C01-月结工作台/tests/*.test.ts`、`npx tsc --noEmit -p tools/C01-月结工作台/tsconfig.json`、`node --import tsx tools/C01-月结工作台/tests/build.ts`。
- **总控正式源码包**：四命令使用源码包根目录 `package.json` 的测试、类型检查与构建脚本；`npm run build -- C01` 调用根 `scripts/build.ts`，输出 `release/C01/0.1.0`。正式构建及验收状态以该正式版本的交接证据为准。
