# B03 滚动预测工作台

候选0.1.1，供企业FP&A在本机编制单年度滚动预测，尚待总控官网及正式包验收，不标accepted。

解压候选离线包后用Chrome/Edge双击index.html，无需账户，断网可用。七页依次为资料与范围、实际锁定、预测更新、假设调整、全年展望、版本比较、导出与恢复。

先体验完全虚构样例：收入全年1235元，成本708元。导入UTF-8 CSV或XLSX，选择页签、确认换资料；固定11列表头见空白模板。必须提供全年12期预测基准，实际/暂估情景填“通用”。支持多组织、多科目、多预测情景；同币种同单位，不自动换汇。每表25行分页，窄屏表内滚动。

截止以内按明确策略选实际/暂估/预测；真实实际可锁定、依据解除。截止后按所选情景预测及未来假设计算。资料页改参数立即重算，若与锁定或假设冲突会阻塞，须先显式解除/停用。预测更新页保留原始文件/页签/行号，更新金额需依据。假设调整为差额或替换，可按范围启停。

版本页冻结可计算的完整输入，已有版本只读；复制为当前不会改冻结原件。可比较两个冻结版本或冻结与当前，跨年度/币种/单位拒绝。导出页提供12张XLSX底稿、逐期CSV、模板、虚构样例及JSON工作。完整工作包含数据；不含资料配置仅含范围策略，恢复会清除原资料、锁定、假设和版本。结果恢复后重新计算。

资料只在浏览器内存，无上传、外部请求、遥测或默认持久化。关闭/退出即清除，关闭前主动下载含资料工作。限10MB文件、30MB解压、20000行、200列、1000组织科目组合，金额最多6位小数和24位数字；公式/宏不执行。空、重复、范围/币种/单位问题阻塞，零和负值合法。导出CSV对可能公式文本加安全前缀，XLSX仅静态字符串。

边界：不做企业多人审批、自动系统集成、AI/OCR或会计税务判断；macOS Chromium验收见证据，Windows实机未验证。原官网ToolProgram由总控接入预算模块原条目。

源码：Node22+，npm ci、npm test、npm run typecheck、npm run build。本款可运行 node --import tsx tools/B03-滚动预测工作台/scripts/build-candidate.ts；只写候选证据目录。完整源码ZIP含锁文件、共享包、代码、测试、声明与构建说明，不含node_modules或业务资料。

0.1.1保留0.1.0旧包。冻结版本底稿中的完整输入JSON按30000字符分片，按编号与分片序号拼接可还原；不会删减输入。虚构交付XLSX元数据日期固定用于源码重建字节一致，不是业务日期。
