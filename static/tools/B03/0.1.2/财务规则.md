# B03 财务规则

rule_version B03-2026-10-04.1；应用0.1.1；适用1900–9999单一自然年度、单币种与单位的企业管理预测底稿。生效2026-10-04起，无税率、会计政策或自动记账判断。依据本款明确参数与已核验滚动预测/版本方法；非中国法定会计政策。

粒度：组织编码+科目编码+月份+数据类型+情景（实际/暂估的情景固定通用）。名称不参与键；同编码名称冲突阻塞。基准预测必须覆盖每个组织科目12期；空、重复、范围/币种/单位不符、公式均阻塞。零和负值合法。最多20000行、200列、1000组织科目组合、10MB文件、30MB解压；金额最多6小数24位数字，用40位精度Decimal，显示6位与零勾稽容差独立。

截止期以内选锁定实际，其次实际；严格实际策略缺失阻塞；允许暂估策略以暂估补缺，仍无则阻塞；允许沿用预测策略实际→暂估→预测，并逐期标明未结账。截止后只取所选情景预测，实际/暂估留源但不提前替换。实际锁定只允许截止内真实实际，解除须理由；编辑禁止改锁定行，换资料显式清除当前锁定但冻结快照保留。

假设仅应用截止后预测，差额相加，替换最多一个；先替换后累计差额。调整须有依据负责人，引用存在组织科目与范围，不得跨已关闭期；重复ID、重叠替换阻塞。无静默覆盖。全年=实际+暂估+预测基数+调整；原预测取导入原始资料，更新行不改原基准；原预测合计与展望差额=历史替换差额+未来预测更新差额+未来调整，勾稽为零。

冻结需完整可计算，保存完整范围、源行、锁定、假设和规则；不覆盖既有ID/名称，最多20快照。复制明确转当前工作，原冻结只读。比较必须年度/币种/单位相同；缺失键显示缺失且差额留空，不能默认为零。恢复严格校验schema_version、工具/应用/规则版本、尺寸和静态源值；不信任外来结果，全部重算。无资料配置不含金额资料/冻结/锁定/调整/操作记录。
