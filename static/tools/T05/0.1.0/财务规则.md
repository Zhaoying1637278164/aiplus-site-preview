# 财务规则 T05-2026-10-04.1

生效：应用0.1.0起；非政策数学参数测算，无税率/会计政策判断。依据见参考来源。视角固定借款人：放款本金正，偿还本金/利息/费用负；补贴退款正，所有输入金额非负，负值拒绝而非猜方向。

每笔放款按毛额录入；前扣费独立一行且同放款日，净到账=首日放款减首日前扣费减首日独立费；未来费在实际未来支付日折现。前扣费不可从毛本金再双扣。融资现金成本=利息+费用-退款，净现金支出=-全部现金流之和，未清偿本金另列，两者勾稽差额=还本-放款。未还足阻塞可比，不补尾期还款。

Decimal40位；输入最多6小数且24数字，单位元/万元不换算混比。显示2小数不改变计算；金额容差单独配置。NPV=ΣCF/(1+r)^(实际天数/年化天数)，基准日为比较起日，365或360明确记录，r>-1。原始行逐笔保留。

IRR使用对数利率网格256段+二分，最多100次，归一化NPV残差≤1e-10且利率区间≤1e-10；只在有限搜索范围内找候选根。按日期聚合后零现金流不计符号；同号严格无解，全部抵销无唯一解。一正后全负且跨日为正常借款，可用单调唯一性确认范围内单根；非正常流即使只找到一根也阻塞单一年化结论，未检出不证明无根，切触根可能遗漏。未收敛不返回可信利率。曲线与根范围导出。

比较须同币种单位期间，首末现金日、本金及还本平衡一致；净到账差异单列。异期限可查看各自成本，但阻塞直接排序。费用退款及多次放款触发复核，非正常流不能产生推荐。

求解可选区间扫描＋二分或区间扫描＋保守割线（只在括区中部采用割线，其余二分），相同收敛门槛。恢复采用结构与财务检查分离：结构有效但空金额、重复流水等财务异常允许保存恢复，计算仍阻塞；schema/声明/来源错误拒绝。原文件行保留静态原值，手工修改首次捕获修改前值，底稿保留编辑标记；不执行原值公式。
