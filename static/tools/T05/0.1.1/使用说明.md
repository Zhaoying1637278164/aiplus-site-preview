# T05 融资成本比较

应用版本0.1.0。按借款人视角核对放款、还本、利息与费用，比较净到账、融资现金成本、净现金支出、NPV和有效年化成本。所有财务资料只在浏览器内存处理，不上传、不写日志、不遥测、不默认保存。关闭页面或“退出并清空”后清除内存；需接续的工作请先主动下载。

## 打开工具

在官网的“资金”模块进入“融资成本比较”详情，选择使用工具，在同站页面完成全部七个工作步骤。退出后回到详情，再次进入不保留未下载资料。

离线使用：下载离线包，解压后用 Chrome 或 Edge 双击文件夹内的 `index.html`。无需账号或安装程序，断网可用。先点击“载入虚构样例”，熟悉页面与结果，再录入自己的资料。Windows 实机未验证。

## 1. 比较范围

填写基准日/期间开始、期间结束、币种和金额单位，完整期间必须覆盖全部放款和清偿现金流。设置年折现率、实际天数/365或360、金额勾稽容差，以及IRR搜索上下限和求解算法。币种、单位不混比，不自动换汇；显示位数不改变计算精度，空金额不补零。

## 2. 方案台账

新增并选择方案，填写名称、币种、单位、约定毛本金和条款备注。约定本金和“放款”金额都填扣费前毛额，不填净到账。可新增、编辑、删除方案。

## 3. 条款与费用

逐笔填写流水ID、实际现金日期、类别、金额和说明，金额填非负值，方向由类别决定。放款、退款为到账；还本、利息、前扣费、独立费、未来费为支付。前扣费单独录一笔并与对应放款同日；独立费按实际支付日；未来费在首笔放款日之后。不要先填已扣费用的净放款，又重复录入前扣费。长明细用“上一批/下一批”分页维护。

## 4. 导入现金流资料

从“现金流资料”下载空白模板或虚构样例CSV，按字段填写方案ID、方案名称、币种、单位、约定本金、流水ID、日期、类别、金额、说明。日期为 `YYYY-MM-DD`，同一方案的名称、币种、单位和本金须一致。

选择本机UTF-8 CSV或XLSX，选择页签、表头行并设置字段对应；核对预览后点击“确认替换全部方案”。导入是整批替换，不追加旧工作。最多20方案、2000笔现金流、10MB文件、30MB解压体积、200列；不支持xls、xlsm、密码工作簿，不运行宏、公式、外链或用户代码；计算字段需要静态值。

## 5. 阅读成本比较

“成本比较”分别显示放款本金、首日净到账、利息、费用、退款、融资现金成本、NPV及有效年化。NPV采用借款人现金流方向：到账为正、支付为负；负值代表折现后的净支付。本金与现金勾稽单列净现金支出、本金差额和守恒残差。

本金、首末现金日期、币种、单位和完整期间一致且勾稽通过才可直接比较；净到账差异仍须结合实际资金需求复核。异期限、本金不等或未清偿不直接排序，不提供个人贷款推荐。

## 6. 检查异常与原始来源

“求解与来源”显示输入异常、原文件/页签/行号、求解范围、候选根、NPV残差及曲线。正常借款按日期聚合后一正后负，确认唯一根并收敛才显示单一年化。非正常现金流即使只检出一根，也阻塞单一年化结论；多根、同号无解、全额抵销无唯一解、未收敛或范围内未检出须复核，有限搜索可能遗漏切触根及范围外的根。

已编辑现金流保留编辑标记、修改前原始值及来源；页面显示当前值，完整底稿可回查原值。异常资料不自动调平，应核对原始条款与现金时点后修改。

## 7. 保存、恢复和导出

在“方案与底稿”下载“仅参数方案”（不含条款与现金流）或“完整工作（含数据）”（包含方案、金额、原始值与来源）。恢复JSON先预览是否含数据、方案与笔数，确认后替换当前内存资料；取消则保留原工作。结构有效但尚未填完的工作可保存恢复，财务异常仍阻塞对应结果。方案带schema、应用及规则版本，不兼容文件会提示错误。

点击“下载完整底稿XLSX”，导出比较汇总、逐笔现金流来源、参数与版本、候选根与残差、NPV曲线、异常清单六张页签。金额以十进制文本输出，避免表格软件再次改变精度。导出异常底稿用于复核，不代表异常已解除。
