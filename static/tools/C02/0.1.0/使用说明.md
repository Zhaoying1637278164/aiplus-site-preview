# C02 计提与冲回

应用 0.1.0，完整八页财务流程。下载离线包并解压后，用 Chrome 或 Edge 双击本文件夹内 index.html；断网可用，无需账号或安装。官网及平台实际验收状态见项目 progress/STATUS.md；Windows 实机未验证。

1. 费用依据：载入完全虚构样例，或导入费用依据 CSV/XLSX，选择页签后确认替换本表。第一行表头，按模板字段；费用、规则、冲回申请、变更依据四份表独立导入，也可新增行编辑。
2. 规则与生效期：由用户判断应否计提，填写规则依据、版本、生效起止、币种单位、计提比例及借贷映射。手工冲回或次期全额任选；次期全额不允许叠加手工申请或变更。
3. 冲回申请：部分填正金额，全额金额留空并按当时余额冲回；期间晚于原计提。跨月分次可行，同事项同月重复阻塞。
4. 计划与余额：按币种单位分别看计提含变更、累计冲回、剩余余额与逐月勾稽；有效草稿可能仍含其他阻塞，不能直接入账。
5. 分录核对：费用/负债科目由用户映射；正计提借费用贷负债，冲回和负变更反向；逐笔严格借贷平衡，不通过则阻塞确认。
6. 确认与变更：未来变更填新的计提总额和依据，自动产生差额事件。确认人/复核依据齐备才保存内存快照，最多30版本且完整恢复工作不超过10MiB。资料或规则变动保留旧确认，展示事件及原始字段差异；回看确认计划/分录，下载快照。
7. 异常追溯：按原文件、页签、行号定位。缺失不是零，负金额及精度超限不接受；零提示、不生成分录。
8. 底稿与恢复：下载十三表完整 XLSX、含数据计算证据、含数据工作或无数据方案。工作含四表及历史，无数据方案只含规则和容差，恢复时清空业务与确认历史。恢复校验结构/版本并重算，不接受被篡改历史结果。

数据只在浏览器内存处理；关闭/确认退出清空。资料不上传、不日志、不遥测、不默认保存。文件及完整恢复工作10MiB、解压30MiB、20000行、200列；不支持xls/xlsm、宏、外链或用户代码，禁止公式缓存值。四份资料及所有结果按每页50行分页，无200/500行访问上限；可搜索ID、期间、原文件/页签/行号或任意字段，并使用首页/上一页/下一页/末页/指定页码。搜索保留原记录序号，尾部可直接编辑；异常、事件、分录及余额可定位原始行，费用/规则/冲回/变更来源分别可跳转。历史来源只读，点击即定位对应历史原始表；当前编辑不修改历史。换资料或恢复清空分页搜索定位，切换历史重新分页。

样例：F001计提1200次期全冲；F002计提1200，02冲400、03变更到1500增加300、04全冲1100；CNY累计计提2700冲回2700余额0，USD100分别核对。全部数据虚构。金额2位 HALF_UP，比例最多6位；不換汇或换单位。

复核确认只是本地快照，不是企业审批、自动入账或政策判断。政策不明需由用户专业判断后输入，本工具不猜测。详细口径见本文件夹内财务规则.md，来源版本/许可见参考来源.md；验收证据和实现交接见源码包本款目录。

同版本源码包解压后，使用 Node.js 22 或以上，依次运行 npm ci、npm test、npm run typecheck、npm run build -- C02。输出 release/C02/0.1.0/index.html 与 runtime.json；构建说明见 docs/source-build.md。源码重建只生成本机成品，不自动修改官网。
