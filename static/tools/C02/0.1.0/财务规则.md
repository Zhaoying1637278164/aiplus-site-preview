# C02 财务规则 · C02-20261004.1

适用于用户已自行决定的费用计提及冲回底稿，应用0.1.0。不作中国会计/税务政策判断，没有依据和适用期的政策不内置；用户须填费用依据、决定「计提/不计提/待判断」、规则依据和起止期。待判断阻塞对应事项，非计提事项保留来源不生成事件。

- 金额原始单位不换算，不换汇；每事项与规则/冲回/变更币种、单位必须相同；各币种单位分别勾稽。Decimal40位运算，金额2位 HALF_UP；原金额超过2位阻塞，比例最多6位。借贷比例必须大于零，最终每笔借贷差必须严格零；余额容差参数只标注差异，不改变金额或放行借贷。
- 原计提=费用依据金额×比例，经分位舍入。规则ID唯一且计提期在生效期内。按规则次期全额冲回只生成一次事件；该事项另有手工冲回或变更时阻塞，避免混用。手工规则可跨月分次冲回：部分冲回必须正数不超过当时余额；全额冲回取当时余额；同事项同期间冲回不许重复，即使ID不同。
- 变更ID唯一，指定新计提总额及未来生效期和依据；当期变更差额=新计提总额−已生效计提总额。新总额不得低于此前累计冲回金额；已冲完事项不能再次变更。变更期必须晚于原计提期；同事项同期间不得重复变更。变更不得修改原计提或已确认快照。
- 事件顺序：计提、变更、冲回；同月变更先于冲回。期初余额+计提变动−冲回=期末；累计计提变动−累计冲回=余额；重复/超额请求不生成合法事件，异常全量保留。
- 正计提/正变更：借用户映射费用科目，贷用户映射负债科目；冲回/负变更反向；零值保留提示且不生成分录。无科目映射、相同借贷科目、比例不平衡阻塞确认。
- 确认=用户保存复核快照，不是审批或入账。任何资料/规则变动重算草稿，旧快照完整保留；展示新增/删除/变动事件差异。换资料不静默沿用确认，恢复含数据工作重算确认内容，篡改快照不接受。

来源方法及许可见参考来源.md；全部样例虚构，规则日期2026-01至2026-12仅样例适用期，不能理解为政策有效期。
