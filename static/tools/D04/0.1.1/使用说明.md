# D04 PDF财务表格整理

应用 0.1.1。本包包含本机程序、完整说明、财务规则、模板、完全虚构PDF与Excel预期样例。官网和平台实际验收状态见项目 progress/STATUS.md；Windows 实机未验证。

下载离线包并解压后，双击本文件夹内 index.html 在Chrome/Edge本机运行，无账号、外部请求或安装要求。六页工作链：资料与页码 → 选表与列界 → 分页表头 → 校正复核 → 金额勾稽 → 导出与恢复。

先下载或载入完全虚构PDF，再导入本机文本型PDF。每页查看读取状态，在文字坐标预览中拖动选择矩形，也可输入左/顶/右/底坐标（左上原点，PDF点）。设置递增的列分隔X；输入表名。续页使用相同表名、列界与表头行数，按添加顺序合并。每区前N行作为表头，表头不符/文字跨列/重叠区域会报异常。可删除区域重选；改变范围会清除旧校正和确认。

复核页每页20行，全部结果可翻页。点击单元格校正，必须填写理由，原值与坐标来源保留。点击定位原文高亮该行文本项。逐行确认，排除也必须说明理由并保留底稿。修改财务口径会清除旧确认。金额口径按原PDF确认币种、期间、单位，选金额列及总计行；空不当零，精度过界不自动舍入。样例Missing金额刻意缺失：必须先对原文核查，不可自动补零。独立测试中的补零仅为完全虚构预期。

导出完整XLSX底稿包含整理页、原始正文、分页表头、原文定位、异常与勾稽、参数版本；所有单元格以文本保存，保留十进制原值，不执行公式。CSV下载包含原始与校正全量，为防Excel公式注入，公式起始字符及负号前加文本引号；原始负值以XLSX和方案为准。正式整理表要求全行复核、口径确认且检查无阻塞。

方案主动下载JSON，schema_version=1：可选含抽取文本/坐标/校正/确认，或仅含区域和规则。不含PDF二进制，方案非原文真实性认证。无数据方案恢复后需重新导入PDF并复核。用户资料只在浏览器内存，不上传、不默认保存、不遥测，退出/关闭清空。

边界：OCR、自动识别所有版式、密码PDF、旋转/竖排/无法解码页面未支持；不会造表。预览仅文字坐标图，不是PDF影像，文本项内字符共享该项来源框；不承诺每字符精确字形边框。不依赖外部CMap/字体；缺少PDF内嵌必要映射可能阻塞。10MiB文件、100页、20万文本项/100万字符、200区域、50列/2万正文行，16MiB单解码流/64MiB累计DecodeStream缓冲分配限额；这不是总浏览器内存上限。
