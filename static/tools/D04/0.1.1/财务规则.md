# D04 财务规则 1.0.0

适用：2026-10-04起本工具文本整理复核，非会计政策判断，不生成分录，不自动换汇。

每个表声明币种（默认CNY需用户确认）、期间YYYY-MM或YYYY、单位（元/千元/万元）并人工确认与原PDF一致。表之间不跨口径求和。原文口径文字不自动解析或推断。

金额Decimal.js十进制，金额原字符串保留。千分位仅接受3位分组，括号代表负数，前导负号允许；空、横线、文字不当零。金额精度0–6位，超出精度阻塞而非偷偷舍入；容差≥0且独立于精度。逗号小数格式可显式选择，禁止混用格式自动猜测。输出字符串，避免Excel双精度改变原额；不执行公式。

用户显式指定总计行（按同表序号）及金额列：其余行和为明细合计，差额=明细合计−总计；绝对差额≤容差为通过。缺失/格式/精度异常使该勾稽不可执行。无总计行只显示可执行求和，不声称通过勾稽。重复整行提示人工复核，零/负值保留。排除行要求理由，保留完整底稿和来源，不静默丢弃。

人工校正需理由，原值不可覆盖；每行确认只代表本机用户已对原文核对，不自动提供审计保证。修改范围、列界或表头清除结果校正与确认；更换PDF清除全部旧确认，避免套用旧结果。扫描页/不可靠坐标页阻塞提取，不合成数据。导出完整底稿始终包含异常，正式整理表需全行确认、元数据确认及无金额阻塞。
