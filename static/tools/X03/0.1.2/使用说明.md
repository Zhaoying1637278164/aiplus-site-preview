# X03 纳税调整测算

应用 0.1.2，七页完整测算工作区。官网及平台实际验收证据见项目 progress/STATUS.md；Windows 实机未验证。

1. 确定主体、完整年度、币种单位和会计利润（利润可空），选择结果小数位及差异容差，确认年度资料完整性。
2. 导入UTF-8 CSV或XLSX，选择页签与表头，确认替换，检查字段对应并重新确认主体期间。可先体验完全虚构样例，全部案例参数仅教学，不可用于申报。
3. 建立或修改调整规则：填写ID、版本、主体币种单位、生效起止年度、依据文号/章节、生效依据、适用条件与确认人，勾选适用确认。规则默认没有法定数值。
4. 差额公式区分收入与费用；年度限额按同规则ID合并账面金额并共用一次年度基数，每行填写相同的年度总基数。不支持跨年结转、税额/优惠资格判断、任意脚本或自定义表达式。
5. 在测算明细查看公式、代入、舍入差和例外；原始行缺失不补零，年度一行失效阻塞整组。其他事项继续显示局部结果，完整利润桥在全部导入组可算时才显示。
6. 在例外复核填写复核人与意见，逐组确认或撤销；阻塞不能人工通过。改资料或规则会清除复核。来源页查看文件/页签/原始行号及全部字段。
7. 下载九页XLSX底稿、含数据工作或仅规则方案JSON。恢复前确认替换，取消保留当前全部工作；恢复后重算；仅规则方案会清除当前原始资料和复核。schema_version=1，当前版本不支持的方案拒绝。文件和方案最多10MB，XLSX解压30MB、200列，本款5000事项、200规则，全部记录可搜索、每页25条、前后页/末页/直接跳页；计算和底稿保留全部。

下载离线包并解压后用Chrome或Edge双击index.html；成品无CDN、在线字体及外部请求。资料仅浏览器内存，不上传、不遥测、不默认持久化，关闭/退出清空，未下载工作不能找回。

源码：Node.js22+，npm ci、npm test、npm run typecheck、npm run build -- X03；同版本源码包说明见 docs/source-build.md，输出 release/X03/0.1.2/index.html 与 runtime.json。开发编译依赖已锁定，成品无需安装或联网。原官网税务模块列表/详情/同站工作区由总控维护，ToolProgram接口已提供。

参考来源和财务规则见本文件夹；独立预期见源码包本款目录。
