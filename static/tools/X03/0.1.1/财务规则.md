# X03 财务规则 X03-2026-10-04.1

金额最多24位数字、6位小数；Decimal隔离60位精度。结果逐组按用户选定0—6小数ROUND_HALF_UP舍入。容差只用于标记小额差异，不能把差异归零；记录原始调整、舍入调整及残差，合计为已舍入组额之和。空不等于零。

主体、完整年度、币种、单位必须显式一致；不换汇。费用差额=账面-税务；收入差额=税务-账面。直接调整使用输入税务栏作为非负调整绝对额及用户方向；负值允许在差额公式且提示红冲复核，限额公式负值阻塞，不推断冲回。

受限算式只允许差额、年度基数比例上限、年度双比例上限、直接调增、直接调减。上限=min(账面,基数×比例)；双限额=min(账面×发生额比例,基数×基数比例)。比例输入为0—1十进制，无预填法定值。不支持任意表达式、eval、脚本。年度同规则账面求和，共用基数必须一致；规则ID不可拆分同一政策以重复使用年度基数，用户声明年度资料完整，否则年度组阻塞。

规则含版本、精确主体币种单位、起止年度、适用条件、来源文号/章节、生效依据、确认人、确认状态。缺依据、未确认、日期失效、源数据缺失、重复ID或规则映射不唯一：对应组阻塞，其他组继续显示局部结果；存在阻塞时不显示完整调整后利润。复核不能解锁无效事项。

官方核验：实施条例第27/28/43条；国家税务总局2025-05-30回应关切再次说明一般经营招待费年度双限额与视同销售基数。财政部公开条例（页面发布日期2007-12-13）第133条已核验2008-01-01生效（https://www.mof.gov.cn/zhengwuxinxi/zhengcefabu/2007zcfb/200805/t20080519_27853.htm）；本款不自动创建法定规则或认定资格，规则有效期及条件由用户填入。教育经费、广告专项比例、优惠税率、跨年结转及不确定政策只阻塞有关事项；不得套旧政策数字。所有样例参数/依据为虚构演示，不能用于申报。

利润桥只展示输入会计利润+已计算净调整；不计算应纳税额、不含亏损弥补、免税及其他未导入项目。需用户确认资料与政策完整才具有完整已导入事项的含义，仍不是申报确认。每组保留全部来源行、公式、代入、版本、参数、例外和复核。
