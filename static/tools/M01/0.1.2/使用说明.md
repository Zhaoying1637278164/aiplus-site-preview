# M01 客户产品项目盈利分析

候选0.1.2，八页管理分析工作链。尚未经总控正式包装、原官网及公开下载验收，不标accepted；Windows实机未验证。

解压候选离线包，Chrome/Edge双击index.html，断网可用。先点“载入完全虚构样例”，经分析范围、资料、字段口径、费用池确认后计算；原始行、结果与分摊表50行分页可达末页，底稿全量导出。资料仅在浏览器内存，关闭/清空/退出清除，不上传或默认持久化。

输入：收入成本业务（每行同客户/产品/项目/期间/币种/单位）、共用费用池。UTF-8 CSV或xlsx，先选页签和表头再应用。单文件10MB，解压30MB，每表20000行200列，不支持xls/xlsm/宏/外链/密码。公式不执行且引用字段阻塞。空缺不等零；无成本费用须填0并注明依据。没有共用费用需主动确认，不从未导入推断为零。

业务模板字段：记录ID、期间、币种、单位、客户、产品、项目、收入、直接成本、成本依据、直接费用、费用依据、分摊权重。费用池字段：费用池ID、期间、币种、单位、共用费用、分摊基础、范围维度、范围值、费用依据。字段可以映射。期间YYYY-MM，币种三个大写字母，单位元/千元/万元。金额最多6位小数24位数字，建议金额及编号原始值以文本保存。

池基础正收入/权重/平均，范围全部/客户/产品/项目，全部的范围值*；正收入法将零及负收入基数置0，权重须非负，同期间币种单位分配。分摊精度默认两位，池金额超精度拒绝。尾差归最大基数，同基数最小ID。毛利、直接贡献、分摊后贡献严格区分，成本缺失不称利润；利润率先汇总再相除，非正收入不适用。规则详见财务规则.md。

下载13表XLSX底稿（含原始资料/异常/三维汇总/分摊过程/复核）、含数据工作JSON或无数据方案JSON。恢复会替换当前工作，校验schema和应用/规则版本后按原行重算，不信任缓存结果。工作含数据请自行保管。没有AI/OCR、自动因果判断、会计政策判定、自动汇率/记账或远程服务。

源码重建四命令：npm ci；npm test；npm run typecheck；npm run build -- M01。Node22+、Python3，安装锁定依赖需网络，成品运行不需要网络。候选输出 tools/M01-客户产品项目盈利分析/candidate/0.1.2/。第三方通知随程序附带。

共用费用页可直接保存/撤销人工分摊基础、范围及依据，不修改原始费用池。分摊过程上限100000行，超过整体拒绝并提示缩小范围，绝不截断。
