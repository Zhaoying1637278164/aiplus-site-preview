# U02 财务规则

应用0.1.0；规则U02-2026-10-04.1，自2026-10-04本候选生效，仅用于用户已决定样本量后的选择与记录。依据为本项目规格及已核验方法参考，不是中国注册会计师审计准则实现；政策判断、自动保证水平、样本充分适当性、错报外推均未实现且无输出入口。

1. 原始总体按记录ID作为抽样单位。总体ID、币种、单位、YYYY-MM期间与配置严格匹配；必填空、公式、重复ID等阻塞待抽总体。来源标识为文件＋页签＋原行。完全原始行留存，公式仅存文本不执行。
2. 剔除显式填写原因；已剔除行继续出现在原始总体/校验/剔除底稿。无原因不剔除。源行重复或陈旧剔除来源阻塞。原始重复ID可通过显式剔除重复项消除待抽ID重复，不静默去重。
3. Decimal精度40，金额最多24数字6位小数；求和不舍入、不按币种改精度。容差只用于外部控制金额比较，不改变计算值。NULL不等零；零负值保留并提示，-0数值归一为0但原文留存。混币种/单位/期间不自动转换。外部条数比原始全部条数；外部金额比全部原始金额，有未知行则无法通过。
4. 原始条数=待抽条数+剔除条数；已知原始金额=待抽已知金额+剔除已知金额。未知金额单独计数；已剔除缺金额允许继续选择但不宣称全总体金额完整，外部金额控制存在则仍阻塞。待抽金额=样本金额+未入样金额，负数符号守恒。
5. 简单随机：种子字符串UTF-16逐码单元FNV-1a得到uint32，零状态替换0x9e3779b9，xorshift32生成流，按记录ID UTF-16排序后Fisher–Yates不放回洗牌。非零32位输出减1映射至0…2^32-2，每个有界抽取拒绝超过floor((2^32-1)/m)*m范围的值，避免取模偏差。伪随机有限状态，不作为密码学随机或统计保证。
6. 分层随机：每层必须显式给配额，可为0，总数须>0；不得大于层总体。层名UTF-16排序，层种子JSON.stringify([原种子,层名])，逐层独立洗牌，不按金额自动配额。
7. 指定项目：ID必须属于待抽总体、唯一且至少一项，有选择依据；顺序按输入。它是非统计选择，不允许由其向总体推断。
8. 外部控制数可空但提示未核验；控制数一致仍不能证明总体真实完整。抽样目的/样本量依据必填，样本量自行确定，不内置海外风险表。
9. 方案schema_version=1，绑定tool/app_version/rule_version/algorithm/contains_data；含数据工作保留全部总体，无数据方案仍含参数/剔除标识与原因，清楚提示且不声称全无敏感文本。恢复替换全部工作并重新计算；换资料清除行级选择。版本不匹配拒绝。
