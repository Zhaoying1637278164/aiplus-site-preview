# U02 审计抽样

候选0.1.0，尚未由总控accepted或公开发布。七页完整工作：总体资料、校验与剔除、抽样参数、样本清单、来源追溯、底稿与恢复、使用说明。打开candidate/0.1.0/index.html使用；不需要账号或联网。

先载入完全虚构样例，或导入UTF-8 CSV/静态XLSX，选择页签和表头行并确认替换。固定中文字段：总体ID、记录ID、金额、币种、单位、期间、分层、摘要。每行一条抽样单位，记录ID唯一。填写范围、目的、样本量依据，校验缺失及范围，明确剔除原因；选择简单随机、分层随机或指定项目，复核样本和全部来源后导出。

金额Decimal最多24数字、6位小数；空不是零，零负值默认保留，混币种单位期间阻塞，不自动转换。外部控制数一致也不能证明总体完整。种子与算法版本记录，重复输入参数种子重复样本；不提供保证水平、自动样本量、充分适当性或错报外推。

底稿8表包含参数版本、总体勾稽、样本、总体校验、剔除、分层、异常与限制、所有原始行；阻塞时样本表空，诊断仍可下载。分页/搜索不影响全量导出。无数据方案保留参数和剔除标识/原因，含数据工作包含全部总体；恢复前明确contains_data，主动下载JSON，不默认存储。换资料清除旧剔除/指定/层配额。关闭或清除释放内存。

文件限10MB，解压30MB，20000数据行200列，单元格10000字。不运行宏/公式/外链/用户代码，不上传/遥测/在线字体/CDN/外部请求。

源码包根目录四命令：`npm ci` → `npm run typecheck` → `npm test` → `npm run build`。本工程定向验证：`node --import tsx --test tools/U02-审计抽样/tests/*.test.ts`，`npx tsc --noEmit -p tools/U02-审计抽样/tsconfig.json`，`node --import tsx tools/U02-审计抽样/scripts/build-candidate.ts`。Node22+，构建依赖锁文件。源码含共享core和ToolProgram接口，不含node_modules、凭据或业务资料。

实际证据见验收证据.md；官网集成与公开下载由总控验收。Windows实机未验证。
